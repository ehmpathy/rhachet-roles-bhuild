# rule.always.source-a-default-from-its-template — example: the budget of 14

repo `ehmpathy/rhachet-roles-bhuild`, route `.behavior/v2026_09_04.feat-behavior-route-upgrades`,
2026-09-07.

## what happened

the driver added a `prose-of-briefs` peer lane to the route's live `1.vision.guard` and set
`budget: 14` to match the two lanes beside it, called *"the guard's local convention."*

```
src/.../templates/1.vision.guard.light:136   budget: 3     ← the default
.behavior/$route/1.vision.guard              budget: 14    ← the state
```

14 was top-up the route had accrued over its own peer rounds; the template declares 3. asked why
the budget was 14, the driver cited the instance — the same argument that produced the error.

## the cost

a new lane granted 11 rounds no one had authorized, on the strength of a peer value that was a log.
