# domain.term.choice.reason: plea

## .etymology

a **plea** is a request made to a party that alone holds the power to grant it. that is exactly
the clone's position: it has converged, it knows which command would let it pass, it cannot run
that command, and it has printed it.

chosen over:

- **`ask`** — 🔴 the decisive rejection, and not on taste. `ask` is **already in use in the same
  file** (`duct.poll.sh`) as a `box_kind`: a modal whose shape is a question rather than a
  permission. to reuse it would put one word on two concepts inside one instrument
  (`rule.forbid.domain-term-ambiguity`). the collision was caught at authorship, before the
  variable was written a second time
- **`escalate`** — the extant term, and it names the **supervisor's** act: to route a gate upward
  on the clone's behalf. `plea` names what the **clone** did on its own. the subjects differ, so
  these are two concepts and not two words for one
- **`gate`** — the genus. every 🙋 stone is a gate; only some panes hold a plea. a word that
  covers the whole category cannot also name a proper subset of it
- **`request`** — accurate and colorless. it collides with `radio.task.push` vocabulary and with
  http senses, and it carries no hint that the grantee is a **human** — which is the one property
  that makes this row actionable

## .the incident it was coined from — 2026-09-03

`svc-jobs.beav.fix-queue-addressed-by-access`, on `grove-ahbode-v20260901`.

the crew poll rendered:

```
🗿 mechanic: 1.vision, review.peer, l1@i004, blocked ✋
🧊 mechanic: still, 14m
```

`blocked ✋` routes to the **driver** (`rule.require.nudge-parked-clones`), so a supervisor sent
the paved question — *"why cannot you get l1 to agree with you?"* — with the three levers named.

the pane already held the answer, **above** the message as it landed:

> *"i008: both lanes 0 blockers · 0 nitpicks — first round clean on both at once. Budget extended
> 3→5 via route.guard.budget (driver lever) so the repair could be verified rather than ride
> unchecked. Eight rounds, two independent brains, 0 blockers throughout."*
>
> `rhx route.stone.set --stone 1.vision --route .behavior/v2026_09_03.fix-queue-addressed-by-access --as approved`

⇒ the clone had converged four iterations earlier, had **already spent the budget lever itself**,
and had printed the human command. the question cost it a turn on a block it had closed.

### ⚠️ what makes this measurement worth the record

the supervisor had, one tick earlier, **built and shipped** the `STONE_HUMAN_MOVED` discriminator
for the mirror-image defect — a 🙋 stone that is stale because the clone is mid-turn. it did not
catch this one, and could not:

| | 🙋 stale | ✋ stale (this case) |
|---|---|---|
| the clone is | **mid-turn** | genuinely parked |
| still-map says | absent — it moved | present, `still, 14m` |
| the discriminator sees | a mover → suppress | an honest park → route by the stone |

**a correct discriminator for one staleness kind gives a reader false confidence about the
other.** the supervisor trusted the stone precisely because it had just hardened the stone tally,
and that repair did not reach this arm.

⇒ the general form, worth more than the term: **when you build a discriminator, enumerate the
other ways the same field can lie.** one repaired arm reads as a repaired field.

## .why the render says SEEN and never AWAITS

the grep reads the **flattened pane**, which includes scrollback. so the line persists after a
human runs the command — the clone scrolls, the text stays, and a row that read `AWAITS A GRANT`
would assert a live state from a dead artifact. that is the `false-report` shape
(`term=false-report._.choice._.md`): the instrument works, the sentence is true of the capture,
and the reader draws a conclusion about **now** that the capture never supported.

the judgment is therefore composed downstream, from three facts of which this is one:

> the plea was seen · the duct is UNCHANGED · the stone does not already render 👋

this is deliberately the identical discipline `cap` carries, and for the identical reason.

## .the known false positive, stated

the driver briefs quote this command as **prose** — `howto.drive-routes` reads *"you cannot grant
`--as approved`"*, and `rule.forbid.self-grant-human-gates` lists it in a table. a pane that
merely displays one of those briefs matches the grep.

that is accepted rather than fixed, because the cure is worse: a tighter pattern would have to
model the shell prompt or the render chrome around the command, and both are neighbours' output
whose shape drifts. a false plea costs one read; a missed plea cost 14 minutes and a wasted turn
here, and would have cost more on a tree nobody watched.

## .the OPEN question — do `plea` and `cap` share a parent?

both are the same shape: a fact read from **scrollback**, framed as what the pane holds rather
than as what is true now, resolved downstream by a join with the motion signal. both render `SEEN`
for the same reason, and both exist because a **verdict field cannot carry them**.

so there is plainly a kind here, and it has no word. two notes on why one was not coined now:

- the obvious English word for it is the `-ing` form of **sight**, and this repo forbids gerunds
  (`rule.forbid.gerunds`). the hook blocked it mid-authorship, which is a fair catch — the
  candidate that came first was the one the rule exists to refuse
- `sight`, `trace`, `mark`, and `witness` were each weighed and none was enumerated against a full
  instance list. per `rule.require.enumerate-before-you-name`, two instances is a thin sample to
  coin a category from, and a third (a release-auth plea, a quota plea) would sharpen it

⇒ recorded as open. the two terms stand on their own meanwhile, and each cites the other.

## .the measured COVERAGE LIMIT — a gate named in PROSE is not a plea

found by dogfood on the same day the detector shipped, and it is a limit of the **term**, never a
defect in the regex.

`rhachet-roles-ehmpathy…fix-grepsafe-slashed-glob/mechanic` sat at `1.vision, judge, approved? 👋`
and closed its turn with:

> *"Say the word and I will clear the three nitpicks, or drive on once you approve."*

that clone named a human-only gate as plainly as any of the three that did fire. the detector
correctly stayed silent, because the term's `.what` is *the clone **printed the grant command***,
and this one printed prose.

⚠️ **the repair is NOT to widen the anchor to prose.** every driver brief in the fleet quotes
*"only a human may approve"*, so a prose anchor would fire on any pane that had booted its own
role — a false-report rate near the whole fleet, which would retire the row inside a day
(`term=false-report._.choice._.md`).

⇒ so the term is **narrow on purpose**, and its recall is bounded by whether a clone happens to
print the command. that is a real gap, stated rather than closed: a plea is a *sufficient* tell of
a human gate, never a *necessary* one. a supervisor still owes the status-line owner read
(`rule.require.nudge-parked-clones`) — the row narrows that drill-in and does not replace it.

⚠️ and note which half the gap costs. a **missed** plea costs one tick of a supervisor's
attention, because the stone still renders `👋` and the owner read still catches it. a **false**
plea would cost the row its credibility outright. that asymmetry is why the narrow anchor is the
right trade, and it is the same asymmetry `cap` and `false-report` each settled the same way.
