# domain.term: ask

term.chosen   = ask
term.kind     = noun  (the verb form — *to ask* — is the same word, per `poll`'s precedent)
term.synonyms.forbidden:
- question
- request
- query
- prompt
- inquiry
- poke
- favor

## .what

a message that **hands the reader the work of an answer** — it does not restore motion, does
not change a route, and does not render a verdict. it transfers a piece of thought.

```
nudge      restores MOTION      — the clone was stopped, now it goes
steer      changes ROUTE        — the clone was headed at a wall
ask        transfers THOUGHT    — the reader must now answer
escalate   transfers a DECISION — the verdict is not yours to give
```

## .the boundary against its three peers

each of the four is one message into one keyboard, so they part on **what the reader owes back**:

| | what the reader owes | who governs it |
|---|---|---|
| **nudge** | naught — they resume the plan they held | `rule.require.nudge-parked-clones` |
| **steer** | naught — they take the path you named | `term=steer` |
| **ask** | **an answer** — thought they must produce | this cluster |
| **escalate** | a **verdict** — one only they may render | `term=escalate` |

⇒ the sharpest pair is **ask vs steer**, and the fleet already draws it:
*"why can't you get l3 to agree with you?"* is an **ask**, not a nudge — it hands the clone the
work of a diagnosis (`term=nudge`, its own routes table).

## ⚠️ .an ASK is not a HALT — and the two arrive in one message

this is the distinction the word most needs, and `term=steer` already records it:

> **the ask and the halt are two things.**

a clone that stops and says *"i need X"* has emitted **both**: a question that may genuinely be
the human's, and a stop that is usually its own. they are parted by one test:

| the half | the question it answers |
|---|---|
| the **ask** | *may this be answered by anyone other than the reader?* |
| the **halt** | *must the work stop while it is answered?* |

⇒ so a legitimate ask can ride on an **illegitimate** halt. the paved move is to answer the ask
where it is genuinely yours **and refuse the halt regardless** — a steer on the halt, an answer
on the ask (`term=steer`, sense 3).

## .an ask COSTS — and that is what bounds it

an ask is the one message of the four that spends the **reader's** thought rather than the
sender's. so it is priced, and the fleet prices it explicitly:

> *an ask is worth its cost only while neither answer is known to be safer.*
> — `rule.require.clarify-radio-push-vs-pull`

that rule was **superseded** for exactly this reason: once the safe default was established
(`define.sprout-vs-seed`), the ask bought naught and became a round trip. the sprout-vs-seed
case is the paved example — a bare *"dispatch"* seeds, and no question is owed.

⇒ **the test:** *"is there a default that fails safe?"* where there is, the ask is a round trip
and the default is the answer. where there is not, the ask is owed.

## .an ask is NOT

- **a `nudge`** — a nudge restores motion the clone already had; an ask stops it to think
- **a `steer`** — a steer names a path; an ask names none and requests one
- **an `escalation`** — an escalation transfers a **verdict** that is not yours to render. an ask
  transfers **thought** that anyone could produce (`term=escalate`)
- **an approval** — a `--keys 1` renders a verdict on a request already made. an ask makes one
- **a `prompt`** — TAKEN twice over: the harness's permission modal (`🚧 PROMPT`), and the text
  handed to a brain. one word, three concepts, so it is forbidden here outright
