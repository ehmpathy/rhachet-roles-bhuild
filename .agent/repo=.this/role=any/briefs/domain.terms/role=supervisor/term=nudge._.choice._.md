# domain.term: nudge

term.chosen   = nudge
term.kind     = verb  (the noun form — *a nudge* — is the same word, per `poll`'s precedent)
term.synonyms.forbidden:
- ping
- poke
- prod
- wake
- bump
- kick
- unstick

## .what

a **single message into a parked clone's keyboard that restores its MOTION** — it was stopped,
and now it goes on with the plan it already held.

```
parked, plan intact      → a NUDGE       restores motion
parked, plan blocked     → a steer       changes route
parked, gate is human's  → an escalation changes nobody's plan
```

## .the boundary against `steer` — the one that carries the load

both are one message into one parked keyboard, so they are easy to conflate. they differ in what
changes, and each answers to a different rule:

| | what it changes | who governs it |
|---|---|---|
| **nudge** | the clone's **motion** — stopped, now it goes | `rule.require.nudge-parked-clones` |
| **steer** | the clone's **route** — headed at a wall | `term=steer`, whose third sense no rule yet covers |

a nudged clone resumes the plan it already had. a steered clone takes a different one.

⚠️ `nudge` sits in `term=steer`'s forbidden-synonym list, and that is **not** a contradiction —
it is the house pattern (`replication` forbids `reproduction` on the identical ground). a word
taken by an adjacent concept is forbidden AS A SUBSTITUTE precisely because it is live elsewhere.

## .the evidenced kinds

the nudge rule's own routes, sorted:

| the message | verdict |
|---|---|
| dismiss a survey or other non-permission modal | ✅ a nudge — the clone was stopped by chrome |
| *"release into prod"* to a verified, granted tree | ✅ a nudge — it is done and awaits a word |
| a continue prompt after a vendor cap's reset has passed | ✅ a nudge (`rule.require.resume-quota-capped-clones`) |
| the carry-on order to a crew whose view was hidden | ✅ a nudge — silence stopped it (`rule.require.brief-a-crew-you-hide`) |
| *"`git checkout -b` is off your allowlist — rebase in place"* | ⛔ a **steer** — the route changes |
| *"why can't you get l3 to agree with you?"* | ⛔ an **ask** (`rule.require.ask-why-the-reviewer-wont-agree`) |
| `--keys 1` on a permission modal | ⛔ an **approval** (`howto.review-permission-requests`) |

## .a nudge is NOT

- **a steer** — see the table above. the two rules do not overlap
- **an approval** — `--keys 1` renders a verdict on a request. a nudge answers no request
- **an ask** — a question hands the clone the work of an answer; a nudge hands it leave to go
- **free** — a nudge costs the clone a turn. `rule.require.brief-a-crew-you-hide` grades one sent
  into a pane where a human is live a **blocker**, and `rule.require.resume-quota-capped-clones`
  grades one sent under a still-live cap a **nitpick**. it is spent on a clone that is genuinely
  stopped, never on one that is merely quiet
