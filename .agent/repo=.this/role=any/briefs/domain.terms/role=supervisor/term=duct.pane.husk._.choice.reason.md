# domain.term.choice.reason: duct.pane.husk

## .etymology

⚠️ **there is no etymology here, because there is no coinage.** `husk` was paved on 2026-08-25
for a `_worktrees/` dir git does not own, and every word of its definition transfers unchanged:

> *"it has a tree's shape and a tree's name, and it is not a tree."*

the round that met this state reached first for the glossary rather than for a keyboard
(`rule.always.reuse-pavement-before-improvise`), and the glossary answered. what follows is the
record of **why the reuse holds**, which is the only claim a reuse owes.

### the parent's own forbidden list predicted this family

`term=husk` forbids `ghost`, `phantom`, `zombie`, `leftover`, `debris`. those are precisely the
words a traveler reaches for when they meet a pane like this one — so a fresh coinage would have
landed on a word the parent had already ruled out, in a sense the parent had already claimed.

⇒ **the strongest tell that a reuse is right is that the independent coinage would have been a
forbidden synonym of the extant word.**

### what parts a reuse from an overload

`rule.forbid.domain-term-ambiguity` forbids one word over two concepts, so the reuse had to
survive that test before it could be written. run the two senses out:

| the subject | substance present | the absent half | what it is mistaken for |
|---|---|---|---|
| a **worktree** | a dir full of files | git's admin entry | a tree |
| a **duct.pane** | claude's drawn chrome | the claude process | a live, empty box |

the third column differs — a **record** in one, a **process** in the other — and that difference
is what a careful reader will challenge. it does not part the concepts, because in each subject
the absent half is simply *whatever conferred liveness there*, and the defect is identical: an
instrument checks the substance, finds it, and never checks the half that is gone.

⇒ so it is **one concept over two subjects**, which the rule answers with a **boundary**, never a
second word. `duct.pane.husk` slots beside `duct.pane.plea` and `duct.pane.cap` with no friction.

### 🔴 the arrears this creates — the parent is now under-qualified

`term=husk._.choice._.md` carries **no `term.boundary` field** and a flat filename. the moment a
second subject exists, that flat name is ambiguous by `rule.require.boundary-qualified-terms`'s
own test:

> **"$word, of WHAT?"** — `husk, of what?` → a **tree**, or a **duct.pane**.

the parent is owed `term=tree.husk`. **left in place until disturbed** — a rename touches every
citation of a term settled a week ago, and the rule's own no-mass-rewrite clause governs. this is
the second such arrears on the record: `tree.inflight` is owed for exactly the same reason, from
exactly the same kind of round.

⇒ **that pattern is now n=2, and it deserves a name: a boundary-qualified child paves the ROAD,
and the flat parent it came from is the pothole it leaves behind.** a term paved flat before its
second subject existed will always come due later, and it always comes due at the moment a
traveler is busy elsewhere.

#### the classifier arm this one exercised

| token | what it asserts | why it is believed |
|---|---|---|

grove tree renders `on grove — not read from here`, so neither half holds. **no grove crew can be
flagged `WORK ORPHANED`, by construction.**

#### 🔴 the husk HIDES FROM THE STALENESS DETECTOR — and this is why it goes unseen for hours

the two tokens above are not a stable misclassification. **they oscillate on a pane that never
changes**, and the motion detector reads each flip as movement.

measured across four ticks on this one crew, whose pane is byte-identical throughout — same
`💥143`, same `04:20:51`, same `took 1d0h18m4s`:

| tick | box token | the row it produced | still-age |
|---|---|---|---|
| A | `mechanic:empty` | `🙋 blocked:on-human` + a stone | 10m |
| C | `mechanic:empty` | `😶 at work — foreman:shell mechanic:empty` | **42m** |
| D | `mechanic:❔unread` | `😴 unread` | **6m** |

⇒ **the still-age FELL, 42m → 6m, on a pane that had not changed in hours.** an age can only fall
if the instrument believes the duct moved. so the flip between `empty` and `unread` is itself
counted as motion.

that closes the loop on why a husk survives so long unseen:

- `😴 CLONE QUIET` keys on **a large still-age that no other duct shares** — and this duct's age is
  reset every time the token flips, so it never grows large enough to fire
- the `🌊 ducts moved` tally counts it among the **movers**, which is the fleet-level signal that a
  supervisor reads as *"the fleet is alive"*
- and `rule.require.pause-babysit-cron-after-idle-streak` counts a no-change streak. **a husk
  contributes a false CHANGE to that count**, so a fleet of husks would read as a busy fleet

🔴 **the fix must therefore NOT be built on the still-age.** the obvious repair — *"flag a duct
that has been still too long"* — is defeated by construction here, because the husk's own
misclassification manufactures the motion that clears the timer. the discriminator has to be the
one this term already names: **read whether the pane's LAST line belongs to claude or to the
shell.** that is a property of the render, and no oscillation upstream of it can launder it.

### .what this does NOT license

- ⛔ **do not read the exit code as a liveness test.** it answers *what killed it*, and only after
  the extant discriminator has already answered *is it a husk*. a live claude prints no exit code
- ⚠️ **`^C%` does not mean the gate was granted** — it means a human was at that keyboard. read

## .the invariant it adds

> **chrome outlives whatever drew it.**

every extant duct state asks *what does the pane show*. none asks *is the author of that render
still alive*. the peer terms all assume a live clone and differ on where it sits in a turn:

| state | what it assumes of the clone |
|---|---|
| `empty` · `prefilled` · `queued` · `inflight` | alive, at various points of a turn |
| `shell` | never started |
| `down` · `phantom` | the tmux session itself is gone |
| **`duct.pane.husk`** | **started, finished, and left its face behind** |

⇒ so the maxim for the classifier is: **read what the pane shows — and whether anyone is still
there to have shown it.**

## .the family this joins

this is the **third proxy row** on `term=false-report`, and the most expensive of the three:

| the proxy | the false inference | what it costs |
|---|---|---|
| the `🗿` stone line | *"this is its current state"* | a stale surface |
| `🙋 PLEA SEEN`, already answered | *"a grant is owed"* | a human's glance |
