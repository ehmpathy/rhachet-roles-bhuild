# domain.term.choice: appendix

## .what

an **appendix** is a support artifact a stage emits beside its yield: the evidence, the walked
space, the demos. the yield states the decision and **cites the appendix by path**; the appendix
holds the work that produced it.

```
term.boundary = yield        # "an appendix, of WHAT?" → of a yield
```

🟡 **`yield` is a boundary this glossary names and has not yet declared** — see the `.readme.md` gap
census. the boundary is right; its own cluster is owed.

## .the shape — an INFIX, never a dir

```
$stage.yield.md                      # the decision
$stage.yield.appendix.$what.md       # the work behind it
```

⇒ a dir (`$route/appendix/`) would file every stage's appendices together and break the `N.stage.`
prefix sort that orders a route dir. the infix keeps the sort and carries the same claim.

## .why it is a term rather than a filename habit

the infix **partitions one glob into three**, so a rubric can name exactly one of them:

| glob | reaches | what grades it |
|---|---|---|
| `*.yield.md` | the decisions | a density rubric — the yield must be terse |
| `*.yield.appendix.*` | the evidence | a coverage rubric — the space must be walked |
| `*.yield*` | both | a prose rubric |

🔴 **a density gate over an appendix would fire on evidence that is correctly placed.** the
appendices are archaeology **by contract** (`rule.require.archaeology-in-notes`), so the separation
is what stops the terse-yield rule from a cut of the proof it rests on.

## .forbidden synonyms

| forbidden | canonical | one-line |
|-----------|-----------|----------|
| `support artifact` | `appendix` | prose, not a term; and it names no relation to the yield |
| `peer file` | `appendix` | names the **filesystem** relation, so it holds for the stone and the guard too |
| `attachment` · `annex` · `addendum` | `appendix` | plain synonyms; one word per concept |
| `archive` | `appendix` | 🔴 **a real distinction.** bhrain's `rule.always.yield-the-output-not-the-archaeology` parts them: an **appendix** holds evidence under a decision that IS in the yield; an **archive** holds ideas **rejected** |
