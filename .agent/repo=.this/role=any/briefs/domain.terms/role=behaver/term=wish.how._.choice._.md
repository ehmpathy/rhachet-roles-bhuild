# domain.term: how

term.chosen   = how
term.kind     = noun
term.boundary = wish
term.synonyms.forbidden:
- implementation
- solution
- approach

## .what

a part of a wish that says **how** the work gets done, rather than **why** it matters or **what**
the wisher asks the product to do: a poc or prior command, a parity target a prior tool set, a named mechanism
(field, flag, storage layout), a done-when phrased by a prior tool.

a how is evidence, never spec. vision and criteria restate each how in domain terms, with a keep,
drop, or open verdict, in the vision yield's `## .the wisher's how` table. an open how is one only
the wisher can settle; it is also a `[wisher]` open question.

## .its peers in a wish

| part | trusted | how far |
|---|---|---|
| why | yes | whole |
| contract (verbs, rough shape) | yes | roughly |
| how | no | evidence only |
