# domain.term.choice.reason: decost

## .etymology

`de-` + `cost`. the category set is built on one morphology, declared in
`define.eco.rock-taxonomy`: **`de-` cuts, `en-` builds.** so `decost` reads
*"cut the cost"*, `ensell` reads *"build the sell"*, `entool` reads *"build the
tool"*.

three categories, one shape, each six letters. the symmetry is not decoration —
it is what lets a reader tell the set is closed at a glance, and what makes a
fourth coinage feel wrong before anyone checks the rule.

## .disputes

### dispute: dekeep — raised 2026-09-14 — status: RESOLVED (keep `decost`)

- raised.by = beaver 🦫 (a supervisor, mid-registration of a priority row)
- claim = a row about **revenue we fail to keep** — a voice-transcript leak that
  never reached an invoice — fits neither *"cut the cost"* nor *"build the
  sell"*. it needs a third branch, `subrock://ahbode/dekeep`, for the objective
  *"keep what we earn"*
- counter = the wisher, verbatim, in three moves:
  > *"what is dekeep?"*
  > *"decost = keep what earn"*
  > *"otherwise, where would it go? its a cost if its not kept"*
- resolution = keep `decost`; record `dekeep` and `enkeep` as forbidden
  synonyms. `decost`'s scope was never "the bill" — it is **the gap between
  earned and kept**, and revenue that leaks out is a cost by the only definition
  that matters here. the say file now states that scope out loud, because its
  absence is what made the coinage feel necessary

#### 🔴 the three independent refutations, cheapest first

each would have killed the coinage alone. **the cheapest one was available
first, and it was the one not run.**

| # | the refutation | what it costs to run |
|---|---|---|
| 1 | 🔴 **the set is CLOSED.** `rule.require.rock-goal-treestruct` grades a `{category}` outside `{decost, ensell, entool}` a **blocker** | one grep — and the rule had **already been read in the same session** |
| 2 | **the morphology inverts it.** `de-` cuts the noun it binds, so `de-keep` reads *"cut what you keep"* — the exact opposite of the intent | one read of the taxonomy table |
| 3 | **the scope already covered it.** an unkept dollar is a cost | one question to the wisher |

⇒ **#2 is the sharpest, and it is worth more than the verdict.** the coinage did
not merely fail to fit the set — **it meant the reverse of what it was coined to
mean**, and it read fine anyway. a morphology strong enough to make a new word
legible is strong enough to make a new word LIE, and it does so silently:
`dekeep` scans as a peer of `decost` because it has the shape of one.

## 🔴 .the failure was not ignorance — it was a COINAGE reached for before a LOOKUP

the rule that forbids this was read in the same session, minutes before. so the
defect is not that the closed set was unknown; it is that **a gap in a taxonomy
was answered by an invention rather than by a re-read of the taxonomy.**

⇒ `rule.always.reuse-pavement-before-improvise` names exactly this, and its cue
fires here: *"you name a new artifact, dir, or convention"* → check what the repo
already names.

⚠️ and the tell was present and ignored: **the new word was the only one whose
scope had to be argued for.** `decost`, `ensell`, and `entool` each need no
defense; `dekeep` needed a paragraph. **a category that owes an argument is a
category the set did not want.**

## 🟡 .the real defect this dispute exposed — the say file was SILENT on scope

the coinage was a rational response to a real absence. before this cluster,
`decost` was defined nowhere as a term:

- `define.eco.rock-taxonomy` gives it one cell — *"cost **down**"* — which is
  the narrow read
- `rule.require.rock-goal-treestruct` gives it one row — *"cost **down**"* —
  the same narrow read
- ⇒ **no artifact said "keep what you earn"**, so a reader with a revenue-leak
  row in hand found two sources that both told them it did not fit

⇒ **a closed set whose members do not state their own bounds invites a fourth
member.** the enforcement clause carried the whole load, and an enforcement
clause catches the coinage only *after* someone has written it.

## .evidence

- **discovery**: the live registration of a voice-transcript leak
  (`ahbode/svc-notifications#223`), which had no obvious category under the
  narrow read of all three
- **precedent**: the `en-`/`de-` morphology, declared in
  `define.eco.rock-taxonomy` — the same pattern that makes `ensell` and `entool`
  legible is what makes `dekeep` read backwards
- **invariant**: the `{category}` slot takes exactly one of three values; a
  fourth is a **taxonomy decision**, never a free-form slug, and only a human
  may make it

## 🟡 .drift noted, not repaired

⇒ left as found: the repair is a rewrite of a peer brief, not a term choice, and
