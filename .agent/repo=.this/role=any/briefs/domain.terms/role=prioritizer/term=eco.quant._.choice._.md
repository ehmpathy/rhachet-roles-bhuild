## .what

a **quant** is a field on an `eco.priority` whose value is a NUMBER a human
would defend — either one the store counted, or one the human estimated and
would put a figure on.

three today: `quant.gain` (cash we get back), `quant.cost` (work to do it),
`quant.asks` (how many times a human reached for it).

## .the invariant it carries

> **a quant INFORMS an opine. it never overwrites one.**

that direction is the whole reason the word exists. a quant is narrow by
construction — `asks` counts a reach, `gain.cash` counts one cell of the 3x2
cost-gain matrix — so a rank driven by quants alone would rank by whatever
happens to be countable. the human carries the rest, and the `opine` is where
they put it.

⇒ so the rank order is opine-first, always, and a quant that disagrees with an
opine arrives as a **flag** (🪃, ⚖️, ❔) for a human to re-judge. the store decides
naught.

## .the pair

`quant` : `opine` :: measured : judged. one term is useless without the other —
the split is the model, and either half alone reads as "the fields."
