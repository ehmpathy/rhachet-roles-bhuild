🔴 **stdout is the sharper case than prose, not the softer one.** `U+26A0` is
`East_Asian_Width=Ambiguous`, so a terminal reserves 1 cell where an emoji font paints 2. in a
markdown body that shift reaches no column a reader relies on. in `catch.dream.ts:86` the glyph sits
**inside a treestruct** (`└─ ⚠️  …`), where a one-cell error shifts every column to its right — and
`rule.require.treestruct-output` is what those branch characters exist to satisfy.

🟡 **the two-space padding after each `⚠️` is the tell that someone already met this.** it is a hand
correction for a width the author could not predict, and it is wrong on whichever terminal the
author was not using.

## .the shape of the fix

1. `rhx sedreplace --old '⚠️  ' --new '🟡 ' --glob 'src/contract/cli/*.ts'` — note the **two**
   trailing spaces collapse to one; `🟡` is `U+1F7E1`, unambiguously Wide, so the pad is no longer owed
2. same over `src/domain.roles/behaver/skills/*.sh`
3. `rhx git.repo.test --what integration --resnap` + `--what acceptance --resnap` for the 3 snapshot lines
4. verify with the grep above — it must return `0`

🟡 **check the palette before you assume `🟡` is right for every site.** these are `warn`-severity
writes, and `catalog.of=glyph._.md` may already assign a marker to that role; a second glyph for one
concept is its own defect (`rule.forbid.emphasis-noise`, glyph-synonym drift).

## .why it is not done in this round

**not clean.** the 7 files are outside `--diffs since-main`, so a repair here widens a route whose
wish states *"do not widen"* — and it would drag 3 snapshot files into a diff about behavior-route
upgrades, where a reviewer would have to sort a real prose repair from unrelated churn.

**and not safe, in one spot.** `review.behavior.sh` writes through `echo` in a skill whose stdout the
guard parses; a glyph swap there touches a surface `contract.reviewer-output` reads. that wants its
own verification, not a ride-along.

⇒ the 6 in-diff occurrences are repaired, so this branch adds no new carriers. the defer of the rest
is a judgment about ripple cost, so it rides fulcrum `F26` beside the error-header sweep.
