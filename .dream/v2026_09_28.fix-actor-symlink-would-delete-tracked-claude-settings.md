# 🌙 dream: the actor symlink would delete the repo's tracked `.claude/settings.json`

- **kind** — `fix`
- **owner** — this repo (`ehmpathy/rhachet-roles-bhuild`), plus whoever owns actor isolation
- **caught** — 2026-09-28, at `5.3.verification` of
  `v2026_09_22.feat-lift-supervisor-and-prioritizer-roles`

## .the cue that fired

a routine `git status` read, while halted, reported a deletion I never made:

```
 D .claude/settings.json
?? .claude
```

both lines at once. the first is a **tracked** 548-line file; the second is a new symlink
that took its place.

## .the gap, precisely

`.claude` is no longer a directory. actor isolation replaced it:

```
$ file .claude
.claude: symbolic link to .agent/.actors/actor.via.slug=.default/brain/.claude
```

⇒ git sees the tracked path `.claude/settings.json` as **gone**, and the symlink as new.

🔴 **and the target is not the same file.** the symlinked settings is a reduced copy —
`git show HEAD:.claude/settings.json | diff /dev/stdin .claude/settings.json` reports
`9,56d8`: the whole repo-level `SessionStart` boot block is absent from it.

| hook the tracked file boots | in the symlink target? |
|---|---|
| `roles boot --repo .this --role any` | 🔴 absent |
| `roles boot --repo ehmpathy --role mechanic` | 🔴 absent |
| `roles boot --repo ehmpathy --role architect` | 🔴 absent |
| `roles boot --repo ehmpathy --role ergonomist` | 🔴 absent |
| `roles boot --role driver` · `--role reviewer` | 🔴 absent |

## .why it is a hazard rather than a defect today

the deletion is **unstaged**, and the staged index records no change under `.claude`:

```
$ git diff --cached --stat origin/main -- .claude .gitignore .agent
  (empty)
```

⇒ so the PR as it stands is clean. the hazard lives in the **commit that has yet to
happen**:

| the commit | what lands |
|---|---|
| `rhx git.commit.set --unstaged ignore` | ✅ safe — the deletion stays out |
| 🔴 `rhx git.commit.set --unstaged include` | the deliverable **plus** a 548-line delete of the repo's hook config |
| 🔴 `git add -A` | same |

⚠️ and `--unstaged include` is the natural reach for this PR, because the entire
deliverable is untracked — `git ls-files --cached 'src/domain.roles/supervisor/*'`
returns `0`, and so does the prioritizer. one flag stages both the lift and the deletion.

**the harm, named:** every future session in this repo opens with no boot hooks. no role
briefs, no permission notice, no route bind. the failure is silent — a session simply
starts less capable, and nobody reads a diff for an absence.

## .the shape of the fix

| # | the move | owner |
|---|---|---|
| 1 | at commit time, stage the deliverable **explicitly** — never `--unstaged include` — so `.claude/settings.json` keeps its tracked blob | 🔴 whoever commits this PR |
| 2 | decide whether `.claude` SHOULD relocate under the default actor's brain. if yes, the tracked content must move with it and `.gitignore`'s `!.agent/.actors/actor.via.slug=.default/` must land in the same commit | this repo + actor-isolation owner |
| 3 | if no, restore `.claude/` as a real directory and teach the enroll tooling to place actor brains beside it rather than over it | actor-isolation owner |

## .why it is not done in this round

**SAFE?** 🔴 no. the symlink is load-bearing for the session that found it — this clone's
own brain sits at `.agent/.actors/actor.via.hash=07bb9428/brain/.claude/`, and the
enrolled peer reviewers read from sibling actor dirs. to undo it mid-drive breaks the very
reviewers the stone is halted on.

**CLEAN?** 🔴 no. it ripples into `.gitignore`, `.agent/.actors/`, and the enroll tooling —
none of which this lift opened.

⇒ so: caught, and surfaced where the human will meet it — the blocker artifact names it
beside the `claude /login` ask, because both are read at the same moment.
