## .the gap, precisely

the `case=_` inventory carries two independent statements of one fact, and no check that ties them:

1. the **matrix** — 36 rows × 2 legs, each leg verdicted `demoed` / `itemized` / `forbidden` /
   `impossible`, with a care grade
2. the **tally** — a prose sentence that counts the `itemized · criti` legs and owes a reason per
   leg ("there are **nine**, all happy legs…")

**measured evidence that they drift:** on this very route the tally read **six** while the matrix
verdicted **nine**. rows 10, 20, and 22 sat in the tables and outside the count, and row 17 was
mis-filed as kind 2 while its own sharp leg is demoed — which is how "six" read as internally
consistent. it **survived four review rounds**. two peer lanes found it in the same round; the
author never did.

⇒ the defect class is not "someone miscounted once". it is that **the count and what it counts are
stated twice, in prose, with no mechanical tie** — so they drift silently and read plausibly.

## .the shape of the fix

a suite that parses a `1.vision.experience.case=_.md` and asserts its internal consistency:

| assertion | what it catches |
|---|---|
| count the matrix legs verdicted `itemized` + care `criti`; diff against the number the prose tally states | the six-vs-nine defect, exactly |
| every row the tally enumerates by number exists in the matrix with that verdict | a row named in the reason table but re-verdicted later |
| every `itemized · criti` row in the matrix appears in the tally's reason tables | the inverse — a leg verdicted and never reasoned about |
| every `demoed` cell names a `case=N`, and that file exists on disk | a demo pointer with no target |
| every sharp `demoed` row has a non-empty fail-safe column | the declared blocker condition of the contract |

🔴 **glob it, never pin it.** match `.behavior/*/1.vision.experience.case=_.md` so the suite guards
every route's catalog and survives this route's archival. a test pinned to
`v2026_09_22.feat-lift-…` dies the moment the route is archived, and dies green.

⚠️ **prove the clamp bites** (`rule.require.clamp-edge-cases`): restore the tally to "six" on a
fixture copy, watch it go red, restore "nine", watch it go green. a clamp never seen to fail is a
guess.

suggested home: beside the behaver's other catalog guards, **not** in `src/domain.roles/*.test.ts`
— see below.
