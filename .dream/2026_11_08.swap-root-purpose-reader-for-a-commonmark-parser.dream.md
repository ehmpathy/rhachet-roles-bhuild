# 🌙 dream: read the root purpose through a commonmark parser, not a partial renderer

- kind: refactor
- owner: bhuild/behaver (the depth lane)
- caught 2026-11-08

## .the cue that fired

a peer reviewer (5.1, round i006, `enroll-impl-arch-defects` nitpick.1) found the fifth divergence
between the depth lane's line reader and a rendered page.

## .the gap, precisely

- the section reader is a partial commonmark renderer, built from three parts:
  - `asMarkdownLinesRendered`
  - `asIndentWidth`
  - the nest bounds in `getOneVisionRootPurpose` (`LIST_MARKER_WIDTH`, `CODE_INDENT_WIDTH`)
- each review round found one more place where it disagrees with a page:
  - tab width
  - a fence inside a comment
  - a `<!--` inside a code span
  - a one-column nest
  - a code-indented nest and a blockquote chain
- each one is clamped now. the class stays open: lazy continuation, list items that interrupt a
  paragraph, and html blocks other than comments are all still unmodeled

## .the shape of the fix

- walk an mdast tree (`mdast-util-from-markdown`, or `micromark` with its mdast extension):
  - find the h2 whose text is `.the root purpose`
  - take its section up to the next h1 or h2
  - depth = the longest chain of `listItem` nodes whose paragraph opens with `why:`
- delete `asMarkdownLinesRendered`, `asIndentWidth`, and the nest bounds
- keep every parser caselist row as the clamp. the rows are the spec, and a parser that matches
  them all is a sound swap

## .why it is not done in this round

- it adds a pinned runtime dependency to a published role package, which is the owner's call
  (fulcrum F22)
- the lane already matches a page on every clamped row
- each extant miss is graded `better`: it costs a round, and ships no harm
