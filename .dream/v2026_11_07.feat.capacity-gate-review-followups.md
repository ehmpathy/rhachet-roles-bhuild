## .the gap, precisely

1. **terms** (`enroll-impl-arch-defects` i004 blocker.3): `at work` means a live duct in the
   supervisor glossary, but `crews_at_work` here means ≥ 0.25 cores. `caps.jsonl` is an append-only
   change log, named a ledger (the glossary's ledger upserts one row per subject). `gate` and `hold`
   overlap `plea`/`park` and the dispatcher's `held`. no `domain.terms/role=supervisor/term=*` file
   holds gate, hold, slot, lever, pool, or calibrate
2. **scanner marks** (`mech-failhides` nitpick.3–4, `enroll-impl-behavior-intent` blocker.4): a cap
   line that does not parse is dropped by `fromjson?` with no mark; `find`/`grep` errors on the burn
   scan go to `/dev/null`; a config dir under an unreadable ancestor is never listed. each makes a
   total a silent lower bound
3. **the gate verdict channel** (`enroll-impl-arch-defects` nitpick.1): "no slot" and a bad flag both
   exit 2; `trap 'exit 0' PIPE` can turn a printed refusal into exit 0. a distinct exit for "no slot"
   or a `git.grove.slot` verb would part them
4. **burned keyed by grove** (`enroll-impl-arch-defects` nitpick.2): a directive crew's root is the
   same path on every grove, so a burn on grove A hides an idle crew on grove B
5. **the levers file** (`enroll-impl-arch-defects` nitpick.5): the shipped `levers.jsonc` carries
   this fleet's read counts and tiers; a consumer owes its own evidence
6. **test polish** (`ergo-friction-hazards` nitpick.1–5, `enroll-impl-behavior-intent` blocker.5–6,
   `behavior-intent-coverage` nitpick.3): census `--help` untested; `--until` error path untested;
   merge conflict and malfunction renders asserted, not snapped; caplog `--status` not snapped; no
   capacity-level asleep/timeout case (tokens [case8]/[case9] clamp the shared ladder); the lever
   table never snapped in rank order; no real directive crew in any capacity fixture
7. **a 🟡 stall grants in silence** (`enroll-impl-behavior-intent` nitpick.2): the brief says sprout
   with a reason at 2–10%; the grant tree prints no stall line there
8. **render labels** (i005 `enroll-impl-behavior-intent`): the headline count says neither "at once"
   nor its band; the tokens/h figure never says "cost-weighted", and no footer names the weights
9. **the caplog tick cost** (i005 `enroll-impl-behavior-intent`): each statusline refresh forks
   `git rev-parse`, ~10 `jq`/`date`, `flock`, and a whole-ledger `grep | tail`; measure forks per
   tick before the fleet rollout, and read only the ledger tail
10. **lib seams** (i005 `enroll-impl-arch-defects` nitpicks 1–3): one hold-key derivation above
   both gate paths; the pure calibration defs out of `capwork.sh` into a `calwork.sh`; named
   `as_probe_instant` / `get_find_min` in the `calibrate` orchestrator. the early-refusal `--json`
   shape gains `free`, `held_before`, `idle`
11. **gate verdict and probe channels** (i006 `enroll-impl-arch-defects` nitpicks 1–5): put the
   deadline remote (`ssh … "timeout $t bash -c …"`) so a timed-out scan stops on the box it reads;
   render `free N (held H)` on the read; one `as_gate_verdict` transformer for all seven exit sites
   (the early reheld grant claims `unread_axes: []` it never read); a `notes` list from probe stderr
   to the row, so a crew filed `other` on a failed `git` is never silent; stamp `source: fixture`
   when the fixture record replaces the probe

## .the shape of the fix

- terms: run domain discovery per term, write `term=<x>._.choice._.md` for each, rename the cpu
  sense (`crews_busy`? — a term call, so discovery first) and the cap file or its name
- scanner marks: count the dropped cap lines and the scanner's non-zero exits into the unread list,
  as the per-file unreadable case already does
- verdict channel: exit 3 for "no slot" (a refusal of the box, not of the caller), or split the gate
  into `git.grove.slot get|gen|del`
- burned: key by (grove, crew)
- levers: ship the schema and generic rows; read the evidence from a consumer path
- tests: a fake `ssh` on PATH for the capacity asleep/timeout arms; an unsorted lever snapshot on the
  fixture record; a repo-root fixture crew for directive; mask-then-snap the four renders
- 🟡: a `🟡 cpu stall N% — sprout with a reason` line on the grant tree

## .why it is not done in this round

safe, but not clean: the terms are a vocabulary call that wants discovery and ripples through
renders and snapshots; the channel is a contract change; the rest is polish past a ladder whose
every lane spent its rounds. each item is better, none ships a harm the round left open.
