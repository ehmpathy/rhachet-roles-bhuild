# 🌙 dream: crew boot verbs grant phone contacts both ways

kind: followup · owner: bhuild supervisor · caught 2026-10-21

## .the cue that fired

#491: "contacts supplied at boot by whoever boots the tree". the phone ships `phone.contacts set`
as the boot step, but `git.crew.boot` and `git.tree.behavior` do not call it.

## .the gap, precisely

- `crew.boot` (`src/domain.roles/supervisor/skills/work/crewwork.boot.sh:19-340`) enrolls each seat
  as `@:<role>` and passes no director address into the tree
- grep `director|contacts` over `src/` (before the phone) → 0 matches

## .the shape of the fix

two halves:

1. **the director's boot hooks lift its meter** (the wisher's verdict on F3/F4): the director's
   boot hook runs `phone.contacts.uses allow` beneath the clone, so a director may `set` / `del`
   its own contacts. no role is allowed by detection; the meter stays blocked by default for
   every other tree. the director role lives outside this repo, so this half is a `reseed`
2. **the crew boot verbs grant contacts both ways**, after each seat enrolls, beneath their own
   shell (not a clone tool call). contacts are per clone and take no `--at` (route fulcrums F11,
   F12), so each grant runs as the seat it widens — in that seat's tree, with that seat's serial
   in `RHACHET_CLONE_SERIAL` (or from the seat's own boot hook, which already runs beneath it):

```sh
# in the crew tree, once per seat (mechanic, then foreman), as that seat
rhx phone.contacts set \
  --address "phone://grove=$director_grove/tree=$director_tree/clone=$director_clone"

# in the director tree, as the director
rhx phone.contacts set \
  --address "phone://grove=$crew_grove/tree=$tree/clone=mechanic" \
  --address "phone://grove=$crew_grove/tree=$tree/clone=foreman"
```

   which of the two (env, or each seat's own boot hook) the verb uses is the open half of the fix;
   the boot hook needs no new env plumb, the env needs no new hook.

the director's grove, tree, and clone come from the caller: its grove name (never `local` — it is
cast before it is stored), its tree name, and `rhx clone whoami`. a crew sprouted on a remote grove
names that grove in `$crew_grove`.
