  (`__grove_refused_cure`); the cause is not
- `saturation` prints `└─ 🔴 refused — <cause>` on one line; `saturation.spend` prints
  `🔴 refused (rc=255)` with the cause nested below
- the stall legend prints under renders with no measured figure (refused, asleep)
- wake snapshots pin `--timeout 0`, so the prose reads `within 0s`
- wake's `account:` label is one column wider than its peers
- `git.grove.send`: the file-write failure shape differs from the command failure, and hedges
  with "if"; case2 snaps an empty string
- no live render or snapshot for: the poll unreached seat roll in `pollwork.summary.sh`, the
  no-answer lines in `git.grove.auth.sh`, `git.tree.duct.sh`, `crewwork.boot.sh`, `duct.list`,
  `duct.poll.sh` (verdict + 🛟 footer), `__term_attach_program`'s retry line, the `cloud://` strip
  in `git.grove.send.sh`, and `saturation.spend`'s `😴 asleep (timeout …)` string
- no acceptance run of a bare `rhx git.grove.list` through the built package
- `saturation.spend` has no live read of a grove that answers (only the refusal arm runs)
- `git.crew.poll --help` and `git.grove.saturation --help` are unsnapped
- `git.grove.send`: case2 pins an empty stderr; no rc 0 run is pinned; the command failure opens
  with ssh's raw line, unlabeled, and its header carries `(rc 255)`
- the reach reader's row refusals print `git grove set <grove>` where the grove is known, a regex
  class (`[A-Za-z0-9._:-]`), and "power lever"

  label ends in a colon over children, and its `reach:` pad aligns to an absent `box:` row

  says `down`/`mute` where the render says `DOWN`/`MUTE`
- list: no pin of the all-live footer, nor of the silent-timeout cause on a hetzner row
- the `duct.send` pins in `[case3]` and `[case4]` differ in their last newline

## .the shape of the fix
- one `__grove_cause_of verdict=<v>` transformer beside `__grove_refused_cure`; every site calls it
- one refusal shape (`└─ 🔴 <verdict> — <cause>`, cure as its child); drop `rc=255` from prose
- print the legend only when a measured figure is in the render
- wake fixtures at `--timeout 1`; align the wake's label column
- a live-render snapshot per surface above, each with a hetzner and an ec2 grove
- one bare `rhx git.grove.list` in `skill.surface.acceptance`, asserted free of
  `No such file or directory`
