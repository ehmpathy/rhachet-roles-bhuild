# 🌙 dream: init.behavior --help should print usage, not error

kind: fix · owner: behaver · caught 2026-10-05

## .the cue that fired

stone 5.3.verification of `.behavior/v2026_10_05.feat-brain-per-stage`. the critical-path walk
ran `rhx init.behavior --help` and got an error, not help. the fix was built, then reverted: the
peer reviewer `ergo-contract-snapshots` (r002 blocker.1) ruled that the fix flips an extant pinned
test's intent, and only the wisher can approve that flip.

## .the gap, precisely

- `rhx init.behavior --help` exits non-zero
- stderr: `⛈️  error: input invalid` / `└─ --name must be a string, got undefined`
- stdout: empty
- cause: `src/contract/cli/init.behavior.ts` parses `schemaOfArgs` (with `name: z.string()`
  required) before it looks at any help flag. there is no help flag in the schema at all
- the gap is pinned on purpose: `blackbox/role=behaver/skill.init.behavior.flags.acceptance.test.ts`
  `[case7] --help flag (currently errors - no help support)` asserts `exitCode not 0` and snaps
  the error

this breaks ergonomist `rule.require.help-on-demand`, which marks a command with no `--help` as a blocker.

## .the shape of the fix

1. add a help-only zod schema (`help`, `h`, plus the rhachet passthrough keys `repo`, `role`,
   `skill`, `s`; getCliArgs strips unknown keys). parse it first; on `--help` or `-h`, print help
   and return before `schemaOfArgs` demands `--name`
2. `HELP_TEXT` as a treestruct: `.what`, usage, every flag (`--name`, `--size`, `--guard`,
   `--wish`, `--open`, `--dir`, `--help, -h`) with defaults, and one example
3. flip `[case7]`, **after wisher sign-off**: exit 0, every flag listed, no `.behavior/` created
   and no branch bound, with stdout and stderr snaps. add a `-h` case that snaps both streams too
   (r002 blocker.2 asks for both variants snapped)
4. add `--help, -h` to the `init.behavior.sh` header

## .why it is not done in this round

it is safe and clean as code. the blocker is that it rewrites an extant test whose intent was pinned
on purpose, and `rule.forbid.test-intent-violations` needs explicit wisher approval for that. the
wish (brains per stage) does not cover it. recorded as fulcrum F13 for the council.
