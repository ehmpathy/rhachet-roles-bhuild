# 🌙 dream: the husky practice's secrets gate hides a broken grep

kind: reseed · owner: declapract-typescript-ehmpathy (upstream) · caught 2026-11-08

## .the cue that fired

the `mech-failhides` peer lane on `5.1.execution.from_vision` (branch `beav/feat-vision-root-purpose`)
raised a blocker on `.husky/check.secrets.sh:48`, a file the husky practice delivered.

## .the gap, precisely

```sh
line=$(printf '%s\n' "$content" | grep -nIE -e "$regex" | head -n 1 | cut -d: -f1)
```

under `set -eu` with no `pipefail`, the status of that substitution is `cut`'s, which is 0. so a
grep that breaks (exit 2, e.g. a malformed `-E` regex after a future edit to `SHAPES`) reads as a
clean no-match, and the gate passes a commit it never scanned. proven here: with this pipe shape
restored, `.husky/check.secrets.integration.test.ts` goes red (12 of 34).

## .the shape of the fix

shipped here as a repo-local addition, marked inline — port it to the practice verbatim:

```sh
status=0
matches=$(printf '%s\n' "$content" | grep -nIE -e "$regex") || status=$?
if [ "$status" -gt 1 ]; then
  # 💥 MalfunctionError: check.secrets could not scan for a key shape (+ shape, exit, fix) → exit 1
fi
line=$(printf '%s\n' "$matches" | head -n 1 | cut -d: -f1)
if [ "$status" -eq 0 ]; then
  # ✋ ConstraintError … exit 2
fi
```

also port: the `fix:` line on the unreadable-blob malfunction, the shape order (`anthropic key`
above `openai-style key`, else a `sk-ant-` key is named as the wider shape), and the integration
suite (each shape, the word edge, a broken regex via a temp copy, an unreadable blob, snapshots
with grep's and git's own lines masked). its fixture keys are built from parts at runtime, so the
suite passes the gate it tests.

the peer gate `check.timestamps.sh` held the same class: its scan pipe ended in `head`, so a
broken `sed -E` or `grep -E` pattern read as clean. fixed here the same way (each tool's status
read by hand, `💥 MalfunctionError` + fix, exit 1), with clamp [case7] — port it too.

half is done. until the practice adopts it, a `declapract apply --practice husky` here would
revert it — the inline `repo-local:` note marks the line to keep.
