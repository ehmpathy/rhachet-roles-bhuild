## .the gap, precisely

- `getGithubTokenByAuthArg` returns `{ token, role, authSource }`; callers strip `authSource` with a rest spread, so a new field would leak into `github.auth`
- `getOneRadioContextFromCliArgs` and `getOneRadioContextForRecord` each build `{ github: { auth }, git }`
- `ShellExecutor` is declared in `record/ShellExecutor.ts`, `genAuthFromKeyrack.ts`, `getOneRadioContextFromCliArgs.ts`, and inline in about eight auth files; `{ env, shx, keyrackGet? }` repeats beside it

## .the shape of the fix

- return `{ auth: { token, role }, authSource }` from the derive, so no caller spreads
- the record builder calls the cli builder for its channel context, and adds only the replay bar and the held fault
- one `ContextRadioAuth` type in `auth/`, imported by every op
- clamp: types pass with the rest spreads gone; the context builder suites green
