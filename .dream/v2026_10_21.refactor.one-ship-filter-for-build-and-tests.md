# 🌙 dream: one ship filter that the build and every test read

kind: refactor · owner: rhachet-roles-bhuild · caught 2026-10-21

## .the cue that fired

i007 peer review of `fix-clamp-behaver-boot-budget` (r011 blocker 2, r010 nitpick 10): the boot
clamp's `isRoleFileShipped` is a hand copy of the rsync filter in `build:complete:dist`, and
`orgNamesAbsent.integration.test.ts:46` holds a second copy, `isShipped`, which already disagrees.

## .the gap, precisely

- three statements of "what the build ships": the rsync `--include/--exclude` flags in the
  `package.json` command `build:complete:dist`, `isRoleFileShipped` in
  `roleArtifacts.integration.test.ts`, and `isShipped` in `orgNamesAbsent.integration.test.ts`
- the only drift guard on the clamp copy is a snapshot of the build command string — it prompts a
  human, it does not compare behavior

## .the shape of the fix

- move the filter rules into one file (e.g. `src/domain.roles/.ship.filter`), read by rsync via
  `--filter='merge src/domain.roles/.ship.filter'`
- in both tests, materialize the seat copy by a real rsync with that merge file, or parse that one
  file — then delete `isRoleFileShipped`, its 15-row table, the command snapshot, and `isShipped`
- clamp: a test that rsyncs a fixture tree and asserts the shipped set, so a filter edit is
  exercised, not remembered

## .the cheaper variant, and why it is not taken either

i008 r011 nitpick 3 offered a variant that edits neither the build command nor `orgNamesAbsent`:
read `scripts['build:complete:dist']` from `package.json`, swap its last two args `src/ dist/` for
the role dir and the seat dir, and run it in the test. that makes `rsync` a bare host dependency of
the test, which `rule.forbid.bare-host-deps` (mechanic) forbids: the build may assume it, a test
may not. the variant is viable once the test provisions rsync, or once the filter lives in one
file that a test can parse without rsync (the shape above).

## .why it is not done in this round

not CLEAN: it edits the build command and a second, unrelated test suite (`orgNamesAbsent`), so it
ripples past this behavior's diff. the round's clamp mirrors the filter today and agrees with the
real build (`roles cost --what dist/...` equals src for every budgeted role).
