# 🌙 dream: qualify every `✋`/`💥` error header across `src/domain.roles`

**kind** = repair · **owner** = bhuild · **caught** 2026-10-21

## .the cue that fired

`mech-failhides` r004 on stone `5.1.execution.from_vision` raised `rule.require.qualified-error-headers`
on `src/domain.roles/supervisor/skills/git.grove.keyrack.sh`: 18 headers read `✋ git.grove.keyrack:`
where the rule asks `✋ ConstraintError:`. that file is repaired in this round. the grep that followed
it was the find:

```sh
rhx grepsafe --pattern '✋ [a-z][a-z.]*:' --path src/domain.roles --output pipeable
```

258 lines after the keyrack repair.

## .the gap, precisely

the skills under `src/domain.roles/**/skills/*.sh` open an error with the skill's own name as its class
(`✋ <skill>: …`). the header names where it came from and leaves out who must act — the one fact the
qualifier exists to carry. the same pattern holds across every role, so it is a convention, not a
slip.

### the shared cli parser carries the same gap, plus a wrong exit code

found at `5.3.verification`, 2026-11-20, in a live walk of `rhx tally.reviews.peer --by bogus`:

```
⛈️  error: input invalid
   └─ --by invalid option: expected one of "lane"|"rule"
exit=1
```

`src/infra/cli/getCliArgs.ts:143` opens every arg refusal with `⛈️  error:`, and `:160` exits `1`.
a bad flag is the caller's to fix, so it is a `✋ ConstraintError:` and exit `2`
(`rule.require.exit-code-semantics`). every cli that parses through `getCliArgs` inherits both.
untouched by this route (`git diff origin/main` empty).

## .the shape of the fix

1. per skill: `rhx sedreplace --old '✋ <skill>: ' --new '✋ ConstraintError: '` and the same for `💥` →
   `MalfunctionError:`, plan then apply
2. for each PreToolUse hook: keep `exit 2` on a `💥` (the gate must not fail open)
3. resnap the acceptance suites whose snapshots carry the old header, and read each diff
4. `getCliArgs`: header → `✋ ConstraintError: input invalid`, `process.exit(1)` → `2`; update its
   three unit assertions, `skill.reflect.on.reviews.self` at line 380, and any suite that asserts
   exit 1 on a bad flag
5. verify: the grep above returns 0

## .why it is not done in this round

**not clean.** 258 lines across many skills outside this route's diff, plus whichever acceptance
snapshots carry those headers. a sweep here drags unrelated skills and snapshots into a pr about behavior-route upgrades,
and a reviewer would have to sort a real repair from churn. the defer is a judgment about ripple cost,
so it owes a fulcrum too: `F26`.
