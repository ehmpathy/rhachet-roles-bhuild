# 🌙 dream: `git.crew.move --mode verify` reads each seat's bar

- kind: feat
- owner: rhachet-roles-bhuild, supervisor role
- caught 2026-11-26

## .the cue that fired

a level-3 review of `fix-crew-move-promoted-upstream` (r10) noted the wish's gate: the bar. verify proves the ledger, the tree, and a live claude in each seat, but never the bar. a seat can pass verify with a blank bar, and that is how the original gap hid.

## .the gap, precisely

- `__crew_move_verify` (`work/movework.sh`) has no bar row
- no crew-grain suite runs a real tmux. each one fakes the duct verbs and records the calls, so no test can boot a seat and read its stamp

## .the shape of the fix

1. per seat in verify, run `__duct_status_box_probe "<grove>" "<session>"`. print `✓ bar: <repo> · <branch> (pinned)`, or `✗ bar: unpinned`. a probe that cannot read prints `unread`, never `✗`
2. a crew harness on a private tmux socket (`DUCTWORK_TMUX_SOCKET`, as ductwork uses), with claude faked by a no-op in the pane. use it to boot one seat via `crew.boot --resume` and assert the `🏷️ status box` line plus a pinned probe
3. one move apply snapshot over that harness that carries the line

## .why it is not done in this round

the route's stamp is proven at the duct grain (`ductwork.status`, real tmux) and the crew grain (`crewwork.verbs`, which records the calls). the live proof is the release step's `tmux.bar.probe` on hetzner. a real-tmux crew harness is new test infrastructure, larger than this route's last review round. see fulcrum F14.
