## .the gap, precisely

- case1 [t0]–[t5] chain six whens on one scene: each when reads the files the prior one wrote
  (task a held at [t0], delivered at [t2], its mark lost at [t5])
- gate writes (`setLocalGate`) and record edits sit inside `useThen`, so a when's title names an
  outcome while its body holds setup plus the act
- case2 [t0], case3 [t0], case6 [t0], and case7 [t0] each run two or three pushes in one `useThen`
- check: `git diff origin/main` on the file. the frames date from #409 (`572d65a`); this pr changed
  only the run id, the cleanup path, one push arg, and the [case7] asserts (#511)

## .the shape of the fix

- give each step of case1 its own given, whose `useBeforeAll` replays the prior pushes to reach
  the state that step starts from (a `genSceneAfter({ steps })` fixture keeps the replay short)
- move every `setLocalGate` and record edit into that `useBeforeAll`; leave the when with one push
- where a when must run two pushes (a re-push, a second task), split it into two whens, each with
  one `useThen` and a singular label
- keep the journey readable: one top `describe` per case, the given titles numbered as the steps
