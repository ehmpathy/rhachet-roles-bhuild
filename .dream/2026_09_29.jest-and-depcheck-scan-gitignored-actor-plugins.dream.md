# 🌙 dream: jest and depcheck scan gitignored actor plugins

kind: reseed · owner: declapract-typescript-ehmpathy · caught 2026-09-29

## .the cue that fired

`rhx git.repo.test --what unit --thorough` on `beav/fix-radio-recorder` reported
`552 passed, 0 failed` yet exited failed: 6 suites FAIL under
`.agent/.actors/actor.via.hash=*/brain/.claude/plugins/.../code-modernization/tests/*.test.ts`.
`rhx git.repo.test --what lint` then failed on depcheck (verbatim: `Missing dependencies * claude-code`)
from the same plugin dir.

## .the gap, precisely

- `.agent/.actors/` is gitignored (`.agent/.actors/.gitignore:7:/*`), so CI never sees it
- but jest `testMatch` (`**/*.test.ts`) and depcheck walk the whole tree, gitignored or not
- ⇒ any clone whose actor dir holds a claude plugin with tests fails unit + lint locally, with
  no defect in the repo

## .the shape of the fix

in the declapract-typescript-ehmpathy templates:
- `jest.{unit,integration,acceptance}.config.ts`: add `'!**/.agent/**'` to `testMatch`
- `.depcheckrc.yml`: add `ignorePatterns: ['.agent']`

## .why it is not done in this round

the configs are template-managed; an edit here drifts from the template and is stamped back
on the next `declapract.upgrade`. the fix belongs upstream.
