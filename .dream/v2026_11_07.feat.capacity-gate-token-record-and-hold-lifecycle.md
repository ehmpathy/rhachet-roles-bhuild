# 🌙 dream: the capacity gate's token record, its hold lifecycle, a per-account cap ledger, and one set of probe readers

kind: feat · owner: supervisor role (rhachet-roles-bhuild) · caught 2026-11-07

## .the cue that fired

round i003 of `5.1.execution.from_vision` on `beav/feat-concurrency-token-budget`. three reviewers
(arch-defects, behavior-intent, hazards-behavior) asked for redesigns of the gate's inputs, each
larger than the round. fulcrums F16–F19 record the call to defer.

## .the gap, precisely

1. **gate latency** (F16): each `--for` ask on a grove not stalled 🔴 runs `git.crew.tokens` and
   `calibrate`, each a fleet-wide scan. measured 135–227s per scan at load 37–56. `FREE` is read
   before the scans end.
2. **hold lifecycle** (F17): a hold counts until `--release` or a 15 min lapse. a caller that never
   releases double counts for up to 15 min. a fresh crew reads ~0 cores, so it sits in neither count.
   holds live on the gate host, and a held refusal names no holder, age, or lapse.
3. **cap ledger scope** (F18): rows live per worktree, so a fell drops them. N seats log one change N
   times. a past span's burn is filed by today's sign-in.
4. **reader duplication** (F19): the census, the token probe, and the capacity probe each hold a
   `/proc` reader and a config-dir glob. the census still forks two jq per transcript.

## .the shape of the fix

- persist the derived token record (burn per kind-hour, calibration) with its age under
  `~/.rhachet/storage/repo=bhuild/role=supervisor/`. the gate reads it, and a record past its bound
  reads ⚪. better still: the token probe emits time-bucketed usage, so one scan derives any window
- until then, a two-pass gate: ask `calibrate`'s scan-free cap-row arm first; read the fleet burn
  only on a calibrated pool, or on the ram-refusal path, where `idle_crews` needs `burned` to name
  the crews to fell (G9). a skipped burn must never feed `idle_crews`, or it names crews at work idle
- key each hold by tree slug (the same slug as `.bind.<branch>.flag`). a hold counts only while that
  tree is not a crew at work. a repeat ask for a live tree answers "already sprouted". the held
  refusal lists holder · age · lapse
- cap ledger: one file per account, `…/cap.ledger/<account>.jsonl`, keyed (account, 5h %, 7d %). a
  config dir's account at time t = its latest row at or before t
- `work/procwork.sh` (the `/proc` readers) and `work/repowork.sh` (repo roots, config dirs), embedded
  via `*_payload_lib` in both probes. the census calls the token probe and reads its record

## .why it is not done in this round

safe, but not clean. each item is a new store or a new probe contract with its own clamps, and each
ripples into both verbs and the census. the round's budget was one review pass.
