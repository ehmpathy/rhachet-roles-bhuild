# 🌙 dream: one grove fan-out for every grove read

kind: refactor · owner: bhuild/supervisor · caught 2026-11-06

## .the cue that fired

the 5.1 self review `has-consistent-mechanisms` on `feat-concurrency-token-budget`. the two new
verbs (`git.crew.tokens`, `git.grove.capacity`) each carry a copy of the grove fan-out.

## .the gap, precisely

four inline copies of one mechanism, no shared lib:

| verb | the copy |
|---|---|
| `git.grove.saturation.sh` | `GROVE_PROBER` dedupe (~:166), the fan-out (~:911), the classifier (~:1044–1080) |
| `git.grove.saturation.spend.sh` | `GROVE_PROBER` (~:198), fan-out (~:323), classifier (~:351) |
| `git.crew.tokens.sh` | `GROVE_PROBER` (~:305), fan-out + `get_forest_record` classifier (~:337–365) |
| `git.grove.capacity.sh` | `GROVE_PROBER` (~:291), fan-out + classifier (~:319–352) |

the copies already disagree. saturation sorts an ssh-level timeout (`Connection timed out`,
LoginGraceTime) apart from a probe-budget timeout and names it a load signal; `ductwork.uri.sh`
counts `Connection closed` / `Operation timed out` as unreachable; the two new verbs file all of
those as `unreadable`. one box, three verdicts by verb.

## .the shape of the fix

- `skills/work/grovework.fanout.sh`: `__grove_fanout <payload> <timeout>` — read the registry,
  dedupe entries by `host:port` to one prober, run the payload on each (local `bash -c`, remote
  `ssh -n -o BatchMode=yes -o ConnectTimeout=8`), write `<slug>.{out,err,rc}`
- `__grove_fanout_rows`: one classifier → `[{grove, state, hint, record}]`, states
  `read | timeout | asleep | unreadable`, the saturation split of ssh-timeout kept as a hint
- each of the four verbs keeps its own payload and its own hint verb
- clamp first: one fixture per state, run through all four verbs, asserted equal
- let the shared probe take its `/proc` root from an env path (default `/proc`), so a fixture
  can set `pressure/cpu` and `stat`: the capacity gate's 🔴-stall refusal and its free-cpu math
  then run on any box, where today only the branch the host's real stall picks runs

## .why it is not done in this round

safe, not clean: the lift rewrites two verbs this branch does not own (`git.grove.saturation*`)
and their large clamp corpus. fulcrum F12 on `feat-concurrency-token-budget` records the defer.
