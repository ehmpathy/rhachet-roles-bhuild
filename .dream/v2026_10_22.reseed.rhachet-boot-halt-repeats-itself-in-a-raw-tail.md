## .the gap, precisely

`npx rhachet roles boot` on a spec over its budget prints, on stderr:

1. a clean treestruct — `✋ ConstraintError: over budget`, budget, payload, over-by, four fixes
2. two blank (color-reset) lines
3. a second header: `✋ ConstraintError: boot payload exceeds its declared budget`
4. the error's metadata as raw json: `{ "hint": …, "budget": …, "payload": …, "over": … }`
5. an argv dump: `[args] roles,boot,--what,<path>`

items 3–5 restate item 1 in a less legible form. it reads as the cli's top-level error handler
that prints a thrown `ConstraintError` after the command already rendered it. evidence: the
snapshot `the halt reads as a human meets it` in
`src/domain.roles/__snapshots__/roleArtifacts.integration.test.ts.snap` (rhachet-roles-bhuild).

## .the shape of the fix

where the boot command renders its own treestruct for a `ConstraintError`, mark the error as
rendered (or exit 2 directly), so the top-level handler skips its json + argv dump for it. one
test: the halt's stderr holds the header once and no `[args]` line.

## .why it is not done in this round

the render is rhachet's; this repo only snaps it. to trim the tail in this repo's snapshot would
make the test's claim — "as a human meets it" — false, since a human meets the tail too.
