## .the gap, precisely

- **notice retry** — `sayFailNotice` in `setPhoneDeliveriesOfTree.ts` says a failure notice once;
  if the sender sits at a modal, the notice is only logged. the record holds the failure; nobody
  is told
- **one wedged say** — the tick says texts in turn; one say that hangs to its 3-minute timeout
  delays every other clone's text in the tree
- **per-tick cost** — each tick reads and validates every record in every mailbox, and the idle
  check scans them again; mailboxes are never pruned, so the cost grows with history
- **`phone.text get` unbounded** — it prints every text in full, forever; no `--limit`, no
  `--with <peer>`
- **P11 stale flag** — the vision's `stale` tag on a long-QUEUED text in `get` is not built; the
  `daemon: DOWN` line (i006) covers the silent-stall half of it
- **layer placement** — `genPhoneRefusal` renders a vibe line and a tree into the `ConstraintError`
  a deep domain op throws; `PhoneMailboxEntry` and `PhoneMailboxClaimAct` sit in the dao; a few
  domain types (`PhoneReach`, `PhoneRefusal`, `PhoneTreeNode`) sit in operation files
- **one lease, two copies** (i007 r011 nitpick 1) — `daoPhoneDaemon.gen` and
  `daoPhoneMailbox.genClaim` each create a file exclusively, write a pid, check `isPidAlive`, and
  remove a stale one only if unchanged. both trust a bare pid, so a reused pid reads LIVE: a dead
  daemon whose pid was reused reports FOUND while naught delivers. the temp-plus-rename write
  repeats in the mailbox and contacts daos
- **daemon upgrade + env** (i009 r011 nitpick 4) — the lock now names `protocol: 1`, but a set
  that finds a live daemon of another protocol does not yet replace it; and the detached daemon
  inherits the full env of the clone that started it

## .the shape of the fix

- notice: a `notice` record per sender with its own QUEUED status, carried by the same tick and
  the same claim protocol as a text, so a busy sender gets it once its modal clears
- wedged say: a per-peer say with a short timeout, and a wait on a timeout, so the tick moves on
- per-tick cost: a queue index (a dir of symlinks to QUEUED records), so a tick reads only what
  waits; settled records stay where they are as the audit trail
- get: `--limit N` (default the last 20) and `--with <address>`; the full thread stays one flag away
- stale: a `queuedSince` day stamp on a QUEUED record (the mailbox is under `.agent/.cache`, never
  tracked), and `get` tags any text QUEUED past a bound
- layers: a structured `PhoneRefusal` (headline + nodes) thrown by the domain, rendered to text by
  `withPhoneRefusalVibe` at the contract; move the domain types to `domain.objects/phone/`
- lease: extract `infra/fs/genPidLease` (the claim passes an act, the daemon lock none) that
  records the pid and the process start time (`/proc/<pid>/stat` field 22 on linux), so a reused
  pid reads stale; extract `infra/fs/setFileAtomic` for the temp-plus-rename write. clamp: a lease
  file whose pid is alive but whose start time differs is reclaimed
- daemon upgrade: the release that first bumps `PHONE_DAEMON_PROTOCOL` makes `phone.daemon set`
  stop a live daemon of another protocol (`del`, then start) — owed then, since one protocol
  exists today. env: an allowlist for the detached spawn, built from what `rhx clone say`
  measurably reads, never a guess, so a delivery never fails on an env var the list dropped

## .why it is not done in this round

dirty: each item adds a record kind, a flag, an index, or a cross-layer move, with tests, and the
round is the director's last before release. none loses a text: each is a delay, a cost, or a
placement. fulcrum F22 records the call.
