# 🌙 dream: the phone's grove leg — push, pull, and relay across groves

kind: feature · owner: ehmpathy/rhachet-roles-bhuild · caught 2026-10-21

## .the cue that fired

the vision's outputs for "across groves" (push over a live tunnel, a pull by the tunnel holder, a
relay between two groves, a refusal when no grove tunnels to both). route
`v2026_10_21.feat-phone-text` shipped same-grove reach only (fulcrum F13).

## .the gap, precisely

- `setPhoneText.assertPhonePeerAdmitted` refuses any peer whose grove is not this grove, exit 2,
  `no river to that grove yet`
- `setPhoneDeliveriesOfTree` leaves a cross-grove QUEUED text with reason
  `grove leg not in this delivery` (no such text can be written today, so the branch is latent)
- `getPhoneContextFromEnv` names this grove `PHONE_GROVE` else the hostname (F14); a grove boot
  does not export `PHONE_GROVE` yet

## .the shape of the fix

- **push**: in the daemon, for a peer on a grove with a live tunnel, run
  `ssh <grove-alias> 'cd <tree dir> && rhx clone say @:<clone> --what @stdin --output json'` with the
  said text on stdin (the `git.grove.send --file` discipline), then write the `in` copy over the same
  ssh, content on stdin, never parsed. read the tunnel state the way `git.grove.list` probes it
- **pull**: each tick, for each grove with a live tunnel, read the remote trees' mailboxes for QUEUED
  texts addressed to a tree on this grove; say each locally, write the local `in` copy, mark the
  remote `out` copy DELIVERED. a remote send writes reason `awaits pull from <grove>`
- **relay**: grove to grove rides the grove that tunnels to both; when none does, refuse at send
  with the vision's `no route from <a> to <b>` refusal
- **name**: grove boots export `PHONE_GROVE=<registry name>`
- tunnel down → QUEUED, reason `grove unreached`, and `phone.text get` names `rhx git.grove.wake <grove>`

## .why it is not done in this round

dirt, not size alone: three mechanisms with their own failure modes, none provable on this box (no
tunnel open from here), under a commander EOD. the same-grove path ships proven; this rides next.
fulcrum F13 records the call.
