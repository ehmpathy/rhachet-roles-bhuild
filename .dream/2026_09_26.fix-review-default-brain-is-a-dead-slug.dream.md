# 🌙 dream: `rhx review`'s DEFAULT brain is a slug the registry no longer has

| field | value |
|---|---|
| kind | **reseed** — the fix is one line in `ehmpathy/rhachet-roles-bhrain` |
| owner | whoever owns `rhachet-roles-bhrain/src/contract/cli/review.ts` |
| caught | 2026-09-26 |
| reach | 🔴 **every review lane in every route that passes no `--brain`** |

## .the cue that fired

nine peer lanes, repaired to `--focus pull` after four rounds of context overflow, malfunctioned a
**fifth** round — on an error no prior round had shown:

```
BrainChoiceNotFoundError: brain not found: fireworks/deepseek/v4-flash
```

⇒ the overflow had been **hiding** this. `push` mode assembles the whole prompt and throws on size
*before* it ever looks a brain up, so four rounds of lanes died upstream of the real defect. the
`pull` repair was correct and it moved the failure one step later, which is where the next defect
was already sat.

🔴 **a quiet defect behind a loud one.** the loud one was not a red herring — it was a lid.

## .the gap, precisely

`review.js:37-40`:

```js
/**
 * .what = default brain for review skill
 * .why = fireworks/deepseek/v4-flash is better, cheaper, and faster for code review
 */
const DEFAULT_BRAIN = 'fireworks/deepseek/v4-flash';
```

the live registry holds no such slug. the nearest is **`fireworks/deepseek/flash/v4.1`** — so the
brain naming convention moved from `<vendor>/<family>/<variant>-<tier>` to
`<vendor>/<family>/<tier>/<variant>`, and this constant did not follow.

### 🔴 the help text prints the dead default and the live list in ONE breath

```
--brain <slug>      brain to use for review (default: fireworks/deepseek/v4-flash)

🔭 available brains
   ├── ○ fireworks/deepseek/pro/v4
   ├── ○ fireworks/deepseek/flash/v4.1
   …
```

⇒ `printHelp` interpolates `${DEFAULT_BRAIN}` and then calls `getAvailableBrains()` for the list
beneath it. **the two lines come from different sources and no check compares them.** a reader who
scans the help has the contradiction on screen and no reason to look for it.

⚠️ this is `rule.require.timeless-comments`' neighbour and worse: the `.why` block above the
constant is a **claim about a brain that does not exist**, so the comment reads as a considered
choice and is a fossil.

## .what it costs

| who | what happens |
|---|---|
| any `rhx review` lane with no `--brain` | 💥 `malfunction`, before one line is read |
| the guard around it | scores an unreadable verdict as **one blocker** (`contract.reviewer-output`), so the stone gates |
| the driver | owes a `.taken` per lane for a concern no reviewer ever raised |

⇒ and the failure is **silent as to its cause from the route's view**: the guard reports
`malfunction 💥` with a stack trace, so a driver who does not read stderr in full sees nine dark
lanes and reaches for the bind again — which is the four-round stall this route already paid once.

## .the shape of the fix

### half 1 — repoint the constant

one line. `fireworks/deepseek/flash/v4.1` is the successor by name.

⚠️ **but the `.why` above it must be re-earned, not carried over.** *"better, cheaper, and faster
for code review"* was measured against a brain that is gone; `v4.1`'s numbers are not `v4-flash`'s.
⇒ either re-measure, or downgrade the comment to name what it actually is: the cheapest live
deepseek.

### 🔴 half 2 — the default cannot serve `--focus pull` at all, whatever its slug

`stepReview.js:196-201` refuses an atom in `pull` mode:

```js
const choiceIsRepl = isBrainRepl(context.brain.brain.choice);
if (input.focus === 'pull' && !choiceIsRepl)
  throw new BadRequestError(`focus 'pull' requires a brain with tool use (BrainRepl) …`)
```

and every `fireworks/*` and `xai/*` slug is an **atom**. the repl set is exactly
`anthropic/claude/code{,/haiku,/sonnet,/opus}`.

⇒ so **one default cannot serve both focus modes.** the honest repair is a default *per focus*:

| focus | needs | a live pick |
|---|---|---|
| `push` (default) | any atom; cheap is fine | `fireworks/deepseek/flash/v4.1` |
| `pull` | a **repl**, mandatory | `anthropic/claude/code/sonnet` |

a single constant forces every `pull` caller to pass `--brain`, and the help text is silent about
it — so the first `pull` user of any route hits a hard error the docs never warned of.

### half 3 — the clamp, so neither half rots again

a test that asserts `DEFAULT_BRAIN` (and any per-focus default) is present in
`getAvailableBrains()`. it is nearly free, it goes **red today**, and it turns a dead default from
a five-round mystery into a failed gate.

🟡 the same clamp shape is owed for the `--focus pull` ⇒ repl constraint: a default that cannot
satisfy its own mode is the defect half 2 names, and a clamp can check that pairing statically.

## .why it is not done in this round

**not SAFE** — the constant is the default for every review lane in the ecosystem. to repoint it is
to change which model grades every route that never chose one, and
`lesson.brain-selection-for-review` measured real quality divergence between brains (`grok/4-fast`
flagged a rule's own **examples** as violations; `gpt/4o` hallucinated text). a blind swap trades a
loud malfunction for quiet bad verdicts, which is the worse failure.

**not CLEAN** — the code is in `rhachet-roles-bhrain`, so no part of it lands in this repo's diff.

⇒ so it defers as a **reseed**. the route's own guard is repaired in place — all nine lanes now
carry `--brain anthropic/claude/code/sonnet` — because that file IS this route's diff. **the
instance is fixed; the CLASS is what defers.**

## .the pick, and its honest bound

`anthropic/claude/code/sonnet` satisfies both live constraints, and no other slug does:

| constraint | what it eliminates |
|---|---|
| a REPL, for `pull` | every atom — incl. **both** brains the lesson blesses |
| reviews well | the lesson's measured failures |

⚠️ **the lesson graded `claude/sonnet` as an ATOM, never sonnet in a repl.** a repl adds a tool
loop, so its failure modes are not the ones measured. this is the closest pick the extant evidence
supports and **not a tested one** — recorded here so the next reader does not mistake a reasoned
choice for a measured one.
