# 🌙 dream: teesafe keeps every byte it reads, the final newline included

kind: reseed · owner: ehmpathy/rhachet-roles-ehmpathy (role=mechanic, skill=teesafe) · caught 2026-11-24

## .the cue that fired

a byte-exact copy of four pioneer files (`cat <src> | rhx teesafe <dst>`) diffed as `\ No newline at end of file` on every file; a follow-up `printf '\n' | rhx teesafe <dst> --append` left the file unchanged.

## .the gap, precisely

teesafe drops the final newline(s) of its stdin, in write and append modes alike. a paved copy path that silently alters bytes defeats any `diff`-proved promotion, and the lone-newline append is a no-op that reports success.

## .the shape of the fix

write stdin verbatim (no `$(...)` capture, which strips end newlines; stream via `cat > "$dst"` or `tee`). clamp: a test that tees `a\n` and `a\n\n` and asserts the file bytes equal the input, red before, green after.

## .why it is not done in this round

the skill belongs to another repo; this round restored the last byte by hand and proved the copies with `diff -r`.
