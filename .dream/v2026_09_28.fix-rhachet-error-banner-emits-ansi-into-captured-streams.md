## 🔴 .the gap, precisely

the escapes color an error on a terminal — correct and useful. the moment stdout is **captured**
they become literal `[0m` / `[31m` text:

| where it lands | the cost |
|---|---|
| a jest snapshot | a human reads a snapshot to vibecheck a render; a control code buried in it is noise they must read past (`rule.forbid.snapshot-visual-blemishes`) |
| a ci log | the same, on every failed run |
| `rhx … \| tee build.log` | a log file that no plain-text tool greps cleanly |

⚠️ and the **doubled** form is the tell that this is a decoration, not a render: `[0m[31m` resets,
then re-colors, on every line — a wrapper applied per-line to text that was already complete.

---

## .the shape of the fix

in whatever wraps a skill's error output in red, gate the escape on the stream:

```ts
const color = Boolean(process.stderr.isTTY);   // or process.stdout, per the stream it writes
const red = color ? '\x1b[31m' : '';
const reset = color ? '\x1b[0m' : '';
```

this is the identical shape the three in-tree repairs took, so the pattern is already proven
against a live acceptance suite here.

⚠️ what must NOT happen: a strip of the escapes at the **capture** boundary instead — a
`.replace(/\x1b\[[0-9;]*m/g, '')` in the test helper. it would clean the snapshot and leave every
pipe and ci log exactly as polluted, and worse: it would **hide** the next renderer that emits
color it should not. the defect is at the emitter (`rule.forbid.failhide`).

---

## .why it is not done in this round

**owner.** the banner is not in this tree:

```sh
rhx grepsafe --pattern 'blocked by constraints' --glob 'src/**/*'
# → 6 matches, ALL of them captured .log fixtures under
#   src/domain.roles/supervisor/skills/work/.test/.assets/ — never an emitter
```

the string `🪨 run solid skill repo=…/skill=…` is the **rhachet runner's** header, printed before
this package's code is reached at all. a tree adopts only what is scoped to itself
(`rule.always.catch-dreams-for-followups`), so this is caught as a **reseed** rather than fixed
here.

## .the residue this leaves, deliberately

27 lines across two snapshots keep their escapes until the reseed lands. that is the honest state:
the noise names a real defect in a dependency and stays visible, rather than a strip that would
make the snapshot pretty and the pipe no cleaner.
