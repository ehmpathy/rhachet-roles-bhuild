## 🔴 .the shape of the fix — and the one site to leave alone

### `git.checkout.sh` — a flat guard chain

the 4-branch create/checkout/pull matrix collapses to early exits:

```bash
# create a fresh branch from a base
if [[ "$create" == true ]]; then
  git checkout "$from"; git pull; git checkout -b "$branch"
  echo "created branch: $branch (from $from)"
  exit 0
fi

# otherwise, check out the extant branch
git checkout "$branch"

# and pull only when asked
if [[ "$pull" != true ]]; then echo "checked out: $branch"; exit 0; fi
git pull
echo "checked out and pulled: $branch"
```

⚠️ `exit 0` vs `return 0` depends on whether the block sits in a function — check before the edit.

### 🔴 `duct.send.sh:356` — DO NOT flatten without a clamp first

the branch carries its own warn:

```bash
else
  # ⚠️ BOTH HALVES or the flag is inert
```

it encodes a two-flag invariant (`--anyway` × `--await`) whose halves must move together. an
early-return rewrite of a flag-pair invariant is the exact shape that ships a **silently inert flag**,
and `duct.send` is on the path of every crew dispatch.

⇒ **owed first: a clamp over the 2×2 flag matrix** (`--anyway` × `--await`, all four combinations,
asserted on the emitted command). only then is the flatten safe.
