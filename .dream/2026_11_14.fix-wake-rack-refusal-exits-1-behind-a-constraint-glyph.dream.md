## .the cue that fired

```

  fix: the rack named it above — read that line, not this one.
```

and rhachet wraps the exit in `💥 failed with an error`.

## .the gap, precisely
an absent or locked credential is the caller's to fix, so `rule.require.exit-code-semantics` owes
exit 2. the arm prints `✋` (the caller-fixes glyph) and exits 1 (system fixes), so glyph and code
disagree, and an automation that retries on 1 retries a wall. the header also opens with a bare
`✋ the rack…`, not `✋ ConstraintError:` (`rule.require.qualified-error-headers`).

## .the shape of the fix
- the keyrack leg exits 2, header `✋ ConstraintError: the rack did not hand over AWS_PROFILE …`
- `wake.tailnet [case3][t0]` pins exit 2; its snapshot follows
- audit each caller of `git.grove.wake` (crew boot, heal) for a branch on exit 1 before the flip

## .why it is not done in this round
the exit 1 is extant on main and vision case=5 promised to keep it; the flip changes a contract
other verbs may branch on, so it fails CLEAN for a reach-over-tailnet pr.
