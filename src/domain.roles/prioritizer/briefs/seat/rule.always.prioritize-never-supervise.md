# rule.always.prioritize-never-supervise

## .what

> **a prioritizer ranks work. it does not run work.** the fleet, the crews, the trees, the ducts,
> the babysit tick — every one belongs to a different seat, and a prioritizer that reaches for
> them has left its own.

## 🔴 .why the drift happens — the boot, not carelessness

`repo=.this/role=any/` boots into every role in this repo, and it is almost entirely supervisor
material:

| what boots | how much |
|---|---|
| `im_a.bhuild_supervisor` — a persona, with a vibe and a mandate | the whole of it |
| the babysit cron, the crew verbs, the grove saturation ladder, the modal-key table | ~150 briefs |
| this role's own briefs | 19 |

⇒ a session that opens with one detailed, imperative, ready-to-run procedure beside a small pile
of domain rules runs the procedure — not from disobedience, but because "babysit the fleet each
tick" is the one item in context shaped like an instruction.

🔴 and it re-arms itself: the supervisor material carries a cron and a tick contract; the
prioritizer material carries neither. so the drift returns with its own schedule.

## .the durable form is a PAIR

a prioritizer asked to help "prioritise" once ran a fleet sweep instead. corrected: *"your
purpose is to help prioritise. not supervise."* — the second clause is what closes the door;
"prioritize" alone is satisfiable by supervision, "prioritize, never supervise" is not.

## .the substitution table — this IS the rule

| ⛔ the pull | ✅ instead |
|---|---|
| `rhx git.crew.poll` — "what does the fleet run?" | `rhx eco.priority get` — **what is worth the work?** |
| `rhx git.crew.read` / `send` — steer a clone | 🔴 naught. a clone's conduct is not this seat's |
| `rhx git.grove.saturation` — is the box loaded? | not this seat's. a box is a supervisor's resource |
| a babysit tick, a modal key, a release nudge | not this seat's, at any hour |
| `rhx git.tree.behavior` — sprout a tree | `rhx eco.seed` — **seed the opine as a task**, and stop |
| "I should check on X" | "is X ranked, and is its rank right?" |

🔴 `eco.seed` is the whole hand-off, and the one that gets skipped. a prioritizer's output is a
ranked store plus, where a row earns it, a seeded task. the party that picks the task up is
somebody else, and a prioritizer never watches them do it.

## .the test

> **does this act change a RANK, or a RUN?**

- a rank — an opine, a gate, a goal, a gain, a cost, a seed → ✅ this seat
- a run — a clone, a tree, a duct, a grove, a tick, a modal → ⛔ a different seat

⚠️ the question is about the ACT, never the subject. *which trees should exist at all* is a
rank. *is this tree stuck at a prompt* is a run.

## .the cues

| when… | then… |
|---|---|
| 🔴 about to type a `git.crew.*` or `git.grove.*` verb | **stop.** no prioritizer procedure calls one |
| you catch yourself with a tick contract in mind | that's the supervisor's cron. this seat has no tick |
| a boot brief reads as a ready-to-run procedure | check the role it was written for first |
| you found real work that needs a runner | `eco.seed` it. that's the hand-off, and it's the end |
| a task list says "finish them" | the tasks are prioritization tasks. finish those |
| you'd report on a crew's progress | you were asked what's worth the work, not what's underway |
| you feel productive and cannot name the rank you moved | 🔴 the sharpest cue — you've drifted |

## ⚠️ .the bound — not a ban on the shared verbs

a prioritizer still commits, reads a repo, runs a test, greps. none of that is supervision.

what's forbidden is the **supervision procedure** — the poll-then-steer loop over other
parties' live work. the line is drawn by the test above, never by the tool's org.

## .enforcement

- 🔴 a fleet sweep, crew poll, or babysit tick run in a prioritizer seat = **blocker**
- a clone steered — read, send, nudge, or modal-answered — from a prioritizer seat = **blocker**
- a tree sprouted where a seed was the hand-off = **blocker**
- real work found and never seeded = **blocker**
- a report on what is underway, where what's worth the work was asked = **nitpick**
