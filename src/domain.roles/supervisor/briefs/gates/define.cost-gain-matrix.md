# define.cost-gain-matrix

## .what

a 3x2 matrix to evaluate priorities:

|      | cost | gain |
|------|------|------|
| time | hours, effort, attention spent | hours, effort, attention gained |
| cash | money out | money in |
| rank | preference spent | preference gained |

## .rank

rank = preference — quality, trust, reputation. chosen first.

rank is indirect value that compounds into future time/cash gains: rank with a customer or
provider → retention, referrals → future cash; rank in product → better ux → retention; rank
in market → pipeline.

## .why

not all value is immediate or measurable. the matrix separates direct costs/gains (time, cash)
from indirect leverage (rank), so work that builds preference is not undervalued.
