# rule.always.seed-when-the-grove-is-saturated

## .what

when a grove is 🔴 saturated and your own levers are spent, the work does not stop — it
changes verb. a sprout becomes a seed.

```
🔴 grove + 0 fellable  ⇒  do NOT sprout  ⇒  SEED it, and say so
```

the wish is authored either way. saturation decides only whether a tree boots now or the work
waits in a queue.

## .why — a halt with no alternative deletes the work

`rule.require.bound-grove-concurrency-by-saturation` says halt sprouts on a 🔴 grove. a halt
alone leaves the work as spoken intent, which evaporates with the round
(`rule.always.catch-dreams-for-followups`) — diagnosis done, levers spent, and the work still
goes unrecorded.

## .the ladder — spend your own levers BEFORE you seed

a seed answers a genuinely full grove, never a grove you have not measured.

1. `rhx git.grove.saturation` — read the shared resource first
2. `rhx git.crew.poll --fellable` — fell what has merged (yours)
3. `rhx git.grove.prune <grove> --process <p>` — plan it; ⚠️ apply is the human's where the
   process could hold a human's unsaved work
4. 🔴 seed the wish — the work is recorded, the boot waits
5. surface the provision levers with exact commands, and stop

## .what a seed owes, exactly

the same wish a sprout would have taken — `rule.require.behaviors-over-adhoc` does not relax
because the boot is deferred: authored into
`src/stream/$Q/$date.dispatch.repo=$repo.behavior=$slug.wish.md`, outcome-shaped
(`rule.forbid.prescribe-how-on-dispatch`), sized (`rule.require.confirm-behavior-size-above-nano`).
then pushed as a radio task (`rhx radio.task.push`), if radio permits.

### the radio gate does NOT excuse the record

`radio.uses` can be globally blocked by the human — that blocks the push, never the authorship.

| radio | what you do |
|---|---|
| allowed | author the wish, push it, name the issue |
| 🔴 blocked | author the wish anyway — the persisted file IS the queue entry |

the gate governs a transport; the stream is local and needs no permission.

## .the cues

| when… | then… |
|---|---|
| a human says "sprout" and the grove reads 🔴 | 🔴 seed it — the word authorized the WORK; the grove decides the VERB |
| you are about to report saturation with no wish authored | stop; the wish is cheap and owed |
| `--fellable` returns 0 on a 🔴 grove | provision is the human's; the seed is still yours |
| radio is blocked | author the wish regardless — the file is the queue |
| a second grove is asleep | surface the wake command; never wake it yourself (a spend) |
| the grove clears later | the seed is already written — boot it, no re-draft |

## .the bound

does not license a seed where a sprout would have worked — a 🟢/🟡 grove takes the sprout. the
trigger is a measured 🔴 plus a spent ladder, never a hunch about load. a seed is not a
workaround for provision — it keeps the work alive while the human decides
(`rule.forbid.self-grant-human-gates`).

## .enforcement

- a sprout booted onto a measured 🔴 grove, no human override = **blocker**
- a saturation halt reported with no wish authored = **blocker** (the work was deleted, read
  as diligence)
- a wish left unwritten because `radio.uses` is blocked = **blocker** (the gate is a transport)
- a seed where the grove was 🟢/🟡, or `--fellable` was never run = **blocker** (unspent lever)
- a second grove woken by the supervisor rather than surfaced = **blocker**
