# case=008 — a `case=N` demo is blocked for a stale audience

> **who** — a driver clone at `1.vision`, seventeen rounds past the split that broke its header
> **came for** — to pass the experience-coverage gate with its case demos intact
>
> cell — `actor=driver · lens=audience · feel=sharp · care=alterpath`
> — *(**fallback:** a reader infers the actor from prose voice, the status quo. `cost` ≈ 0, so it is
> workable at any frequency. demoed anyway: this route's own headers were 0-for-12 before the rule,
> which is the evidence the gate is worth its place)*

## the narrative

🟡 **this narrative reports the state BEFORE #346 landed on this route.** the check now returns 0
blockers over the same twelve files — the yield's *"all 12 `case=N` headers declare `who` +
`came for`"* is the after. what follows is the before, and it is the evidence the gate earns its
place.

before the rule, i had twelve `case=N` demos. **eleven of them named no human at all.** a
representative header:

```
> cells 14 + 15 + 16 · one adoption seam, three points of view
> cell 16 — wire the hooks · feel happy · care critipath
```

it named three points of view and identified not one of them.

the twelfth was worse, not better: `case=009` declared its audience as **cell 18**. cell 18 had been
split three rounds earlier, precisely because it conflated adopter-goal with filesystem-state; the
file demoed cell 26. a header that names a cell identity which no longer exists had survived
seventeen rounds unflagged, because no reviewer reads a coordinate as a claim about a human.

🟡 **so the compliant set was empty — 0 of 12.** not one header named a human, and the one that
appeared to (`case=009`) named a coordinate. the audience arrived nowhere by design, and where it
appeared to arrive it was an accident of which axis a cell sat on.

the audience check catches both in one pass, because a declared field is a grep:

```
🔴 12 blockers — declared-experience-audience
   ├─ case=001..008,010..012 — no declared actor                        (11 files)
   │     fix: add `> **who** — <a person or role>` to the header
   └─ case=009 — declared actor is a cell coordinate ("cell 18")    (1 file)
         a coordinate goes stale the next time the matrix moves. it already has.
         fix: name the human — e.g. "kai, a consumer who upgraded the package"
```

**12 = 11 + 1**, and the twelve were every case file on the route — the check found no header
compliant. i then named twelve humans. the exercise itself split one case, because once i wrote
`who` + `came for` i could see that case=007 served two goals and was therefore two experiences.

⇒ **that repair is what the current files carry.** re-run the same check today and it returns 0
blockers over the same glob, which is the `12 of 12` the yield reports.

## the demo

```gherkin
given a 1.vision BEFORE #346 landed, with twelve case=N demos
  and eleven headers carry only axis coordinates and no actor
  and case=009 declares its audience as "cell 18", a cell that was split three rounds ago

[t0] the audience check runs over $route/1.vision.yield.appendix.experience.case=[0-9]*.md
  when it greps each header for a declared `who` and a declared `came for`
  then it raises 11 blockers for an absent actor
   and 1 blocker for an actor declared as a cell coordinate
   and 12 blockers in total, across all 12 case files
   and each blocker names the concrete fix

[t1] the driver declares an actor and a goal per case
  when it writes `> **who** — a person or role` and `> **came for** — the goal`
  then every case names a human, or names `system` where the actor is a cron or a CI runner
   and no case names a cell coordinate as its audience

[t2] the declaration surfaces a conflated cell
  when the driver writes `came for` on case=007 and finds it serves two distinct goals
  then case=007 is split into two cases, per "the same actor with two goals is two experiences"
   and the matrix moves, and every header stays true because none of them names a coordinate
```

## what this proves

- **a declared field is checkable; a prose voice is not.** the extant rule grades whether the
  narrative *reads* in an actor's voice — a judgment call, graded inconsistently across rounds. this
  grades whether the artifact *states* its actor, which is a grep.
- 🟡 **`[t2]` is the second-order win and it is the reason the field beats the voice.** a named actor
  survives a matrix move; a coordinate does not. and the act of the declaration forces the goal
  question, which is exactly the defect that caused the original split.
- `system` stays a legitimate value. the rule demands the field be *answered*, never that a felt
  human be invented to fill it.
