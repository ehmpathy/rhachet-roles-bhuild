# F12 — the vision evidence file: `groundage` or `groundwork`

**rework** = clean · **status** = **closed — the coinage is dropped** · **confidence** = 89%

## the fork

the emit contract i added to `1.vision.stone` named a new artifact **`1.vision.groundage.md`** — a
word i coined mid-drive, and shipped in a template, with no choice record.

`rule.require.enumerate-before-you-name` says list every instance the word must cover **first**, then
pick the word. i had picked first. so the enumeration was run late, against the file that already
existed.

## the enumeration — four rows the word must cover, three neighbours it must exclude

| # | the instance | `evidence` | `citations` | `appendix` | `research` | `groundwork` |
|---|--------------|:---:|:---:|:---:|:---:|:---:|
| 1 | external sources read (the twelve issue bodies, bhrain's `review.ts`) | ✅ | ✅ | ✅ | ✅ | ✅ |
| 2 | 16 internal claims, each with its verifying path | ✅ | ✅ | ✅ | ✅ | ✅ |
| 3 | the three load-central finds — arguments quoted from source | ✅ | 🔴 an argument is no citation | ✅ | ✅ | ✅ |
| 4 | 🔴 the assumption triage, **including `[research] — unverified`** | 🔴 the *absence* of evidence | 🔴 | ✅ | ✅ | ✅ |
| — | *neighbour:* `1.vision.yield.appendix.experience.dimensions.md` | — | — | 🔴 covers it | ✅ excludes | ✅ excludes |
| — | *neighbour:* stage `3.1.*` — 14 `research.*` stones | — | — | 🔴 | 🔴 **collides** | ✅ excludes |
| — | *neighbour:* any section ejected from a yield | — | — | 🔴 covers all | ✅ | ✅ excludes |

**row 4 is what broke the two obvious words.** the file's whole point, per the stone's own warn line,
is that *"a bare `i checked X` with no path is worth less than an honest `[research] — unverified`"*.
a file named `evidence` that holds a declared non-verification lies about its contents.

**the stage collision is what broke `research`.** `3.1.*` is a whole stage of 14 research stones, and
`1.vision.stone` explicitly distances itself from it — *"not exhaustive research"*. to reuse the word
would be one word for two concepts, which is `rule.forbid.domain-term-ambiguity`.

⇒ `groundwork` covers all four rows and excludes all three neighbours.

## the verdict: the coinage is dropped

🔴 **`groundwork` is already canonical, and by a wide margin:**

| site | the use |
|------|---------|
| `1.vision.guard.light:25` · `1.vision.guard.heavy:25` | *"check the groundwork section:"* |
| `1.vision.stone:93` | `## groundwork` — the section heading itself |
| `.behavior/v2026_05_27.fix-radio-push/1.vision.yield.md:74` | `## groundwork` — a prior shipped route |

**i coined `groundage` four lines above the `## groundwork` heading, in the same file.** git confirms
it: `git log -S groundage` on the stone returns no commit, so it never existed before this drive.

🟡 **and it is not a free coinage — `groundage` is a real (obscure) english word**: a port fee for
the ground a vessel occupies. an unrelated sense, which is the `hazard` failure (F9) at lower stakes.

⇒ `groundage` covers exactly the set `groundwork` covers, so it discriminates no case the extant word
misses. per the rule, it has not earned its coinage. **renamed everywhere; zero occurrences remain.**

⇒ **no term cluster is owed**, because no coinage survives. this row is the record.

## the bonus the rename bought

both vision guards already instructed the reviewer to *"check the groundwork section:"* while the
stone emitted a file called `groundage`. the guard's instruction and the emitted filename **now
agree**, where before a reviewer was pointed at a section name that matched no artifact.

## why 89% and not higher

**one distinction i considered and rejected**: `groundwork` reads as the *activity* ("do the
groundwork"), `groundage` as the *artifact*. that split is real in principle.

i rejected it because **no other row of the emit contract splits activity from artifact** — `## the
experiences` emits `1.vision.yield.appendix.experience.*`, one word for both. a split with no precedent, invented
for one row, is the tidiness smell rather than a distinction the domain has.

⇒ if the wisher wants the artifact/activity split, it is **clean** rework — but it should then apply
to every row of the contract, not to this one alone.
