# case=011 — an authored dispatch lands route-local

> **who** — a driver clone mid-route, which has just found a defect outside its wish
> **came for** — to hand the defect off over the radio without a widen of its own scope
>
> cell — `actor=driver · lens=dispatch · feel=happy · care=alterpath`
> — *(**fallback:** the lint below. a misplaced dispatch is caught rather than absorbed, so the
> happy path's break is recoverable. demoed anyway, since it is the placement the lens exists for)*
> plus `actor=driver · lens=dispatch · feel=sharp · care=critipath` — **two sharp edges, two steps**:
> `[t1]` the leak into `.agent/**/briefs/` that **INV-1** bars, and `[t2]` the dispatch with no
> bound route. `[t1]` is the one that makes this cell a critipath; `[t2]` is the one the convention
> must answer in prose, since F7 leaves no mechanism to answer it with a throw.

## the narrative

i find a defect that is real and is not mine. the wish bounds me, so i dispatch it rather than fix
it. i author the task text and push it over the radio.

the durable record is the github issue the push creates — the channel is the source of truth. the
local `.[task].md` is merely the text i sent.

before, i had to decide where that text lived **with no rule and no lint in the repo to guide me**,
so i copied the nearest precedent: a prior session had written one into
`.agent/repo=.this/role=any/briefs/`. so i wrote mine there too, and the next clone copied me. three
dispatches accumulated in a dir reserved for durable, reusable domain knowledge that boots into
**every** session's context — each one a one-shot note that pollutes the boot of every future
session, and drifted from the route that motivated it.

now a howto names the home before i reach for a precedent, and a lint catches me if i reach anyway.
i write it to `$route/.dispatch/dispatch.$target.$slug.[task].md` — the same route dir that already
holds `accrue/`, `review/`, and `.fulcrums/`, so the dispatch is born, held, and cleaned up with the
route that produced it.

🟡 **the push does not write it for me** (F7, ruled convention-only). so the guard is the pair —
the howto that states the home, and the lint that blocks the leak — rather than a mechanism that
removes the choice. what failed before was the **absence** of both, not a rule i forgot.

## the demo

```gherkin
given a driver that has found a defect outside its wish's bounds
  and a route bound to the current branch — except at [t2], which drops that bind

[t0] the driver pushes a dispatch over the radio
  when it runs radio.task.push with the task text
  then the github issue is created — the durable record
   and the howto names $route/.dispatch/dispatch.$target.$slug.[task].md as the home
   and the driver writes the source text there, rather than at a copied precedent

[t1] THIS driver's dispatch leaks into the shared briefs
  when a dispatch.*.[task].md under .agent/**/briefs/ is attributable to the bound route
  then it is flagged as a blocker
   and the fix names the exact mvsafe (the repo-safe file move, rhx mvsafe --from … --into …)
       into $route/.dispatch/
   and a durable lesson inside it is distilled separately into a real brief
   # an UNATTRIBUTABLE dispatch takes the other branch — see case=012

[t2] a dispatch is authored with no bound route
  when the driver is on a branch with no route bind, so $route has no value
  then the howto names the fallback outright, rather than leave the driver to guess
   and the lint does not demand a $route/.dispatch/ that cannot exist
   and .agent/**/briefs/ is barred here too — INV-1 holds with or without a route
```

## what this proves

- the convention belongs upstream. bhuild owns both halves — the dispatcher role that pushes,
  and the behaver role that defines `$route`. taught once here, every downstream repo inherits it
  with no per-repo rework.
- 🟡 **`[t2]` is the sharp edge, and it outlived the branch that framed it.** i first wrote it as a
  mechanism's throw — *"a push that writes a file must know where"*. F7 ruled convention-only, and
  the edge stayed: a dispatch authored off-route still has no obvious home, and a howto that
  omits the fallback leaves the driver to guess exactly as before. a silent guess is how the shared
  briefs got polluted in the first place, so the prose must answer where the throw would have.
- the boundary is stated plainly: a dispatch is never a `briefs/` entry. `briefs/` is durable,
  reusable, boot-loaded knowledge; a dispatch is ephemeral and route-scoped.
- `[t1]` is scoped to a dispatch this route can be shown to own. the lint's glob reaches a
  repo-wide dir, so it also meets files no live route authored. that population takes the other
  branch — `case=012` (`maintainer × dispatch × sharp`).
