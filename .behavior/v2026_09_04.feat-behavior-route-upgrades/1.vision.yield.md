# 1.vision.yield — the twelve queued route upgrades

## the terms this yield uses

- `route` — an ordered set of milestones a driver walks. this one is the dir
  `.behavior/v2026_09_04.feat-behavior-route-upgrades/`, written `$route` in a path
- `stone` — one milestone on a route. it passes once its guard clears; this file is the output of
  the `1.vision` stone
- `guard` — a stone's gate. it runs self reviews first, then peer lanes
- `self slug` — one self-review question the driver must answer before peer lanes run
- `peer lane` — one reviewer the guard runs: one rubric over one set of files, with a budget of rounds
- `yield` · `appendix` — a stone's output file · a support file beside it, named
  `$stage.yield.appendix.$what.md`
- `.taken` — the driver's written answer to a review point
- `fulcrum` — a fork where a small design call tips a large outcome. the driver best-guesses it,
  records it under `$route/.fulcrums/`, and drives on
- `critipath` · `alterpath` — an experience whose break leaves no workable route to the goal · one
  whose break leaves a workable route
- `#NNN` — an issue on `ehmpathy/rhachet-roles-bhuild`, cited as provenance only
- `case=NNN.$slug` — a demo at `1.vision.yield.appendix.experience.case=NNN.$slug.md`

## the sharpest test is falsifiability, not word count

the wisher's steer: cut to the bone, eliminate subversive prose, and a sentence with no disputable
claim said naught. `domain.terms/term=prose.subversive._.choice.reason.md` holds it verbatim.

the extant prose rules cut surplus words. *"this approach is robust and scalable"* passes
`rule.require.brevity` and `rule.forbid.rambles` alike, and asserts none.

⇒ the new rule is `rule.forbid.subversive-prose`. it adopts the wisher's own term rather than a
synonym (`rule.require.ubiqlang`).

🔴 **its test is *"what observation would settle this sentence?"*** — never *"could a reader
disagree?"* the latter grades taste, and a metaphor passes it (*"it took the cheaper of two
doors"*).

the term cluster works the test's two defeaters as rows: a *shallow* sentence asserts none; a
*squishy* one names no state of the world.

### the two shapes, one rule

*shallow* reads as insubstantial; *squishy* reads as unjustifiable. the plain word is the
definition; the short word is the handle.

squishy is the dangerous shape. shallow reads as filler. squishy reads as insight, and it takes the
slot a claim was owed.

three bounds ship inside the rule rather than beside it:

- the squishy sub-test (#358) — substitute the sentence for the mechanism it describes
  - if the reader can no longer act on it, the sentence displaced rather than explained
- the false-positive bound (#360) — the defect is ambiguity, never a rhetorical register
  - a metaphor that accompanies a stated mechanism passes; one that replaces it fails
- terse is not thin — a settleable claim stays, however long it runs
  - the gate can over-fire on content the yield still owes, so it must fail safe — demo
    `case=003.prose-gate-overfires-on-owed-content`

⇒ a wisher steer authorized this rule, not one of the twelve, and a direct steer supersedes the
wish's *do not widen* bound. `1.vision.yield.appendix.groundwork.md` traces it issue by issue.

## offload archaeology; never compress it

terseness has two moves:

- cut — a sentence that asserts no checkable claim. `rule.forbid.subversive-prose` is the mechanism
- move — a real claim that is archaeology: the reads, the citations, the triage
  - the driver never cuts it. the yield cites it by path

so the vision stone declares an emit contract, one file per kind of claim:

| file | holds |
|------|-------|
| `1.vision.yield.md` | the decision, one line of reason each, the open forks |
| `1.vision.yield.appendix.groundwork.md` | the reads that back each claim — every row of its claims table cites a path a reader can re-run |
| `1.vision.yield.appendix.experience.dimensions.md` | the axes, and why they are orthogonal |
| `1.vision.yield.appendix.experience.case=_.md` | the inventory, one bullet per cell |
| `1.vision.yield.appendix.experience.case=NNN.$slug.md` | one demo per critipath |

a claim belongs in exactly one file. `rule.always.yield-the-output-not-the-archaeology` demanded
that layout and never named the paths.

⇒ two gates hold the contract. the self slug `has-ejected-the-archaeology` fires at write time;
`rule.require.archaeology-in-notes` rides the `dense` lanes at review time.

### a lint names the line for the MOVE verdict

`rule.require.archaeology-in-notes` has three verdicts: cut, keep, move.

- only move repairs outside the passage under review, so only move invites an argument
- the `archaeology-of-yields` lint names the file and the line, so the repair becomes an edit
  - it grades place, never prose, so the `dense` lane stays
  - its markers, exemptions, and runtime live at `1.vision.yield.appendix.peer-lanes.md`

⇒ `$route/archive/1.vision.archaeology.md` holds the road this yield ejected: the confidence
trajectories, the retracted claims, the triage mis-files, and one rejected design.

### the `yield.appendix.` infix, and the escape hatch it opens

wisher steer, 2026-09-07: *"that way its clear they were created as part of the yield."* every
support artifact carries the infix, so provenance sits in the name. the infix also buys the glob
lever the scope cut needs. `.agent/repo=.this/role=any/briefs/domain.terms/term=yield.appendix._.choice.reason.md`
holds the divergence from the `$route/appendix/` dir, the sort it protects, and the glob partition.

🟡 **the infix opens a real escape hatch: a driver can move bulk into an ungraded appendix and
satisfy the contract.** so a lane grades the groundwork too. a bare *"i checked X"* with no path is
worth less than an honest *"[research] — unverified"*.

## the experiences

### the walk prunes before it verdicts

wisher steer, 2026-09-11 — *"look for opportunities to prune whole subsets of combinations of
experiences … via forbids, redirects, and guards."*

the extant coverage discipline gives each cell a verdict: demoed, itemized, forbidden, or
impossible. no verdict asks whether the design could delete the cell. so the discipline grades
coverage, and a space of any size satisfies coverage.

🔴 **`rule.always.prune-the-experience-space` adds a pass that runs first, at the subset grain** —
a row, a column, a plane, never a cell. it removes a subset via a guard, a redirect, or a forbid;
the rule holds the levers and their bounds.

⇒ it is the architect's `rule.require.fewer-paths-via-idempotency`, one stage earlier. that rule
collapses branches. this one collapses experiences before a branch exists.

### the walked space

the walk decomposes on `actor × lens × feel`: 4 × 8 × 2 = 64 coordinates. it gives every cell a
verdict — 18 demoed · 47 itemized · 2 impossible · 0 forbidden, 67 cells in all. three
`scouts-honor` coordinates hold two cells each, one per instrument: the peer lane and the self gate.

the collapse kept the space lean. twelve lenses would make `4 × 12 × 2 = 96` coordinates — 40 more
than seven lenses make, and not one a new experience.

two `lane × sweep` cells are guard-lever prunes rather than plain `impossible` cells. a guard-lever
prune names a lever and a cost. the cost: no peer lane at the verification stone grades test
selection, so cicd catches an under-scoped sweep one stage later, or no gate does.

### the critipaths

the walk demos every critipath. all 6 name their own `case=NNN` file, and a grep of the inventory
for a ⭐ bullet with no `case=…md` suffix returns none. the walk also demos 12 alterpaths, for 18.

🔴 **the six critipaths share one property: no workable route survives the break.** the break is
SILENT, or it ACCRUES, or the actor holds NO LEVER. that property makes the verdict checkable. the
other 59 live cells have a workable fallback; the 12 demoed alterpaths show where a gate does not
block.

⇒ one principle sets care on every happy cell: a new gate falls back on the world before it.

- so a new gate's happy cell is an alterpath, unless the status quo it replaces is itself broken
- only `scope` fails that test
  - a lane that renders no verdict blocks passage indefinitely, so it has no "before the gate" to
    fall back on

⇒ `1.vision.yield.appendix.experience.case=_.md` holds the per-cell verdicts and the four
boundary-density ranks.

all 13 demo headers declare `who` + `came for` (`grepsafe` for `came for` over `*case=0*.md`: 13 of
13). this vision dogfoods the audience rule it ships.

## mental model: a linter for judgment, not for syntax

a human would describe it as *"a linter for the parts of a document a linter cannot usually see"*.

| we say | they say |
|--------|----------|
| subversive prose | "words that sound like an answer" |
| critipath / alterpath | "the path that matters" / "the nice-to-have" |
| fulcrum | "a decision i want the boss to make" |
| chronological accretion | "the doc grew a changelog inside itself" |

the closest analogy is the boy-scout rule, inverted. extant reviewers ask *did you leave it
complete?*; these ask *did you leave it small?*

## evaluation

**pros — the rules and the checkers already exist; what this wish adds is their reach.**

- the rubric already exists: `lang.prose/` is published, blocker-graded, and booted into every
  session
- four of the seven changes are template edits with zero new machinery

cons, stated plainly:

1. a blocker-grade prose gate can deadlock a route. the severity split mitigates it: accretion
   blocks, because a checker detects it; density counts against the extant nitpick budget.
2. the density reviewer can destroy signal, because the gate can over-fire on content the yield
   still owes. the fail-safe is the `.taken` escape hatch, plus an explicit false-positive list in
   the rubric.
3. re-init is a findsert — a find-and-insert that leaves an extant file untouched — so extant routes
   silently get no new gate. the repair is a loud report, never a change to findsert itself — demo
   `case=010.reinit-keeps-the-old-guard`.
4. the audience rule fails artifacts that predate it, in any repo that stamps bhuild's templates.
   bhuild cannot count those repos.

⇒ the pit of success: the highest-leverage half costs the least. the self review changes what the
driver writes and carries no halt risk, because the driver answers it rather than argues with it.
