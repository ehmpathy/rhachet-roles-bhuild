🟡 **that the quotes survived is luck, not method.** they survived because each seeded a *term*, and
a term cluster owes a `.reason` file by its own contract. a steer that seeds a rule, a guard, or a
scope decision has no such second home — so the next one lost is lost outright.

survived verbatim in the conversation, so the loss is bounded to the order the asks arrived in.
