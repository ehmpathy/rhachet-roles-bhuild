# S5 — a hand-typed index is zero-padded

## .said

> also, can we have the experience cases be indexed with lpad of 3 0's? e.g., 001, 002, ...

> can we enbrief that and enstone that ?

## .settled

**an ordinal in a filename is zero-padded to width 3**, so lexical order equals numeric order by
construction.

🔴 **a cite, not a coin — and the read found it.** bhrain already declares the width and the reason
at `asStoneGuardCounter.ts`: `COUNTER_WIDTH = 3`, *"the single source of the pad width"*. it is
applied to the guard counters (`i001`, `r001`) and to no `case=` inventory.

⇒ **the split is mechanized vs hand-typed.** bhrain's counters are computed, so the defect is
unreachable there and no rule is owed. a `case=` index is typed by a human, so a rule is the only
enforcement available.

🟡 **the second clause is half the seed.** *"enbrief that and enstone that"* names both artifacts a
settled convention owes: the rule that states it, and the template that makes a driver meet it at
write time. a convention with only one of the two is either an unenforced rule or an unexplained
instruction.
