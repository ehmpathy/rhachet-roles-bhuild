# dispatch → `ehmpathy/rhachet-roles-bhrain` — a brain lane must be able to UNENROLL an entooled rule

> **a rule with a deterministic checker does not belong in a probabilistic lane. it is worse there,
> it costs money there, and it crowds out the rules only a brain can grade.**

`rhx review --rules` takes one glob over an open set and offers no exclusion, so a lane that globs
`rule.*.md` enrolls **every** rule — including the ones bhrain has already entooled.

## .the measurement, and all three columns are one command apart

| property | the brain lane, 9 reports over i015–i022 | the shipped checker, one run |
|---|---|---|
| `forbid.emphasis-noise` | 11 points · named **3 sections in 1 file** at i022 | **122 sections over the bar, across 45 files** |
| `forbid.width-ambiguous-glyphs` | 6 points | **15 glyphs**, each with its file, line, codepoint, and cell count |
| cost | ~$0.033 and ~196s **per lane, per round** | **$0.00 and ~1s** |

```sh
node .agent/repo=bhrain/role=telepath/skills/review.for/review.for.emphasis-noise.density.js \
  .behavior/v2026_09_04 --limit=0        # 122 section(s) over 1 emphasized line(s), across 45 files
                                         # 🟡 as of 2026-09-08. re-run 09-11: 158 across 53 — the
                                         #    route grew; the checker's completeness is unchanged
node .agent/repo=bhrain/role=telepath/skills/review.for/review.for.width-ambiguous-glyphs.js \
  .behavior/v2026_09_04                  # 15 width-ambiguous glyph(s) · {"⚠️":14,"⏱️":1}
```

🔴 **the brain lane is not merely redundant on these — it is 40× less complete**, and it charges for
the shortfall. after three rounds of brain points the yield still held 2 breached sections; the
checker found them in one second and the file went to `0` in two edits.

## .the ask — two mechanisms, and the second is the smaller

### 1. `--rules-wout`, the peer of `--paths-wout`

```sh
rhx review --rules '.agent/repo=bhrain/role=telepath/briefs/rule.*.md' \
           --rules-wout '**/rule.forbid.{emphasis-noise,width-ambiguous-glyphs}.md' ...
```

🔴 **a brace over the enrolled set is NOT an acceptable substitute, and bhuild's own glossary is why.**
`term=review.scope.blocklist` settles it: *"a shared template enumerates a CLOSED set, never an open
one."* the telepath's rule dir is open — it grew from 25 rules while this route ran — so a lane that
braces the judgment rules silently fails to enroll every rule shipped after it was written. the
entooled set is the **closed** side of that pair, which is exactly what a `-wout` flag enumerates.

⇒ and the failure mode of a brace is already measured here: `rule.{a,b,c}.md` with `b` renamed
matches 2, `length > 0`, **no throw** — a silently partial rubric, which is the class
`raise-a-blocker-rather-than-recycle` exists to close.

### 2. make `review.for.*` satisfy `contract.reviewer-output` — a REVIEWER, never a judge

🔴 **the first draft of this ask was for `exit 2`, and it was wrong.** a judge is a binary gate; a
reviewer emits POINTS. these tools produce a located finding per breach — `file:line`, with its
count — which is a review report, not a verdict.

| | as a **judge** | as a **reviewer** |
|---|---|---|
| what the guard reads | the exit code | `N blockers` · `N nitpicks` on stdout |
| what the driver receives | *"blocked"* | 26 located points, in a `.given.by_peer` report |
| the convergence loop | none | each point owes a `.taken`, every round |
| ⇒ what the driver then does | **runs the tool by hand to learn what broke** | answers the points the loop handed them |

🔴 **the judge framing RECREATES the hand-run this dispatch exists to end.** measured on this route:
a driver with no wiring at all invoked `review.for.narration.paragraphs.js` by hand, eight times,
and re-read its stdout each round. a judge would have changed that to *blocked*, then the same hand
invocation. only the reviewer contract puts the findings inside the machinery.

⇒ so the ask is **two output lines per checker**, and the count is already computed:

```
26 blockers
0 nitpicks
```

then each wires as a peer lane, with no parse and no exit-code change:

```yaml
- slug: narration-of-yields
  run: node .../review.for/review.for.narration.paragraphs.js $route/1.vision.yield.md
  budget: 12
  level: 1
```

🟡 **and the hand-rolled parse stays forbidden either way** — the density checker's own banner
records why: a by-tree sweep tool re-parsed its rows for paths and *"reported `.agent` at ZERO
density hits across eight rounds while a `--root=.agent/repo=.this` run reported 19."* the fix is
for the checker to EMIT the contract, never for a caller to infer it.

⇒ `rule.require.exit-code-semantics` still applies as a **peer** ask, for a caller outside a guard.
it is not what makes these gateable.

## 🔴 .the third checker is why the two asks are NOT the same ask

`review.for.narration.paragraphs.js` measures the harder case, and it splits the two mechanisms
apart — the second ask applies to it and **the first must not**:

| | `forbid.emphasis-noise` | `forbid.narration` |
|---|---|---|
| the brain lane found | 3 sections in 1 file | 🔴 **0 — not one citation, in 13 lanes** |
| the checker found | 122 sections, 45 files | **26 paragraphs**, one file |
| the checker's coverage of the rule | the whole rule | **one shape of four** |
| ⇒ the verdict | **unenroll it** — `--rules-wout` | 🟡 **keep it enrolled**, and add the judge |

⇒ **the discriminator is coverage, never cost.** the density checker is more complete than the lane
on every shape its rule names, so the lane's job there is done for free. the narration checker is
complete on the *chained paragraph* and blind to the walkthrough, the bulleted paragraph, and the
preamble — the shapes its own banner declines: *"WHICH claims nest under which is the argument
itself, and a tool that guessed would author a tree rather than render one."*

🟡 **and the zero is the sharper measurement of the two.** emphasis is *visually salient* — a mark
on a page — so a brain reaches for it and merely undercounts. a 3-claim paragraph reads as ordinary
prose, so a brain does not reach for it at all. ⇒ a lane undercounts a property you must **count**
to see — measured twice on this route, emphasis at 3 against 122 and narration at 0 against 26 —
and that is the class this ask is really about.

## .the principle it instances

`philosophy.entoolment-is-the-pinnacle` ranks artifacts by brain cost per use, and a 🪨 solid skill
is rung 4 because *"same input, same output"* and the cost is **none**. to enroll an entooled rule
in a 💧 probabilistic lane is to move it **back down** the ladder — and to pay for the demotion.

> **once a rule has a checker, the lane's job is what the checker cannot do.**

## .the bound — this is not "drop the rule"

both rules stay in the canon, stay blocker-graded, and stay enforced. what changes is **which
instrument reads them**. a rule with a checker is graded deterministically and exhaustively; a rule
without one is graded by a brain, which is the only instrument that can.

⇒ so the ask makes the gate **stricter**: 122 breaches found rather than 3, at no cost, every round.
