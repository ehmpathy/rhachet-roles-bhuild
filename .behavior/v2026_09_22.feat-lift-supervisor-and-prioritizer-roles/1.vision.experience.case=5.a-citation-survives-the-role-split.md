# case=5 — a citation survives the role split

> **actor** = `clone` · **goal** = `learn` — follow a pointer to its record
> **cell** = 08 (`clone × learn × consumer`), sharp leg · latent axis `has-citation-target?`
> **feel** = sharp · **care** = critipath
> 🟡 a **human** hits the same dead pointer at row 20, and row 20 is demoed by `case=10`. the
> break is actor-independent, so it is **subsumed there**, never a second actor on this header

## .the narrative

a clone reads `rule.always.prioritize-never-supervise` and reaches its `.see also`. it wants the
peer rule — the one the brief says to read *together* with it, because the pair names the seam.

the pointer says `rule.require.speak-at-the-supervisor-layer (repo=.this/role=any)`.

after the lift there is no `repo=.this/role=any`. the clone finds naught. and the sharp part is
not the absence — it is that **the clone cannot tell an absence from a loss**. was the peer rule
dropped in the lift? was it renamed? did it ever exist? a reader who cannot part a lost record
from one that was never written will either re-derive it badly or treat the citation as noise.

this failure already has a live instance in the source, and the handoff names it: the term
`term=goal.effect` cites `term=goal.effect._.choice.reason.md` by name, and **that file does not
exist** — 70 `choice` files, 69 `.reason` files. one phantom path, minted before the lift.

🔴 **and the lift's own shape mints more.** the handoff's §3.2 warns about one direction — ten
`eco.*`/`goal.*` term clusters moved to `role=prioritizer` while **supervisor** briefs cite them
(`surgoal.squeeze-the-grove`, `define.cost-gain-matrix`). the mirror direction is live too and is
**not** named in the handoff: `rule.always.prioritize-never-supervise` is a **prioritizer** brief
whose `.see also` cites **three** `role=any` artifacts —

| cited | becomes |
|---|---|
| `rule.require.speak-at-the-supervisor-layer` | `role=supervisor` |
| `rule.forbid.self-appointed-babysit` | `role=supervisor` |
| `term=partial-audit._.choice._.md` | `role=supervisor` |

⇒ **the aha**: a role split is a rename of every path that crosses it. the citations are the part
that does not move itself, and they fail silently — a broken pointer throws no error, it just
teaches the next reader that pointers here are unreliable.

```gherkin

     and moved the 10 eco.*/goal.* term clusters → role=prioritizer

[t1] when a clone follows any `.see also` in a lifted brief
     then the target RESOLVES
     ⇒ no phantom paths, in either direction

[t2] when the citation crosses the new role boundary
     then it names the NEW role
     e.g. `rule.require.speak-at-the-supervisor-layer (role=supervisor)`

[t3] given `term=goal.effect._.choice._.md` cites its own `.reason.md`
     when a reader follows that pointer
     then the file EXISTS
     ⇒ ✅ SETTLED 2026-09-22 — the wisher: "you author F6"
       ⇒ author the reason half. the strike branch is closed
       ⇒ it lands under role=prioritizer, per F2 — `goal.*` is prioritizer vocabulary
     ⇒ the choice file itself is sound — keep it
```

🔴 **`[t3]` has one bound the ruling does not lift.** the cited content names *"the wisher's words
verbatim"* — words i do not have. so the authored file carries the two reconstructible parts (the
rejected `kind`, the name fulcrum) and marks the third **absent, never invented**
(`rule.always.archive-the-wishers-words-verbatim`). ⇒ a reason file that passes reconstruction off
as evidence is worse than the phantom path it cures.

🟡 and the count closes with it: **70 `choice` files, 70 `.reason` files** — so `[t6]`'s walk has no
known exception left to carve out.

## .the check this case demands

a **bidirectional** citation audit, run before the move lands:

| direction | source | target | named by |
|---|---|---|---|
| supervisor → prioritizer | `surgoal.squeeze-the-grove`, `define.cost-gain-matrix` | `goal.surgoal`, `goal.effect` | handoff §3.2 ✅ |
| 🔴 prioritizer → supervisor | `rule.always.prioritize-never-supervise` (3 pointers) | `speak-at-the-supervisor-layer`, `self-appointed-babysit`, `partial-audit` | **not in the handoff** — found here |
| within a role | `term=goal.effect` → its own `.reason.md` | absent file | handoff §3.2 ✅ |

## 🔴 .how it fails safe

the audit table above is a **human act**, run once, at one moment. that is not a fail-safe — it is a
promise, and this defect's whole character is that it is **silent**: a broken pointer throws no
error, fails no build, and reads exactly like a working one until someone follows it.

⇒ so the audit is the repair, and the guard is what keeps the repair true:

```gherkin
[t6] given a test that reads every `.see also` / citation path in every lifted brief
     when it resolves each path against the shipped role dirs
     then EVERY path resolves to a file that exists
     and the failure names the citing brief AND the absent target
     ⇒ fast (a unit test over the brief corpus) · loud (red) · teaches the fix
        (the message carries both halves — you fix the pointer or author the target)

[t7] given a citation that crosses the new role boundary
     when it resolves
     then the path names the role the target ACTUALLY lives in
     ⇒ a citation that resolves to the wrong role dir is the same defect one week later
```

⚠️ **`[t6]` is what makes `[t3]`'s phantom findable at all.** `term=goal.effect._.choice.reason.md`
was minted before the lift and went unnoticed for months — precisely because no check existed. the
same absence would hide every phantom this lift mints.

🟡 the guard is **cheap and complete**: the corpus is a fixed set of markdown files, the citations
are a regex, and the targets are paths on disk. this is the one sharp case in the lift whose
fail-safe is near-free, which is why its absence today is hard to defend.

## 🔴 .the placement call makes this audit MANDATORY

`F2` places the `eco.*`/`goal.*` vocabulary under `role=prioritizer` — and that is the branch that
needs the audit most. the two were never symmetric:

| branch | citation churn |
|---|---|
| leave them shared under `role=supervisor` | ⛔ **none** — no path crosses a role boundary |
| ✅ **move to `role=prioritizer`** (the call) | 🔴 **every supervisor→`goal.*` citation becomes cross-role** |

so `[t6]`/`[t7]` are not precautionary. the known citations — `surgoal.squeeze-the-grove`
and `define.cost-gain-matrix`, both supervisor briefs that cite `goal.surgoal` / `goal.effect` —
are **guaranteed** to cross the new boundary, and they fail silently.

🔴 **the unit that moves is 13 artifacts, not 10.** a third fact, found here and absent from the
handoff's §3.2 account: **two `define.invariant.eco.*` briefs also sit in `role=any`** —
`gain-propagates-down-and-sums` and `gain-sums-up-never-down`. §3.2 scopes the call to the 10 term
clusters only. ⇒ a lift that follows §3.2 **literally** splits the gain arithmetic from the
vocabulary it is written in. plus one stray fixture (`case=6`): **10 + 2 + 1**.

⚠️ so this case now pairs with `case=4` `[t8]`: **`[t8]` asserts the move landed whole; `[t6]`/`[t7]`
assert it minted no phantom paths.** neither alone is sufficient — a complete move with broken
citations and an incomplete move with intact ones both pass one test and fail the other.

see the fulcrum inventory, `F2`.
