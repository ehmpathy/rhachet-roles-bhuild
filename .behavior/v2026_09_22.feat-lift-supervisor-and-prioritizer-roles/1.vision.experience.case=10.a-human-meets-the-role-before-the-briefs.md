# case=10 — a human meets the role before the briefs

> **actor** = `human` · **goal** = `learn` — decide whether to enroll this role at all
> **cell** = 20 (`human × learn × consumer`), sharp leg
> **feel** = sharp · **care** = critipath · a **live** gap, named by §6.5

## .the narrative

a human in `ahbode/svc-jobs` hears there is a beaver role that runs crews. they open the package
and look for the one artifact every role in this repo has: `readme.md`. the behaver has one. the
decomposer, dispatcher, and dreamer each have one. they are four to nine lines, and they answer the
only question a human asks first — **what is this for, and do i want it?**

🔴 **the supervisor has none.** the handoff names this in §6.5, as an **owed artifact** rather than
a fork. what lifts is 275 briefs, 46 skills, and 284 lines of boot curation — a body of material
whose entry point does not exist.

🔴 **and the reason is sharper than an omission.** measured at source:

```
--paths '.agent/repo=.this/role=*/readme.md'  →  1   role=prioritizer ONLY
--paths '.agent/repo=.this/role=*/boot.yml'   →  2   role=any · role=prioritizer
```

⇒ there is no `role=supervisor` directory in nheuron **at all**. the material lives in `role=any`,
which is the repo's catch-all and has never had a readme because a catch-all has no audience to
address. so this is not *"port the readme"* — it is **author one, for a role with no precedent**, a
strictly larger task than the handoff's one-line entry implies.

🟡 the prioritizer is the counter-proof and the template: it already **is** a named role, and it
already **has** a readme. that asymmetry is the whole of this case.

so the human's next move is to read a brief. and the briefs are written **for a clone already in
the seat**: `rule.always.clamp-the-verbatim-pane-your-classifier-judged` is correct, load-central,
and answers no question a human who has not yet enrolled would ask. the human either enrolls blind
or walks away, and both outcomes look identical from our side — **no error, no signal, no trace**.

⚠️ and the cost is asymmetric with every other case here. every other sharp edge in this lift
costs a session, a rank, or a re-run. this one costs an **adoption** — the human never enrolls, so
none of the other 35 cells is ever reached. it is the cheapest defect in the lift and the only one
that can zero the whole gain.

⇒ **the aha**: a role's readme is not documentation of the role. it is the **contract with the
human who has not enrolled yet**, and it is the only artifact that audience will ever read.

## 🔴 .how it fails safe

this one is **cheap and complete**, which is why its absence is the hardest to defend in the lift:

```gherkin
[t8] given a test that globs src/domain.roles/*/
     when it asserts each role dir holds a readme.md
     then a role with no readme fails the build
     and the failure names the role dir
     ⇒ fast (a unit test) · loud (red) · teaches the fix (the path IS the fix)

[t9] given the role declares `readme: { uri: __dirname + '/readme.md' }`
     when the file is absent
     then the assertion fails at the same place
     ⇒ the same shape as case=3's [t8]/[t9] — file and field, one checkable claim

[t10] given the artifact cutover is HARD — ⛺ supervisor, 🔦 prioritizer
      when the walk reads each readme's first line
      then it carries THAT role's declared artifact
      ⇒ 🌿 is the prioritizer's glyph AT SOURCE, so a port that does not
        cut it over ships the old identity in the one line a human reads

[t11] given 🌿 and 🕯️ are BANNED glyphs, decorative uses included
      when a grep runs over src/ — the whole package, never role-scoped
      then it finds zero of either
      ⇒ a retired artifact that survives as decoration is one a reader
        still meets, so the package would hold two answers to
        "what does 🌿 mean here?" — the ambiguity the cutover closes
      🔴 one live instance sits on `main` today, OUTSIDE this lift's diff:
         `behaver/skills/review.behavior.sh:372` prints `🌿 summary`
      ⇒ a scouts-honor repair on contact, never a src edit from the vision
```

🟡 **`[t8]` and `case=3` `[t8]` are the same test with two fields**, and `[t10]` adds a third to
the same walk: a single `role-artifacts.test.ts` asserts `{ readme, boot }` file-and-field parity
**and** the declared artifact on each readme's first line. ⚠️ `[t11]` is **not** part of it — a
package-wide glyph ban cannot live in a per-role walk, because its whole claim is that it is not
role-scoped.

⇒ and the guard is what turns §6.5 from a line in a handoff into an item that **cannot be
forgotten**. an owed artifact with no check is an owed artifact that ships owed.

## ⚠️ .the bound — a readme is not a tutorial

the temptation, with 275 briefs behind it, is to write a readme that teaches the role. it should
not. the house shape is four to nine lines, and the extant four roles prove the size is enough:

> `## 🌙 dreamer` · *used to dream of and catch the behaviors we want to see in the world.*

the supervisor's version adds one clause the others do not need — **what the role will not do** —
because this is the seat whose boundary was measured, at cost, in `case=4`. the prioritizer's adds
the mirror.

🟡 the wish does not ask for a readme and the handoff files it under §6.5 as an owed artifact, so
its **content** is a small authored call. it is not a fulcrum: there is one right answer (follow
the house shape), and the only judgment is the one clause above.

### 🔴 .the one brief the lift OWES that no repo has today

the supervisor speaks four nouns and **not one of them is defined in this package**:

| term | declared in | and the trap |
|---|---|---|
| `camp` | `ahbode/infrastructure` | reads as an env or a fleet; it is an aws **account** |
| `grove` | `ahbode/infrastructure` | reads as an ec2 or a sandbox; it is a **work-box that hibernates** |
| `camper` | `ahbode/infrastructure` | 🔴 reads as a clone. `clone-user` is a **forbidden** synonym |
| `clone` | `ehmpathy/rhachet` | reads as a session or a process |

⇒ a cross-repo `.see also` does not resolve — `case=5`'s citation audit can check a path inside
this package and cannot reach one outside it. **so these four must be RESTATED here, each with its
source repo named**, or the supervisor ships with a vocabulary whose definitions no reviewer of
this PR can open.

🔴 **the sharpest of the four is `camper`, and it fails in two directions at once:**

- as a **name** — a clone *camps out* on a grove, and `camper` is the OS login it enters **by**.
  one camper per grove today (`CAMP_GROVE_CAMPER_USER`, a singular constant), never one per clone
- as a **boundary** — IMDS answers any uid with no privilege, so a camper with zero sudo already
  holds the grove's full badge. `camper` bounds the **box**; the grove role's **tier** bounds AWS

⇒ a supervisor that conflates them tightens sudo, believes the blast radius shrank, and is wrong.
that is a **safety** claim, so the brief is owed at `say` level in `boot.yml` — not `ref`.

🟡 and this is the case's own bound at work: the readme stays four to nine lines and **points**;
the brief carries the four definitions. a readme that teaches the mythology is a tutorial
(`.the bound` above), and a role with no such brief is a role whose words mean whatever the reader
already thought.

⚠️ **the supervisor's readme is authored from scratch; the prioritizer's ports.** measured above:
`role=prioritizer/readme.md` exists at source and moves with the role. so `[t1]` asserts one file
that travels and one that must be written — a distinction worth a note in execution, because the
two look identical in a diff and only one of them is a judgment call.
