# case=2 — a criteria writer meets a done-when phrased by a prior tool

feel = sharp (t1, t1.light) / happy (t2) · care = critipath · rows c.how.copy, c.how.copy@light, r.criteria.copy, c.how.restate · 4 boundaries (wish → yield, evidence → spec, vision → criteria, yield → review)

## .narrative

the #760 slip, replayed with the rule in place. the wish's `.done when` reads *"`get` shows what
the dev-env-setup `brains.auth.usage` read shows"*. the clone's first draft of the requirement copies
it:

> for each account, `rhx brains auth get` shows every window the `brains.auth.usage` read shows.

the guard's self-review asks the strike test. the clone strikes `brains.auth.usage` from the repo
and re-reads: *"shows every window the ___ read shows"*. the sentence no longer says what `get`
must do. it fails fast — one read — and the prompt names the fix: restate it on the domain's terms.

the clone rewrites it:

> for each account held in the keyrack, `rhx brains auth get` shows each usage window (session,
> week), its used share, and its reset.

the strike test passes. the old tool can be deleted and the requirement still holds.

`[t1.light]` — on a light route there is no criteria guard, so no self-review fires at criteria.
the criteria stone's line asks the strike test at authorship, but a clone that skims it ships the
slip to the next stage. the next stage is the blueprint, and its guard (light and heavy alike) runs
the `wisher-how` lane over the criteria and blueprint yields, with the wish at refs:

```
1 blocker
0 nitpicks

[blocker][better] 2.1.criteria.blackbox.yield.md defines `get` as "shows what
`brains.auth.usage` shows" — strike that tool and the criterion states naught
(rule.forbid.trust-of-wisher-how).
fix: restate the criterion in domain terms: per account, each usage window, its used share, its
reset. carry the fix into the blueprint's test coverage.
```

the blueprint's `reviewed? --allow-blockers 0` judge holds the stone. the slip is caught one stage
later than on a heavy route, but before any code is written.
