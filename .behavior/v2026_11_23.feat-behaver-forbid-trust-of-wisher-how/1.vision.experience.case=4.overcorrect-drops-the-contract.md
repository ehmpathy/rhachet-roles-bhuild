# case=4 — a writer drops a poc rightly, and the wisher's verbs with it

feel = sharp · care = critipath · rows v.how.overcorrect, r.vision.overcorrect (and v.why.overcorrect `[t3]`; c.why.overcorrect, c.how.overcorrect, c.port.overcorrect, v.port.overcorrect via its checks) · 3 boundaries (wish → yield, evidence → spec, yield → review)

## .narrative

a sandpine wish asks for `rhx board.rental get|set|del`, and links a poc: a shell command that
rewrites the whole `rentals.json` on every change. a writer fresh off the rule does half of it
right. the poc's rewrite-all design is a how, so the writer drops it, with a verdict. then it reads
*"never trust the how"* too wide, decides the verb set came from the poc too, and designs one verb,
`rhx board.rental sync`, that reconciles all rentals at once. the poc is gone, and so is the
contract the wisher asked for.

the self-review's last line is the inverse check: *"are the verbs the wisher asked for still all
there?"* the clone lists them — `get`, `set`, `del` — and finds none of them in the yield. the said
cue says it plainly: the inverse slip is a verb dropped as "a how"; the verbs stand, and only the
inputs, defaults, and scope behind them are open.

had the self-review been promised thin, the vision guard's `wisher-how` lane reads the wish beside
the yield and counts it:

```
1 blocker
0 nitpicks

[blocker][better] the vision drops the verbs the wish asked for (`get`, `set`, `del`) and puts
`sync` in their place — rule.forbid.trust-of-wisher-how: the contract's verbs stand.
fix: restore `get|set|del`; carry `sync`'s bulk mode as an open question for the wisher.
```

the writer restores `get|set|del`. the poc's design stays dropped. the one idea from `sync` worth a
keep, a bulk mode, becomes an open question for the wisher, not a replacement.

`[t3]` — the same slip with no poc at all (`why-only`): a wish names `get|set|del` and naught else,
and a writer still swaps in `sync`. no how was read, so the slip crosses no evidence → spec line, but
the inverse check and the lane catch it the same way.
