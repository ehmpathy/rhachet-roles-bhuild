# case=3 — a reviewer grades a vision that adopted a poc unchallenged

feel = sharp · care = critipath · rows v.how.copy, r.vision.copy (and v.port.copy, graded the same) · 3 boundaries (wish → yield, evidence → spec, yield → review)

## .narrative

a sandpine wish asks for `rhx lesson.book` and links a poc: a shell command that writes each lesson
as a row in a csv file under `.lessons/`, one column per field. the vision writer's yield lays out
the design — the csv, its columns, its path — exactly as the poc has them. no line says why a csv,
why those columns, or what a lesson booker needs.

the writer signals `--as arrived`. the vision guard's peer lane `wisher-how` loads
`rule.forbid.trust-of-wisher-how`, with the wish at refs, and reads the yield:

- the design matches the poc field for field
- no `## .the wisher's how` table, no keep/drop verdict, no skeptic's pass recorded
- strike the poc: the storage section reads *"stored as the poc stores them"* — it no longer says what is stored, or why

the review is loud and names the fix:

```
1 blocker
0 nitpicks

[blocker][better] the vision adopts the poc's storage layout (csv, columns, path) with no
skeptic's pass recorded — rule.forbid.trust-of-wisher-how.
fix: restate what a lesson record must hold and why, in domain terms; give the poc's layout a
keep or drop verdict, with its reason.
```

the guard's `reviewed? --allow-blockers 0` judge holds the stone: no human is asked to approve a
vision with an open blocker. the writer adds the table. the csv is dropped (lessons need a lookup by surfer and by slot; a flat
file serves neither); the field list is kept, restated as what a booked lesson is.

## .bdd sketch

```
given('[case3] a vision that copies a poc design with no skeptic pass', () => {
  when('[t0] the writer arrives and the wisher-how peer lane grades it', () => {
    then('the review counts a blocker')
    then('the reviewed? judge holds the stone')
    then('the blocker names the adopted how and the absent skeptic pass')
    then('the blocker names the fix: restate, then keep or drop with a reason')
  })
  when('[t1] the writer records the skeptic pass', () => {
    then('each how in the poc carries a verdict and its reason')
    then('the review counts no blocker for this rule')
    then('the stone may now ask the human for approval')
  })
})
```
