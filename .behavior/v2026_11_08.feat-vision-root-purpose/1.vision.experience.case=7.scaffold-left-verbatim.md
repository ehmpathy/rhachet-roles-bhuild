# case=7: scaffold left verbatim

sharp × critipath · inventory row 4 · a forbidden cell's rejection

## .narrative

a clone drives `sandpine-wetsuit-inventory` in a hurry. the stone scaffold hands it the section with three placeholder layers; it writes the rest of the vision and never touches them:

```md
- why: <the surface motive — why the wisher asked>
  - why: <the motive beneath it>
    - why: <the root motive — the one that no longer shifts>
```

the header is present and the nest is three deep, so a count of bullets alone would pass. the depth lane reads each layer's whole text, finds one `<…>` placeholder per layer, and counts zero:

```
🦫 root purpose
   ├─ section: present
   ├─ layers: 0 of 3
   ├─ blockers
   │  └─ [blocker][better] the root purpose still holds scaffold text in 3 layers
   │     └─ fix: replace each `<…>` with the motive itself
   └─ summary
      ├─ 1 blocker
      └─ 0 nitpicks
```

the untouched template is the path the invariant forbids: a placeholder layer is no layer.
