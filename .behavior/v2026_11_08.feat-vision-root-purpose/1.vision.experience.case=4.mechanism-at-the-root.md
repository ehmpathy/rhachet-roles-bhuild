## .narrative

a clone drives `sandpine-cert-ingest`. it knows the drill now and writes three nested layers:

```md
- why: instructor certs must be ingested from the agency feed
  - why: so the schedule can check a cert before it assigns an instructor
    - why: so a nightly job can sync the certs table with the agency api
```

the depth lane counts three and approves — the shape is right. the motive lane reads the layers and finds the chain turned *down* into mechanism: a nightly job, a table, an api. the root says how, not why:

```
[blocker][better] the root purpose names a mechanism, not a motive
  layer 3: "so a nightly job can sync the certs table with the agency api"
  fix: ask why of layer 2 instead — what harm comes of an instructor with a lapsed cert?
```

a second try adds a fourth layer *above* the bad one, hopeful that depth will carry it — *"why: sandpine wants reliable data"* on top. the root is still the deepest layer, still the nightly job, and the motive lane blocks the same way. extra layers above a mechanism do not save it.

the clone rewrites the deepest layer: *an instructor without a current lifeguard cert cannot legally teach in the water, and a lesson taught by one puts a surfer at risk*. now the root is safety, and the vision's sharp paths reorder around it — a feed outage must block assignment, not skip the check.
