## .invariants (from forbidden cells)

each of rows 3, 4, 5 is an attempt the author may make and the depth lane must reject, so each records its invariant:

- (row 3) a vision yield owes a `## .the root purpose` section; absent → blocked
- (row 5) a layer is a `- why:` bullet, case-blind (row 5i); any other form (`* why:`, `1. why`, prose) is no layer
- (row 4) a `- why:` bullet whose **whole** text is one `<…>` placeholder, or is blank, is not a layer. a motive that merely quotes angle brackets (`<Component>`, `<html>`) still counts
- (row 5f) the header is `## .the root purpose` (dot optional), alone on its line; any other header is no section
- (row 5c) a section with no `- why:` bullet is 0 layers deep, whatever prose it holds

## .the depth rule (from demoed row 6, not a forbidden cell)

- flat `- why:` bullets at one indent are depth 1, never depth N — case=3 `[t1]`
