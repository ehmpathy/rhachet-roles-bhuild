## .the hidden-dimension check

- **D2, D3, D3b, D4 are derived from D1 = `filled`.** where D1 ≠ `filled` no layers exist, so those four axes take no value. the D1 cells themselves are real and verdicted on their own (inventory rows 3–5); only their derived-axis cells are impossible (row 11)
- **D3b presupposes D3 = `motive`.** a shape cannot answer to a root that is a mechanism; the motive lane blocks first. so D3b is walked only where D3 = `motive` and D2 ≥ 3
- **D4 is defined only where the motive lane runs** — D1 = `filled`. `false-block` matters where D3 = `motive`; `false-pass` matters where D3 = `mechanism`
- **D6 = `extant` collapses D1–D4**: no lane runs, so one row covers it
- **D5 changes no outcome** by construction (`rule.require.guard-variant-consistency`); kept so its sameness is a checkable claim
- **D0 = `approver` / `builder`** meet only visions that cleared the lanes: `filled · ≥3`, and D3 = `motive` unless D4 = `false-pass`. the approver meets a false-pass at the gate (row 13c); the builder meets one only if the approver missed it too (row 14b). D3b reaches both: approver × ignores (13b), builder × ignores (14c)

## .axes considered and set aside

- **concurrency** — two clones on one route at once. a route is bound to one branch and driven by one driver (`route.bind`); the lanes are read-only on the yield. no second writer exists, so no axis
- **author resolution** (fill · dispute · `.taken`) — the absorb loop is bhrain's, shared by every lane on every stone; this behavior adds no new resolution path. its uses here appear inline (row 10, case=6), not as an axis
