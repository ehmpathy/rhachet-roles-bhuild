# 1.vision.experience.dimensions

the experience space of "a behavior route picks its brain by stage", factored into axes. each axis
is a small closed value set; the orthogonality of each is argued below the table.

## .the dimensions

| # | dimension | values |
|---|-----------|--------|
| D1 | actor | **driver** (clone that drives the route) · **reviewer** (enrolled peer lane) · **maintainer** (human or clone that edits a template) · **initiator** (human who runs `init.behavior`) |
| D2 | stone phase | **design** (wish → blueprint; prefix `1.`–`3.`) · **build** (roadmap → on; prefix `4.`–`5.`) |
| D3 | the stone's brain declaration, as its template reads | **none** (no guard; the stone inherits the prior brain) · **same** (a guard declares the brain the driver already runs on) · **new** (a guard declares a brain the driver does not yet run on) · **absent** (a guard with no `brain:` line — a maintainer slip) |
| D4 | size | nano · mini · medi · mega · giga |
| D5 | guard variant | light · heavy |
| D11 | the model id's validity | **valid** (the claude cli accepts it) · **rejected** (the cli refuses the slug) |
| D9 | driver enrollment | **enrolled** (spawned by `rhx enroll`; has a clone address) · **unenrolled** (a human typed `claude`; no address — bhrain halts at every `brain:` stone, by design, seed S8) |
| D10 | consumer's bhrain | **≥0.39** (parses `brain:`) · **0.30–0.38** (ignores it; allowed by today's peer floor) |
| D7 | route origin | **fresh** (inited after this change) · **extant** (inited before) |
| D8 | reviewer brain today | **sonnet** (`claude-sonnet-5[1m]`) · **other** (any other brain, or no `--model`, which runs on bhrain's default `openrouter/deepseek/flash`) |

## .why each axis is independent

- **D1 actor** — who meets the experience. no other axis fixes it: every actor touches stones of
  each phase, size, and origin.
- **D2 phase vs D3 declaration** — phase is set by the stone's prefix; the declaration is set by the
  template. a design stone can declare none (light `2.1.criteria`) or a brain (`1.vision`); a build
  stone can declare none (`4.1.roadmap` today) or a brain (`5.1`). so D2 does not imply D3.
- **D3 is read from the template alone.** whether bhrain honors the declaration is D10's question,
  and whether the session can be switched is D9's. `same` vs `new` compares the declaration to the
  prior stone's brain — set by the route's order, not by this stone's phase.
- **D4 size vs D5 variant** — size picks which stones exist; variant picks which guard file fills a
  stone that has one. any size takes either variant (`initBehaviorDir({ guard })`). the one variant
  effect on which stones are guarded: light ships no `2.1.criteria` guard, heavy does.
- **D11 id validity** — a property of the string in the template, independent of who drives and
  which stone. its cause and fix (fix the `--model` string, bhuild-owned) differ from D9's (run
  `rhx enroll`, a session concern), so the two are separate axes.
- **D9 enrollment** — a property of the session, set before the route starts. an unenrolled driver
  halts at any stone whose D3 is `same` or `new`, whatever else holds, so it dominates (c16).
- **D10 consumer bhrain** — a property of the consumer's install, independent of the template.
- **D7 origin** — whether the route predates this change. independent of all the above.
- **D8 reviewer brain** — a property of each review line in a template. independent of the stone's
  own `brain:` (a sonnet build stone carries non-sonnet reviewers, and an opus design stone carries
  sonnet reviewers — `3.3.1.blueprint` does).

## .the walked product

every axis is either a **live column** in the cell table or **collapsed** to a default, below.

**live columns:** D1, D2, D3, D4, D5, D9, D10, D11, D7, D8, plus a per-cell **boundary** attribute.

**collapsed, per axis:**

- **D4 × D5** — change which stones exist, not the experience. every size × variant pair must land
  every stone on the right brain: one *invariant*, checked across 10 pairs by the walk test
  (`case=5`), not 10 experiences. so most cells read `any`. two break out: **nano** (no blueprint;
  its boundary sits at `1.vision → 5.1.execution.from_vision`; c4) and **light** (its
  `2.1.criteria` declares none and inherits; c2 — under heavy that stone declares `same` and joins
  c1b).
- **D3 = same** — a benign re-dispatch: bhrain converges, never compares (seed S5). one cell (c1b,
  c5) per phase; only `new` at the boundary is ours to demonstrate.
- **D9 = unenrolled / unprobeable** — dominates: at any `same`/`new` stone it halts first. one cell
  per value: c16 (no clone address) and c16b (`clone whoami` gives no readable answer). each gets
  its own halt and fix from bhrain. every other cell is `enrolled`.
- **D10 = 0.30–0.38** — reduces the whole space to the status quo: a pre-0.39 parser ignores
  `brain:` (`currentKey` is set only for artifacts, reviews, judges, protect), so no switch fires.
  one cell (c19); every other cell is `≥0.39`.
- **D11 = rejected** — one experience per actor: a driver halts (c7), a reviewer lane malfunctions
  (c17). every other cell is `valid` or `n/a`.
- **D7 = extant** — one cell (c8); every other cell is `fresh` or `n/a`.

**not collapsed:** D1 (each actor has its own cells), D2 (design and build each walked), D8 (sonnet
moves to sonnet-5-5, other stays — c10, c11a, c17, c20a/b).

**no impossible cell remains.** phase is derived from a stone's prefix, so "a build stone before the
blueprint" names no value of D2 — it is not a cell. every combination the table omits is covered by
an `any` in a row that holds.

## .the cells that remain

conventions:

- `any` = the axis is free; every value yields the same experience. where a dominant axis decides
  first (D9 = unenrolled halts before D11 is consulted), the dominated axis reads `any`.
- `n/a` = the axis does not apply to this actor or event (the reason sits in the row's text).
- **boundary** names the stone where design hands off to build, for the cells that cross it.
