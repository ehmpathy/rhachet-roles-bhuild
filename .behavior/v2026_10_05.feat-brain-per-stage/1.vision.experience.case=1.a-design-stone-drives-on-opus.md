# case=1 · a design stone drives on opus

feel = happy · care = critipath

## .narrative

kai inits a mini behavior on a fresh branch. his clone wakes on whatever brain the session
started on — today, sonnet. it runs `rhx route.drive`. the drive reaches `1.vision`. the vision
guard now carries `brain: claude-opus-5-5[1m]`, so bhrain sends `/model claude-opus-5-5[1m]` into
the clone before it reads a word of the stone. the drive render shows the live brain under
`where do we go?`.

the clone writes the vision on opus. it passes. it walks the criteria and research stones. none of
them carry a guard in light mode, so the clone stays on opus by inheritance. it reaches
`3.3.1.blueprint.product`. that guard also declares opus. bhrain dispatches `/model
claude-opus-5-5[1m]` again — it converges on the declared brain and never compares first. the clone
is already on opus, and a switch keeps the conversation, so the repeat changes naught.

kai never typed `/model`. the stones that decide the shape ran on the stronger brain.

## .timeline

`[t0]` is cell c1a (the real switch). `[t1]` is c2 (inherit), `[t2]` is c1b (the benign repeat).

```
given('[case1] a fresh mini route, light guards; an enrolled clone that started on sonnet')
  when('[t0] the driver enters 1.vision')
    then('bhrain sends /model claude-opus-5-5[1m] to the clone')
    then('the drive render names claude-opus-5-5[1m] as the live brain')
  when('[t1] the driver enters 2.1.criteria.blackbox, a design stone with no guard (light ships none for it)')
    then('no switch fires; the clone stays on claude-opus-5-5[1m] by inheritance')
  when('[t2] the driver enters 3.3.1.blueprint.product')
    then('bhrain re-dispatches /model claude-opus-5-5[1m]; the clone stays on opus, conversation intact')
```
