# case=7 · a reviewer cannot run on the id

feel = sharp · care = critipath

## .narrative

i am the driver on `5.1.execution.phase0_to_phaseN`. i run `--as passed`. the guard pours its
lanes, and one claude lane comes back with no verdict: the claude cli refused
`--model 'claude-sonnet-5-5[1m]'` — say the id was typed wrong in a template, or a later release
renamed it.

the guard does not read that as a clean pass. a reviewer with no numeric count is a
`💥 malfunction`, and a malfunction blocks the stone (`contract.reviewer-output`). the halt names
the lane. its stderr names the model the cli rejected. i read it, classify it as driver-fixable
(`rule.always.diagnose-reviewer-malfunctions`), and fix the one `--model` string in the guard. i
answer the malfunctioned lane in a `.taken`, re-arrive, and the lane runs.

if the defect sits in the template, every route that inits after it inherits it. so the template
fix belongs upstream, in bhuild — and a check at execution, one live `enroll claude --model` with
the exact string, keeps the defect out of a release at all.

## .timeline

```
given('[case7] a claude lane whose --model id the claude cli rejects')
  when('[t0] the driver runs --as passed on a guard that pours that lane')
    then('the lane returns no numeric count; the guard grades it 💥 malfunction')
    then('the stone blocks; the halt names the lane')
  when('[t1] the driver reads the lane stderr')
    then('the stderr names the rejected model id')
  when('[t2] the driver classes it driver-fixable, fixes the --model string, answers the lane, and re-arrives')
    then('the lane runs and returns a verdict')
```

the live check that keeps a bad id out of a release is a pre-release step, not this driver's walk —
it lives in the yield's "to verify at execution".

## .why it fails safe

fast (the first pour after the defect), loud (a malfunction blocks; it never reads as `0/0`), and
it teaches the fix (the stderr names the id; the guard is the driver's to edit). the live check at
execution moves the catch from a consumer's route to this repo.
