# case=9 · a new stone lands on the right brain

feel = sharp · care = critipath

## .narrative

i am a maintainer. we want a release stone after verification, so i add `5.4.release.stone` and a
`5.4.release.guard` with two reviews. i copy the review block from `5.3` and forget the `brain:`
line.

the suite goes red before i push: every guard template must declare a brain, and mine does not. the
failure names `5.4.release.guard`. no route ever ran on it, so no route ever drove a release stone
on the wrong brain.

i add `brain: claude-sonnet-5-5[1m]`. green.

a week later a teammate adds a lighter `5.6.retro.stone` with no guard at all. the suite stays
green, and that is right: an unguarded stone inherits the prior stone's brain, the walk computes it
— sonnet, from `5.5.playtest` — and the phase check passes because a build stone landed on sonnet.
had the teammate slotted an unguarded *design* stone after `5.5`, it would inherit sonnet too, and
the phase check would go red. nobody had to remember a rule for unguarded stones; the phase check
on the brain each one lands on is the rule.

## .timeline

this case demos two cells: `[t0]`–`[t1]` is c13a (a new guard with no `brain:`), `[t2]` is c13b (a
new stone with no guard).

```
given('[case9] the bhuild template set, all green')
  when('[t0] a maintainer adds a guarded build stone whose guard has no brain:')
    then('the test fails: every guard template must declare a brain')
    then('the message names the new guard template')
  when('[t1] the maintainer adds brain: claude-sonnet-5-5[1m] to it')
    then('the walk lands the new stone on claude-sonnet-5-5[1m]; the test passes')
  when('[t2] a maintainer adds an unguarded build stone after 5.5.playtest')
    then('the walk lands it on claude-sonnet-5-5[1m], inherited from 5.5.playtest')
    then('the phase check passes: a build stone landed on sonnet')
```

## .why it fails safe

fast (an integration test over the templates), loud (red before push), and it teaches the fix (it
names the guard that lacks a brain). the unguarded case needs no rule of its own: the phase check
on the brain it lands on covers it.
