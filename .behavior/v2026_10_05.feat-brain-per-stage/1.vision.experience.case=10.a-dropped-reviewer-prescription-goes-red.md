# case=10 · a dropped reviewer prescription goes red

feel = sharp · care = critipath

## .narrative

i am a maintainer. i rework the execution guard's architecture lane and paste an older review
block from memory. two slips ride along: the claude lane reads `--model 'claude-sonnet-5[1m]'`
again, and in a hurry i add `--model 'claude-sonnet-5-5[1m]'` to an `rhx review` lane that never
named a brain.

neither slip would surface at runtime. the first lane would quietly run on the older sonnet. the
second would move the lane off bhrain's default, `openrouter/deepseek/flash`, onto claude — a
family change, which the wish rules out: "a reviewer that names any other brain keeps it — this
changes which sonnet a sonnet reviewer runs on, never which family a reviewer runs on."

the suite goes red on both. the reviewer test is this change's deliverable; what follows is what it
asserts. it reads every review line in every guard template:

- every `enroll claude` lane must name `--model 'claude-sonnet-5-5[1m]'` — the first slip fails,
  and the message names the template and the line
- every other lane must read exactly as its pre-change baseline — the second slip fails, and the
  message names the lane that changed

i revert both slips. green.

## .timeline

```
given('[case10] the bhuild template set, all green')
  when('[t0] a maintainer sets a claude lane back to --model claude-sonnet-5[1m]')
    then('the reviewer test fails: every enroll claude lane must name claude-sonnet-5-5[1m]')
    then('the message names the template and the lane')
  when('[t1] a maintainer adds a --model to an rhx review lane that named no brain')
    then('the reviewer test fails: a non-sonnet lane differs from its baseline')
    then('the message names the lane that changed')
  when('[t2] the maintainer reverts both edits')
    then('the reviewer test passes')
```

## .why it fails safe

fast (an integration test over the templates), loud (red before push), and it teaches the fix (it
names the lane and the brain it expected). it is the guard owed by c11b: a family change cannot
ship silently.
