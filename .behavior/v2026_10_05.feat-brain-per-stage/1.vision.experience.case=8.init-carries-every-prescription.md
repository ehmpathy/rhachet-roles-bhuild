# case=8 · init carries every prescription

feel = happy · care = critipath

## .narrative

i am the initiator. i run `rhx init.behavior --name fix-tax-round --size nano` for a small fix, then
`--size mini` for a feature, and later that week `--size giga --guard heavy` for a large one.

i do not open a guard, and i run no step after init. each route carries its brains already: every
guard init wrote declares one, and the brain each declares matches its stage — opus on each design
guard the route ships (vision always; blueprint from mini; distill from medi; criteria only under
heavy), sonnet on each build guard (execution and verification always; roadmap and playtest from
mini; evaluation from medi). a design stone with no guard — light criteria, the research stones —
inherits opus. the mini and giga trees list `4.1.roadmap.guard`; the nano tree
does not, since nano has no roadmap.

what i see at init is only one more file in a mini+ tree. what i get is a route that switches to
the cheaper brain at the right stone, with naught to remember: when the driver enters `1.vision`,
bhrain dispatches opus, from the prescription init wrote.

## .timeline

```
given('[case8] an initiator in a repo on bhuild with this change, and bhrain ≥0.39')
  when('[t0] init.behavior --size nano runs')
    then('every guard init writes declares a brain: opus on 1.vision, sonnet on 5.1.execution.from_vision and 5.3.verification')
    then('the created list holds no 4.1.roadmap.guard (nano has no roadmap)')
  when('[t1] init.behavior --size mini runs')
    then('every guard init writes declares a brain; design guards declare claude-opus-5-5[1m], build guards claude-sonnet-5-5[1m]')
    then('the created list includes 4.1.roadmap.guard')
  when('[t2] init.behavior --size giga --guard heavy runs')
    then('every guard init writes declares a brain, heavy 2.1.criteria included; design guards opus, build guards sonnet')
    then('the created list includes 4.1.roadmap.guard')
  when('[t3] an enrolled driver enters 1.vision on any of the three routes')
    then('bhrain dispatches /model claude-opus-5-5[1m] — the prescription init wrote lands')
```

## .why it holds

the templates are the source and init copies them verbatim (suffix stripped). so the prescription
reaches every size and variant with no new init logic. this case samples three sizes; the walk test
(`case=5`) sweeps all 10 size × variant pairs.
