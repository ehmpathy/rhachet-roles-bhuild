# case=8 — a fixture that moves without its test turns a clamp red

**feel:** sharp · **care:** critipath (every promotion crosses it; an orphan fixture is a cure the
package claims and never tests — silent, and it compounds per delta)

the wish says *"a fixture that moves without its test, or a test that moves without its fixture,
does not count."* today naught enforces that. this tree adds a clamp so it holds by construction,
for this delta and each one after.

## .narrative

the maintainer of the next delta copies 30 new pane fixtures and ports 28 of their test cases; two
cases sit in a split suite they missed. the package test run goes red: two fixtures under
`.test/.assets/` are named by no test, and the failure lists them. the maintainer ports the two
cases; the clamp goes green. the reverse — a test that names a fixture absent from `.test/.assets/`
— already fails on its own read, and the clamp names it too.

## .timeline (sketch)

```
given the published supervisor's `skills/work/.test/.assets/` and its integration suites
  when [t0] every fixture file is named by at least one test
    then the clamp passes
  when [t1] a fixture is added that no test names
    then the clamp fails and lists that fixture by name
  when [t2] a test names a fixture that is absent
    then the clamp fails and lists the test and the absent name
```

## .fails safe

fast (a file-read test, no shell), loud (lists each orphan by path), and it teaches the fix (port
the case, or drop the fixture). per `rule.require.clamp-edge-cases`, it is proven to bite: remove
one test reference, see it red; restore, see it green.
