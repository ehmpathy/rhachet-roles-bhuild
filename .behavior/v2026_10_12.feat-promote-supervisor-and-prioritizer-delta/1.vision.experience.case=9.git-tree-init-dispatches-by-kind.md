# case=9 — `git.tree.init` sprouts a tree by kind

**feel:** happy, with two sharp edges · **care:** critipath (every sprout enters here; a supervisor
with an old script must not break on upgrade)

ruled by the wisher, 2026-10-13: `git.tree.init behavior` replaces `git.tree.behavior`, so new kinds
(`repair`, `goal`, …) extend one verb. shape calls in F7.

## .narrative

the supervisor clone needs a tree for lesson-reminder sms. it runs
`rhx git.tree.init behavior --name beav/feat-lesson-reminders --size nano --wish @stdin`, and the tree
sprouts with a bound behavior, the same as before. a week later a declapract upgrade is due; it runs
`rhx git.tree.init declapract.upgrade --name beav/feat-declapract-upgrade`, and that tree boots the
upgrade route instead. it mistypes a kind, `git.tree.init repair`; the verb refuses, names the kinds
it knows, and sprouts naught. an old script in bert's repo still calls `rhx git.tree.behavior …`; it
works, and prints one line that names the new verb.

## .timeline (sketch)

```
given a published supervisor in a consumer repo
  when [t0] the clone runs `rhx git.tree.init behavior --name beav/feat-lesson-reminders --size nano --wish @stdin`
    then a tree sprouts with a behavior route bound from the wish
  when [t1] the clone runs `rhx git.tree.init declapract.upgrade --name beav/feat-declapract-upgrade`
    then a tree sprouts and boots the declapract upgrade route, no behavior
  when [t2] the clone runs `rhx git.tree.init repair --name beav/fix-x`
    then it exits 2: unknown kind 'repair'
    then it lists the known kinds: behavior · declapract.upgrade
    then no tree is sprouted
  when [t3] the clone runs `rhx git.tree.init` with no kind, or `--help`
    then it prints the usage and the known kinds
  when [t4] a script runs the old `rhx git.tree.behavior --name … --size nano --wish @stdin`
    then stderr carries one line: `🌙 git.tree.behavior is now git.tree.init behavior`
    then the same tree sprouts, with the same exit code as [t0]
  when [t5] the clone runs `rhx git.tree.init behavior --name beav/feat-declapract-x …`
    then it refuses a declapract name and points at `git.tree.init declapract.upgrade`
```

## .fails safe

an unknown kind refuses before any tree work and teaches the fix (the list of kinds). the old names
keep working for one release, so the rename cannot break a consumer on upgrade; the nudge tells them
where to move.
