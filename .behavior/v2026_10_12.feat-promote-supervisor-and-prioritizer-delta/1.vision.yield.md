# 1.vision — the published supervisor and prioritizer match their source again

## .the outcome world

### before

a clone boots `role=supervisor` from this package. it asks to sprout a `mini` behavior and the
sprout lands — no meter stops it, though its source learned on 2026-09-27 that this spends a
human's budget on a guess. it asks *"which trees exist for repo X?"* and finds no verb. it reads a
pane where a weekly-limit menu sits on screen and classifies it as an ask. each of those defects
was fixed once, in the source notebook, and the fix never reached the package.

a clone boots `role=prioritizer`. `eco.priority get` ranks rows by sev and gain. a trivial
two-day upgrade sits below a complex 34-day rewrite of equal rung, and no column says which is
which.

### after

the same clone, same commands, published roles only:

## .mental model

> *"the package is a downstream mirror of the notebook's supervisor. every so often you pull the
> notebook's fixes down, scrub them, and the mirror catches up."*

- **analogy:** an upstream-to-vendored-fork rebase. the fork carries its own patches (layout,
  scrub, test splits); each sync replays upstream's commits on top, never a copy-over.
- **their words vs ours:** a human says *"pull the new supervisor stuff into bhuild"*; the tree
  says *promotion* and *delta*. same act.

| goal (from the wish) | how this meets it |

| same tools, briefs, clamps as nheuron | every one of 116 files gets a verdict; 112 promoted, 4 stay |

| dream backlog (found by the completeness audit) | the 26 new or edited nheuron dreams get the same issue → verdict → artifact table: cured (fixture + test cited), still open (ported, scrubbed), or nheuron-only (reason) |

**pros** — a cheap, measured catch-up; each change is already a production cure; the three-way
port keeps the lift's adaptations.

**cons** — 40 fixtures with private names must be scrubbed byte-carefully (see fulcrum F2); the
split suites mean the test delta cannot be applied as one patch; the delta is large enough
(~20k lines) that review lanes may overflow.

**edgecases and their pit of success**

- a fixture scrub that changes a line's width could mask or fake a width-mismatch cure →
  substitute same-length names (F2), and the cure's own test is the proof
- the sponsor skill's source default is a real person → no default ships. a human records the
  sponsor once in `.meter/git.crew.commit.sponsor.json` via a new `set` subverb; an absent record
  fails loud and names that command (case 6, F1 — ruled by the wisher)
- a ported skill that still reads `.agent/repo=.this/` → case 2 runs from a repo that has none
- **11 of the 40 fixtures are orphans in the source** — named by no source test, cited only as
  brief evidence. each gets a test case written here, or does not move (F5). the source gap goes in
  the yield with evidence
- **the size gate's settings-deny is a stale claim** — no tracked file in either repo denies the
  clone `allow`. the package now ships it (F6 — ruled by the wisher): a new supervisor
  `inits/init.claude.permissions.jsonc` denies the clone `git.tree.size.uses allow|revoke`,
  `git.crew.commit.sponsor set` and its `--sponsor` override, and Edit/Write on both meter files. the tty guard stays inside
  each skill as the second wall; the stale header is corrected
- **private names the clamp does not know** → added to `TERMS_FORBIDDEN` **before** the port, per
  `rule.forbid.private-business-in-published-roles`. measured in the delta's added lines:

  | kind | terms | hits |

  | an initiative | `ghavel` | 16 |

## .what is awkward

- the **fixtures** fight the scrub rule. a verbatim capture is evidence precisely because it is
  verbatim; a scrub makes it a faithful forgery. same-length substitution keeps the shape the
  classifier reads, and the cure's test still proves the cure
- the **commit-sponsor** skill exists to remove a hand-typed identity, and its source answer is a
  hardcoded identity. the package version must reach the same goal with no identity in the code
- the **split suites** turn one source test diff into many target edits. it is honest work, but
  it is where a case can be dropped unnoticed — so the yield counts `then` blocks source vs
  published per suite
