## .what

measure how many crews the fleet can afford to run at once, and what would let it run more.

done = a measured answer, per grove (local, grove-ahbode-v20260901) and per account (local's own, jelly@ehmpath.com on 0901):

1. how many **behavior crews** (a driver, a reflector, and the clone's forks) we can afford to run concurrently
2. how many **directive crews** (a director seat, its observer, its forks) we can afford to run concurrently
3. the **ranked levers** that raise efficiency, each with its measured or estimated gain in crews, so we can raise parallelism

## .the two ceilings to measure

- **tokens**: each account's weekly and 5h caps vs the burn per crew-hour, by crew kind. a crew at a gate burns little; a crew at a review ladder burns a lot. measure both
- **grove**: cpu, ram, and forks/s per live clone. local read 🔴 at load 33–45 on 12 cores with ~41 sessions on 2026-10-20; ram ran low enough that claude code killed a background job

the affordable count is the lower of the two, per grove.

## .the evidence at hand

- `rhx git.crew.tokens` (this repo, role=any) meters the 3h burn per seat. it is blind to crews under `~/git/<org>/_worktrees`, the cloud grove, and workflow agents, carries no cost weight and no % of cap, and died with EPIPE under load on 2026-10-20. cure it first, or measure around it, and say which
- 1h window, 2026-10-20 16:32Z: 110.5M tokens over 13 nheuron seats; the surdirector 70.6M (64%), its 8 forks 57.6M. cache.write (a fork writes its parent's whole context fresh) was about half the cost-weighted spend
- local spend hunts: claude.exe and its bash children carry ~57% of the box; hook chains (sh → rhx → bun → bash, ~4 per tool call) are the fork driver (ehmpathy/rhachet-roles-bhuild#514)

## .the candidate levers, to rank with numbers

- hooks via one local server and `if`-scoped hooks (bhuild#514, rhachet#635)
- tmux control mode, ssh connection reuse, kitty socket (bhuild#515, #516, #517)
- status line from a json written ahead (bhrain#660)
- a fork cap per seat; forks that start from a small context rather than the parent's
- park a crew at a human gate (it spends naught while idle) and move the slot to the next unblocked crew
- per-role boot budgets (rhachet-roles-ehmpathy#1002)

## .why

the org p1 is cost. the commander wants to see exactly how much concurrency we can afford and what raises it.
