# case=6 · a supervisor's day across the forest — the dense walk

covers: R2, R3, R5, C1, G4, G2, G1, K2, V1 · feel: sharp (dominant — six of its nine
boundaries are refusals; each constituent's own feel is in the inventory) · care: critipath
density: **9 boundaries in one walk** — the experience to center. the sharp critipaths inside it
keep their own spotlights (case=2, 3, 4, 5) so each fail-safe stays legible. it does not walk
R1 (a whole, calibrated read); case=1 does.

## .narrative

the supervisor starts its first tick. 0901 hibernated overnight; one felled crew left an
unreadable actor dir on local; local's account was calibrated yesterday from one cap read only.

it reads the forest. local prints, with burn marked a floor and the unread dir named. 0901
prints 💤. local's token rows read ⚪ — one cap read is not a calibration — so it runs the
calibrate step's second read, an hour of burn after the first, and the token rows fill in.

it holds two wishes to dispatch. it asks for a slot on 0901 and is refused: the grove is
unread. it wakes 0901 and asks again: 0 slots, ram binds, two fellable crews named. it fells
one, asks again, gets a slot, and sprouts. the second wish goes to local, which has a slot.

at the weekly read the commander sees the start-forks-small lever at `+0 crews` on both groves
— neither binds on tokens — and funds the fork cap. a week later the supervisor's second read
of the fork cap — a before/after now that the cap has landed, under a heavier fleet — agrees
with the estimate's direction, and its row moves from `estimated` to `measured`.

## .bdd sketch

```
given('[case1] 0901 asleep; one unreadable actor dir on local; local has one cap read')
  when('[t0] `rhx git.grove.capacity`')
    then('local prints; its burn row reads as a floor and names the unread dir')     # partial-read
    then('0901 prints 💤 unread; the sweep does not wait on it')                     # asleep grove
    then('local token rows read ⚪ uncalibrated — one cap read is not enough')       # calibration
  when('[t1] `rhx git.crew.tokens calibrate --account local` (second read, after ~1h burn)')
    then('tokens-per-% derives; local token rows print counts')                      # calibration
  when('[t2] `--grove cloud://0901 --for behavior`')
    then('exit 2: unread grove, no slot granted; the wake command is named')         # forbidden G4
  when('[t3] after `rhx git.grove.wake cloud://0901`, the same ask')
    then('exit 2: 0 slots, ram binds; two fellable crews named; seed named')         # gate refusal
  when('[t4] after `rhx git.crew.fell --tree <done>`, the same ask')
    then('exit 0: 1 slot')                                                           # gate grant
  when('[t5] `--levers`')
    then('start-forks-small reads +0 crews on both groves, beside its token cut')    # wrong-axis lever
  when('[t6] a before/after read of the landed fork cap, a week on, under a heavier fleet')
    then('the fork cap row moves from estimated to measured')                        # verify
```
