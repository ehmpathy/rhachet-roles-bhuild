# case=1 · the commander reads the forest's capacity

covers: R1 · feel: happy · care: critipath

## .narrative

the commander opens a terminal on a quiet day and asks the one question: how many crews can we
afford right now, and which wall do we hit first?

one call. it reads every grove in parallel, each under its own timeout, and every claude
config dir on each — `~/.claude` and each worktree's `.agent/.actors/*/brain/.claude`. it
sums the burn per crew-hour by kind and state, reads each account's 5h and 7d cap %, reads
each grove's ram and cpu stall, and prints one block per grove.

the commander sees that local can carry 5 behavior crews and is bound by cpu, while the 0901
grove can carry 4 and is bound by ram — not by tokens, which had more headroom than either.
the last line names the exchange rate: one directive crew costs what ~9 behavior crews do. the
commander now knows the director seats are what to plan around.

## .bdd sketch

```
given('[case1] two groves, both accounts calibrated, every config dir readable')
  when('[t0] the commander runs `rhx git.grove.capacity`')
    then('one block prints per grove, each with its account')
    then('each grove names four limits per crew kind: tokens.5h, tokens.7d, grove.ram, grove.cpu')
    then('the lowest limit is marked 🔴 binds, and the affordable count equals it')
    then('burn is cost-weighted, and the weights are named once in the footer')
    then('the exchange rate between directive and behavior crews prints per axis')
    then('no grove waits on another; the slowest grove sets wall time, not the sum')
```
