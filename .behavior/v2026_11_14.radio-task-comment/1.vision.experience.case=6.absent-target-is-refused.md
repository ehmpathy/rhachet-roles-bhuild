## .narrative

a clone pushes a comment onto #9999 in `sandpine/svc-lessons`. no such issue exists — a typo for
#999.

```
🎙️ radio.task.comment
   ├─ act: comment on #9999
   └─ ⛔ refused — issue #9999 not found in sandpine/svc-lessons
      └─ fix: check the number; a push with the right --exid is a new comment
```

naught is posted. the record settles REFUSED — the same fate an absent `--exid` update meets today
— so no drain retries it. the queue's halt scope applies unchanged: where gh says the **repo**
cannot be reached (an auth that cannot see it), the record is set aside as `upstream:not-found`,
since another auth may reach it; where the repo is reachable and the **issue** is absent, it is
refused.
