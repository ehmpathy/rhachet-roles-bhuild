# case=7 — os.fileops appends an entry

feel · care: happy · critipath (inventory rows 7, 8, 10, 18). #567 owes the os.fileops form
explicitly, and a local clone on `--via os.fileops` has no other route for a comment if it breaks.
it is also the channel the tests drive end to end with no network.

## .narrative

a clone works a local task queue (`--via os.fileops --into @this`). task `7` is claimed. a
second clone adds a note:

```sh
echo "the swell model moved to v3" | rhx radio.task.comment --via os.fileops --into @this --exid 7 --comment @stdin
```

the task file is untouched. one entry is appended to the task's comment log, a file beside it
under `.radio/`, oldest first. a reader opens that file to see the thread. (a pull that renders
comments was asked by no one; it is out of scope.)

a repeat of the same body appends naught (`kept`). a comment onto task `99`, which does not exist,
is refused with `task not found`, and no log file appears for it.

## .bdd sketch

```
given('[case7] an open gate; os.fileops task 7 exists')
  when('[t0] a comment is pushed onto task 7')
    then('the task file is byte-identical to before')
    then('the comment log beside it holds one entry with the body')
  when('[t1] the same comment is pushed again')
    then('the log still holds one entry; stdout says kept')
  when('[t2] a comment is pushed onto task 99, which does not exist')
    then('the record settles REFUSED: task not found')
    then('no comment log for task 99 is created')
given('[case7b] radio blocked for this repo; os.fileops task 7 exists')
  when('[t3] a comment is pushed onto task 7')
    then('the record is held QUEUED, reason gate; exit 2')
    then('the comment log is byte-identical to before')   # the os.fileops twin of case=2's clamp
```
