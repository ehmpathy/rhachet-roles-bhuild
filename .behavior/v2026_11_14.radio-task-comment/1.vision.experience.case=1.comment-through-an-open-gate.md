# case=1 — comment through an open gate

feel · care: happy · critipath (inventory row 1)

## .narrative

a director dispatched task #640 to `sandpine/svc-lessons` an hour ago: *"lesson reminders skip
the tide window"*. it now learns the cure is wrong — the window is computed in utc, not local
time. it does not want a second task, and it must not rewrite the commander's body.

```sh
cat correction.md | rhx radio.task.comment --via gh.issues --into sandpine/svc-lessons --exid 640 --comment @stdin
```

the radio records the push, meets the gate (open), and posts one comment on #640. the body,
the title, and the status of #640 are byte-identical to before. the output names the comment's
url, so the director can cite it.

```

```

given('[case1] an open gate and a radio task #640')
