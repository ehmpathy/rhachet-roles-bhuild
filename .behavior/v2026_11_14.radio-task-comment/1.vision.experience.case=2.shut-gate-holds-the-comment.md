# case=2 — a shut gate holds the comment

feel · care: sharp · critipath (inventory rows 12, 13, 14, 32, 41). the center: the densest walk.

## .narrative

open hours. the commander has blocked radio globally (`radio.uses --global block`). a director
must amend ehmpathy/rhachet-roles-bhuild#489 — the exact incident from #567, where a raw
`gh.issue.comment` wrapper posted straight past the block. #489 is a thread a human opened, not a
radio task.

now the director has one path, and it obeys the gate:

```sh
cat amend.md | rhx radio.task.comment --via gh.issues --into ehmpathy/rhachet-roles-bhuild --exid 489 --comment @stdin
```

```
🎙️ radio.task.comment
   ├─ act: comment on #489
   └─ ✋ held — radio blocked (global)
      ├─ naught sent; recorded in .behavior/.radio/
      ├─ see what waits: rhx radio.task.queue get
      └─ lift (human): rhx radio.uses --global allow
```

exit 2. github sees no call at all.

the director reads the queue: the comment sits beside two held task pushes, in push order.

```
🎙️ radio.task.queue get
   ├─ 3f9a1c… · ehmpathy/rhachet-roles-bhuild · create "fix: …"     · held: gate (global)
   ├─ 8b20d4… · ehmpathy/rhachet-roles-bhuild · update #601 CLAIMED · held: gate (global)
   └─ c71e09… · ehmpathy/rhachet-roles-bhuild · comment on #489     · held: gate (global)
```

still blocked, the director adds a note to its own radio task #640, then — unsure the first push
took — runs it again. the second run lands on the same held record: one record, not two.

after hours, the commander lifts the block. the next push — any push, of any act — gets through
and drains the backlog oldest first. each comment lands in its own place.

the gate reads only the target repo, never the kind of thread, so the foreign thread (#489) and the
radio task (#640) are held alike.

## .bdd sketch

```
given('[case2] radio blocked globally; two task pushes already held')
  when('[t0] a comment is pushed onto #489, a foreign thread')
    then('the record is written QUEUED, kind comment, reason gate')

    then('exit 2')
  when('[t1] the queue is read')
    then('the comment shows beside the held tasks, labeled "comment on #489"')
  when('[t3] a comment is pushed onto #640, a radio task')
    then('it is held QUEUED too; no gh call is made')
  when('[t4] the same comment is pushed onto #640 again')
    then('it lands on the extant held record (same key); the queue still holds one #640 comment')
  when('[t2] the gate opens and a later push gets through')
    then('the backlog delivers oldest first: create, update, the #489 comment, the #640 comment')
    then('one comment lands on each thread; each record settles DELIVERED')
```
