# case=5 — a malformed comment push is refused, before it is recorded

feel · care: sharp · critipath (inventory rows 27–31)

## .narrative

a clone types `--comment` but forgets the target:

```sh
echo "the cure is wrong" | rhx radio.task.comment --via gh.issues --into @this --comment @stdin
```

```
✋ ConstraintError: --comment needs --exid <n>: a comment amends an extant task
   └─ fix: rhx radio.task.comment --via gh.issues --into @this --exid <n> --comment @stdin
```

exit 2. no record is written: a call the radio could never send never enters the ledger.

the same refusal, each with its own fix:

| call | refusal |
|---|---|
| `--exid 640 --comment … --title …` (or `--description`) | `radio.task.comment` does not read `--title` or `--description`: refused, with the fix "to create or rewrite a task, use `rhx radio.task.push`" |
| `--exid 640 --comment … --status CLAIMED` | `radio.task.comment` does not read `--status`: refused, with the fix "a status change is `rhx radio.task.push --exid 640 --status …`" |
| `--exid 640 --comment ''` (or empty stdin) | a comment needs a body |
| `--exid 640 --comment … --idem upsert` | a comment is append-only; there is no upsert of a comment (`--idem findsert` is accepted — it is the comment's only mode, always on) |

## .bdd sketch

```
given('[case5] any gate state')
  when('[t0] --comment without --exid')
    then('exit 2; stderr names --exid <n>')
    then('no record is written')
  when('[t1] --comment with --title')
    then('exit 2; stderr names one act per push')
  when('[t2] --comment with --status')
    then('exit 2')
  when('[t3] --comment with an empty body')
    then('exit 2; stderr names the absent body')
  when('[t4] --comment with --idem upsert')
    then('exit 2; stderr names append-only')
  then('across [t0]..[t4], no record file is written')
```
