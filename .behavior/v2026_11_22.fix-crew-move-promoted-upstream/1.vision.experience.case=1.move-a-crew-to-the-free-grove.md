# case=1 — move a crew to the free grove

happy × critipath, and the densest walk: one realistic session, six boundaries. case=2 and case=3 spotlight the two sharp critipaths inside it, so their fail-safe stays legible.

## .narrative

the laptop's claude account hits its weekly cap, and every crew it feeds stalls. hetzner holds free seats on another account. the operator plans the move, and the plan refuses: the mechanic is mid-turn, and the refusal names the read that shows when the turn ends. they wait and plan again. this time the plan names what hetzner must settle first: an older copy of the branch, left behind by an earlier life of the tree, sits behind the head and will fast-forward. naught has changed yet. they apply with a why. the branch settles and reads back at the head; the tree rises; the dirty bytes land and prove by sha256; the transcripts land where `--resume` looks; the ledger row moves. the mechanic resumes live, but the foreman comes up a bare shell: the apply says so, says the tree and ledger moved, prints the one boot command that resumes the foreman, and exits 1. the operator runs it. verify proves the whole move. on hetzner each seat's bar names its tree, the same as on the laptop, and stays put when a seat shell `cd`s elsewhere.

## .timeline

```
given a crew svc-lessons.beav.feat-book-a-lesson on local, mechanic + foreman with transcripts
  and on hetzner an old local branch beav/feat-book-a-lesson, an ancestor of the head
when [t0] rhx git.crew.move --tree svc-lessons.beav.feat-book-a-lesson --to cloud://grove-sandpine-hetzner-v20261119
  then exit 2: seat mechanic is busy mid-turn at the source; fix: rhx git.crew.read --tree ... --who mechanic   # rejection
when [t1] the turn ends; the same plan runs
  then exit 0; naught changes; the plan prints settle: fast-forward beav/feat-book-a-lesson <old> -> <head>    # seam: stale dest
when [t2] ... --mode apply --why 'weekly cap on local'
  then the branch settles and reads back at the head; tree, dirt, and transcripts land and prove              # carry proof
  then the ledger row names hetzner; mechanic is up, resumed, a live claude
  then 💥 foreman: the boot returned, but the seat holds no live claude; cure: rhx git.crew.boot ... --roles foreman --resume foreman; exit 1   # husk
when [t3] the operator runs the cure, then ... --mode verify
  then head, branch, dirty sha256, ledger, and a live claude per seat all hold; exit 0
when [t4] rhx tmux.bar.probe on hetzner
  then each seat's bar shows svc-lessons · beav/feat-book-a-lesson, pinned to duct: yes                      # bar stamped at raise
when [t5] a seat shell cds into another repo and draws a prompt
  then the bar still names the duct's tree                                                                    # hook drift
```

the reverse move (`--to local`) is `case=6.carry-a-crew-home`.
