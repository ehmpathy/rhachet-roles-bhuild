# case=3 — a seat that did not come up names its cure

sharp × critipath. a boot that exits 0 can leave a bare shell where a resumed claude is owed, or leave no duct at all; a move that called either "up" would strand the crew silently.

## .narrative

the operator applies the move and watches the seats step. the mechanic comes up live, but the foreman row turns 💥: its pane is a bare shell, though it had a transcript to resume. the operator reads on: the tree and the ledger moved, so naught is lost, and the next line is the exact boot command for that one seat. they paste it, then run verify, which had named the foreman as the miss; now it reads every seat live. had the foreman held no transcript, it would have come up bare by plan, and the operator would see it pass.

on a later move, the reflector row turns 💥 a different way: no duct stands for it on the grove at all, so there is no pane to read and no bar to stamp. verify names the miss with a fresh boot as its cure, not a resume. the operator runs it; the boot opens the duct, the bar is stamped at birth, and verify reads the seat live.

## .timeline

```
given a move whose foreman seat holds a transcript
when [t0] the operator applies, and the foreman boot leaves a bare shell
  then the seat row reads 💥 foreman: the boot returned, but the seat holds no live claude (a bare shell)
  then 💥 1 seat(s) left as a bare shell at <grove>. the tree and the ledger moved; cure each:
  then the cure line names: rhx git.crew.boot --tree <tree> --grove <grove> --roles foreman --resume foreman
  then exit 1
when [t1] the operator runs the cure, then verify
  then verify exits 0
given a move whose reflector seat ends with no duct on the destination grove
when [t2] the operator applies
  then the seat row reads 💥 reflector: no duct stands at <grove>; exit 1
when [t3] the operator runs verify
  then ✗ seat reflector: no duct stands at <grove> — cure: rhx git.crew.boot --tree <tree> --grove <grove> --roles reflector
  and  once the operator runs that boot, its duct.open prints 🏷️ status box — <repo> · <branch>, and verify exits 0
```
