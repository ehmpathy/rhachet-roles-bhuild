# experience dimensions — git.crew.move + the duct-owned bar

actor: the operator (a human or a director clone) who moves a crew, then reads its seats' bars.

| axis | positions | why it varies the experience |
|---|---|---|
| direction | local→cloud · cloud→local · cloud→cloud (relayed through the caller) · same end (the tree is already where `--to` points) | which box relays bytes; which bar the operator reads; or naught to move |
| grove reachability, at each end | registered and up · unregistered · registered but down | judge the move, refuse it (exit 2), or say naught was judged (exit 1) |
| destination state | repo absent (never cloned there) · clean · stale branch (ff · rebase twin · no twin) · stale twin worktree (safe · holds work) · extant tree to merge into | clone, settle, refuse, or merge |
| source seat state | idle · paused · busy mid-turn · text in box | move or refuse |
| destination seat outcome | live claude · bare by plan (no transcript) · husk (bare, transcript owed) · no duct | exit 0 or exit 1 with a cure |
| seat raise path (the duct verb it passes) | `duct.open` created (hire, fresh boot) · `duct.open` found (`--resume`, a move) · `duct.reboot` (`crew.reboot`) · `duct.refresh` (heal, view repaint, a duct opened before the pin) | which verb must stamp the bar |
| bar life after the stamp | local · on a grove over ssh · a branch with shell syntax · a split window · a home gone · a branch switched · a relative or doubled refresh flag | the bar holds its tree, says why it could not, or the call is refused |
| guard | tree org in the allowlist · outside it · a local-only repo onto cloud · held grove | refuse ahead of any box read |
| concurrency | one move · two moves of one tree at once · a move that races a seat raise on the same tree | one result, or two writers on one tree |
| carry step outcome, at the destination | carry proof holds · carry proof fails · a git `post-checkout` hook fails · install holds · install fails (racy `ENOENT` retried once · `ENOENT` every run · lockfile break · patch on a read-only dir · the tree's own prepare hook · a dependency's hook · hooks off, fails too) · build first (a self-hosted tree whose hook needs a `dist`) · role link refused · transcript unplaced · `.claude` link to settle (relink · drop and rerun · none) · bar stamp missed | the step halts loud with its own cure, recovers once and says so, or the seats stand with a repaint owed |
| read verdict | read · unread (no answer: a seat read, a tree digest read) · a read with transport noise beside it · a destination-only path (`.agent/.cache`) at verify | a verdict, or "unread", never "down" nor "the ends differ" |
| call shape | well formed · mistyped flag · flag with no value (or the next flag as its value) · reason under three words · two flags that cannot join | the call runs, or exit 2 names the flag at fault and every valid one |
