# case=4 — every raised seat owns its bar

happy × critipath. the wish's bar gap: a seat raised by `boot --resume` drew a blank or wrong bar on hetzner. the cure puts the stamp in the four duct-verb paths every raise passes, so this case walks each.

## .narrative

a hetzner seat husks; the operator heals it via `git.crew.boot --resume`. today the seat comes up with whatever bar its shell wrote at birth, or none. with the stamp in `duct.open`, the boot writes the duct's own `@duct_repo` / `@duct_branch`, read from the duct's home anchor, and pins the session bar to them. a later `cd` in a seat shell no longer relabels it.

the operator then hires a reflector into the same tree: a fresh duct, stamped at birth. a seat born before this release has no pin, so `git.crew.refresh` stamps it and re-anchors its home to the tree. and when a seat wedges, `crew.reboot` respawns its pane: the pin survives the respawn, and the reboot repaints it anyway. every path, the same bar. and where a boot could not stamp one, the move counts each miss in one line, with the refresh that repaints them, so a blank bar is never a silent one.

## .timeline

```
given a hetzner seat svc-lessons.beav.feat-book-a-lesson/mechanic, husked
when [t0] rhx git.crew.boot --tree svc-lessons.beav.feat-book-a-lesson --grove cloud://<hetzner> --roles mechanic --resume mechanic
  then the boot prints a status-box line: svc-lessons · beav/feat-book-a-lesson (pinned to the duct)
when [t1] rhx duct.bar.probe --session svc-lessons.beav.feat-book-a-lesson/mechanic
  then shown reads ` svc-lessons | beav/feat-book-a-lesson `; pinned to duct: yes
when [t2] a seat shell `cd`s into another repo and draws a prompt
  then the bar still reads the duct's tree
when [t3] rhx git.crew.boot --tree svc-lessons.beav.feat-book-a-lesson --grove cloud://<hetzner> --roles reflector
  then the fresh duct is created, and its bar reads svc-lessons · beav/feat-book-a-lesson at birth
given a seat foreman whose duct was opened before this release (no pin, no home anchor)
when [t4] rhx git.crew.refresh --tree svc-lessons.beav.feat-book-a-lesson --who foreman
  then duct.refresh --home sets the anchor from the tree's worktree (🏠 home anchor set), and stamps the bar
  and  a heal's wedge read (`git.crew.heal`, its duct.refresh repaint) stamps it too, silently
when [t5] rhx git.crew.reboot --tree svc-lessons.beav.feat-book-a-lesson --who mechanic
  then the pane respawns in place; the bar still reads svc-lessons · beav/feat-book-a-lesson
given a move whose seats boot at the destination, and two of their boots could not stamp the bar
when [t6] rhx git.crew.move --tree svc-lessons.beav.feat-book-a-lesson --to cloud://<hetzner> --mode apply
  then each boot says why its bar was not stamped, and the seats still stand
  and  one summary line counts the misses: 🟡 2 seat bar(s) NOT stamped … repaint the bars: rhx git.crew.refresh --tree svc-lessons.beav.feat-book-a-lesson
  and  a move whose every bar was stamped prints no such line (clamps: move case15b, case15c)
```
