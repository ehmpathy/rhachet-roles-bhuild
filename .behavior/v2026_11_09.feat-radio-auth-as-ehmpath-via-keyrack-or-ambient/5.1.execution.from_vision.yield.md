## .the defect found on the way

the case=7 guard failed on its first run: `command -v gh` resolved `/usr/bin/gh`, not the stub. under jest, node's child_process reads the host env when no `env` option is passed, never the sandbox `process.env` the code sees. so every `shx` call ran under the host PATH — the class of leak the wish names. the fix sits in `shx` (F10). the clamp is `getEhmpathTokenFromAmbient.integration.test.ts` case1: red before, green after.
