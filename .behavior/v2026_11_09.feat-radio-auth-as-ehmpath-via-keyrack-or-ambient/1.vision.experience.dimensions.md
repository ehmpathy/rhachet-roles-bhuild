# 1.vision.experience.dimensions

the experience space of a radio send that must find a github token. six orthogonal axes, each a closed set.

## .the axes

| # | axis | values |
|---|---|---|
| P | `--auth` presence | absent (the default applies) · supplied, recognized · supplied, unrecognized |
| A | `--auth` value, when supplied and recognized | `as-ehmpath` · `as-ehmpath-via-keyrack` · `as-ehmpath-via-ambient` · `as-human` · `as-robot:via-keyrack(owner)` · `as-robot:env(VAR)` · `as-robot:shx(cmd)` |
| K | keyrack status (owner `ehmpath`, env `prep`, key `EHMPATH_BEAVER_GITHUB_TOKEN`) | granted · absent · locked after the auto-unlock · blocked |
| E | ambient identity (`git config user.email`, effective in the repo) | ehmpath email · other email · unset |
| G | ambient gh login (`gh auth token`) | token · none |
| S | surface | live push · pull · `queue get` (shows a stored auth) · `queue set` (amends one) · `queue drain` (replays one) · `--help` |

`as-robot:*`'s parameters (owner, VAR, cmd) are not values of A: each form's parameter is an input the extant code already handles, and none changes under this wish.

## .the walked product

P=absent is the default, `as-robot:via-keyrack(ehmpath)`, unchanged — one cell. P=unrecognized is one cell: refused, lists every value. P=recognized opens A × K × E × G = 7 × 4 × 3 × 2 = 168 cells. a value reads only the spots it names, so most collapse:

| A | reads | distinct cells |
|---|---|---|
| `as-ehmpath-via-keyrack` | K | granted · absent · locked · blocked |
| `as-ehmpath-via-ambient` | E, G | E=ehmpath∧G=token · E=ehmpath∧G=none · E=other · E=unset |
| `as-ehmpath` | K, then E, G on a K non-grant | K=granted · K≠granted × {E=ehmpath∧G=token · E=ehmpath∧G=none · E=other · E=unset} |
| `as-human` | G, via gh itself | unchanged |
| `as-robot:*` (three forms) | its own source | unchanged |

the K non-grant cells (absent · locked · blocked) share one fall-through; they differ only in the keyrack line of the miss, which reuses the extant status-specific fix (`getKeyrackAuthFailureMessage`: absent → `keyrack set`, locked → `keyrack unlock`, blocked → `keyrack status`).

## .S — a deliberate collapse

every surface derives a token through one operation, `getGithubTokenByAuthArg`, from two call sites (`getOneRadioContextFromCliArgs` for push and pull; `getOneRadioContextForRecord` for drain). so A × K × E × G yields the same token on every send surface. S adds behavior on only four cells, and only those are walked per surface:

| S | what it adds |
|---|---|
| `queue drain` | the replay bar (`isRadioRecordAuthReplayable`): may a stored value run at all |
| `queue get` | the shown auth (`asRadioAuthShown`): how a stored value reads |
| `queue set` | the amend: a new value stored on a held record |
| `--help` | the value list |

⇒ the inventory walks every distinct cell: `1.vision.experience.case=_.md`.
