# case=7 — a test of the ambient path meets a stub gh, never the real one

feel: sharp · care: critipath (the wish's own bar; the prior draft leaked a real token to a log)

## .narrative

a mechanic writes the integration test for `as-ehmpath-via-ambient`. the code under test runs `gh auth token` through `shx`, which inherits `process.env` and takes no env of its own. so the test puts a stub `gh` in a temp dir and prepends that dir to the `PATH` the subprocess actually inherits — `process.env.PATH` for an in-process `shx`, the spawn env for a skill run. before it asserts aught, the test proves `command -v gh` inside that subprocess resolves to the stub. if a future edit drops the stub, the proof fails loud before any real gh is reached.

the git identity is isolated the same way: the test runs in a temp repo with its own `user.email`, and sets `GIT_CONFIG_GLOBAL` to an empty file and `GIT_CONFIG_NOSYSTEM=1` in that same subprocess env, so the "email unset" case never reads the mechanic's real address into a log or snapshot (`rule.forbid.real-identities-in-fixtures`).

unit tests never exec: they inject a fake `shx` that answers `gh auth token` and `git config user.email`.

## .timeline (sketch)

```
given('a temp dir with a stub gh that prints a fake token, prepended to the subprocess PATH')
  given('a temp repo whose git config user.email is an ehmpath email')
    when('[t0] the test runs the ambient derive through the real shx')
      then('command -v gh, run through the same shx, names the stub path')
      then('the token returned is the stub fake token')
      then('no log or snapshot holds a real token shape')
given('a stub gh that is absent from the subprocess PATH')
  when('[t1] the guard step runs')
    then('the test fails loud: "stub gh not on the subprocess PATH"; the derive never runs')
```
