## .what

teach the dispatcher to **enqueue** a radio task when `radio.uses` blocks the push, and to
**deliver** it once the block lifts — the `radio.recorder` of `ehmpathy/rhachet-roles-bhuild#319`.

today a blocked `radio.task.push` refuses and the task is gone, unless a human re-types it from
memory. that hits almost every worktree: a clone finds a followup, the radio is shut, the task dies.

## .the outcome

- every push attempt is **transcribed first** into the route's `.radio/`, so the local write is
  the transaction
- a blocked push leaves that record **QUEUED**, with the block as its reason — never an error that
  drops it
- the queue **drains itself**: the next push that gets through delivers the backlog first. if you
  can dispatch at all, the radio is open — no flag, no memory, no human needed to replay
- delivery is **idempotent**: a re-attempt never files a duplicate upstream
