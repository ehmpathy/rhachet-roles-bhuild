# case=1 — an open push, now with a record

cells: **C1**, **R1** · feel: happy · care: critipath

## .narrative

the radio is open. a clone pushes a task, as it does every day. the issue lands, just as today.
the one difference: the route now holds a record of it, marked DELIVERED with the issue number.
a reader of the route later sees what this route dispatched, and where it went, with no need to
ask *"what have we dispatched?"*.

## .timeline (sketch)

```
given('[case1] radio.uses allowed; route bound; backlog empty')

  when('[t0] the clone pushes a task')
    rhx radio.task.push --via gh.issues --into ehmpathy/rhachet --title "..." --description @stdin

    then('the task is transcribed into $route/.radio/ as QUEUED before the gate check')
    then('the gate reads open; the task is delivered upstream')
    then('the record is marked DELIVERED with the upstream exid')
    then('stdout matches today, plus the record path')
    then('exit code is 0')
```

## .why it matters

this is the most frequent cell by far — it must cost naught new. the one added line (the record
path) is the only visible change. if the happy path gets slower or noisier, the recorder has
taxed the common case to insure the rare one.
