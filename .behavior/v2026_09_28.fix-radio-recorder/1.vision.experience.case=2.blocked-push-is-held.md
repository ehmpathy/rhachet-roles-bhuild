# case=2 — a blocked push is held, not dropped

cells: **C7**, **C10**, **C11**, **C24**, **A1** · feel: sharp · care: critipath

## .narrative

a clone drives stone 5.1 of a route. it finds a defect in another repo — a flaky test in
`ehmpathy/rhachet`. it pushes a task. the human set `radio.uses --global block` at dawn.

today, the push refuses with a grant hint, and the task is gone. the clone mentions it in prose,
the session ends, and nobody re-types it.

with the recorder, the push writes the task into `$route/.radio/` first. then it meets the block.
it sends naught upstream. it says the task is held, why, how many now wait, and who can lift the
gate. the clone reads "held" and drives on — it has no more to do. an hour later it finds a second
defect and pushes it too. the count reads 2.

## .timeline (sketch)

```
given('[case2] radio.uses is blocked globally; the route is bound; the backlog is empty')

  when('[t0] the clone pushes a task')
    rhx radio.task.push --via gh.issues --into ehmpathy/rhachet \
      --title "fix flaky keyrack test" --description @stdin

    then('the task is transcribed into $route/.radio/ before any gate check')
    then('its record reads status=QUEUED, reason=radio.uses:blocked')
    then('no upstream call is made')
    then('stdout shows it held, not lost')
        🦫 held for the radio
           ├─ task   = fix flaky keyrack test
           ├─ into   = ehmpathy/rhachet
           ├─ status = QUEUED (radio.uses:blocked — global)
           ├─ backlog = 1 await the radio
           └─ lift it (human): rhx radio.uses --global allow
              then the next push delivers the backlog first
    then('exit code is 2 — a constraint, not a malfunction')

  when('[t1] the clone pushes a second task, still blocked')
    then('a second record is written; the first is untouched')
    then('stdout reads backlog = 2 await the radio')

  when('[t2] the clone re-pushes the first task verbatim')
    then('no third record is written — findsert on the held record')
    then('stdout reads backlog = 2, and names the extant record')

  when('[t3] the clone pipes a multi-line body via --description @stdin, still blocked (C24)')
    echo "line one\nline two" | rhx radio.task.push --via gh.issues --into ehmpathy/rhachet \
      --title "fix stale readme" --description @stdin

    then('the held record carries the whole piped body — both lines')
    then('exit code is 2, as [t0]')
```

`[t3]` is the edge transcribe-first creates: stdin must be read before the gate, or a held
record carries no body and the drain later files an empty issue. proven by
`skill.radio.task.recorder.acceptance.test.ts` `[case4]`.

## .why it is sharp and still safe

the actor hits a closed gate — that is the sharp edge. it fails safe: loud (exit 2), fast (no
network call), and it teaches the fix (the lift command, and the promise that the next push
delivers). the one move it must never make is to look like a loss — so the first word is **held**.

⚠️ exit 2 is a fulcrum (F3): a held task is arguably a success. see the yield.
