# case=8 — at stop, the clone reminds the human of held tasks

cells: **S2** (critipath), **S3** (alterpath), **S1**, **L2** (alterpath) · feel: happy · the fallback for A3

## .narrative

the clone held three tasks today; the radio stayed blocked. it finishes its route and stops. the
dispatcher's onStop hook reads the route's `.radio/`, sees three QUEUED records, checks each one's
gate against `radio.uses` — local files only, no network — and prints one line to the human: three
tasks wait, and here is the command that lifts the gate. the stop proceeds; the hook never holds it.

the human runs the lift. the next push, from any clone in the worktree, delivers the three. the
human was reminded at the one moment they were present, by the clone that held the tasks.

on another day the gate is already open but nobody pushed since. the same hook says so: three held,
the radio is open, the next push delivers them. and when no task is held, the hook prints naught.

a human who wants more than the one line asks: `rhx radio.task.held` lists each held task, its
target, and why it waits, then the one command that lifts the gate.

```
    then('it prints: 🦫 3 tasks held, the radio is open · next push delivers them')
    then('exit code is 0')

given('[case8] no record QUEUED')

  when('[t2] the clone stops (S1)')
    then('it prints naught — zero tokens')
    then('exit code is 0')

given('[case8] two records QUEUED; radio.uses blocked by the safe default')

  when('[t3] the human asks what is held (L2)')
    then('rhx radio.task.held prints the whole backlog, one row per task:')
        🦫 held for the radio
           ├─ fix flaky test → ehmpathy/rhachet (radio.uses:blocked — default)
           ├─ guard absent sponsor → ehmpathy/rhachet (radio.uses:blocked — default)
           ├─ lift it (human): rhx radio.uses allow
           └─ then the next push delivers the backlog first
    then('no record changes; naught is sent')
```

## .why a reminder, not a drain

the hook only reads and speaks. a drain at stop would send upstream from a hook — a hidden side
effect at a moment no one asked to dispatch. the push stays the one act that sends; the hook makes
sure the human knows a push is owed.
