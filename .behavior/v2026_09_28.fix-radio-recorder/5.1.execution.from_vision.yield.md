- [x] every push (open or blocked, create or update) upserts its record before the gate (X3)

### hold on a block
- [x] a shut gate: record stays QUEUED with reason `radio.uses:blocked — <level>`; no send; exit 2 (C7, U2)
      — the push reads its gate once; `setRadioTaskRecordHeldAtGate` is the one write for a
      shut gate, shared by the push and the drain step
- [x] held output: task, into, status, backlog count, lift command (rhx), place when unbound (case=2, case=6)
- [x] held detail drops the metadata json helpful-errors appends, yet keeps its `hint` as one more
      hint line when the body lacks it — `asRadioErrorDetail` + `asRadioErrorHint`
- [x] a record already DELIVERED meets a shut gate: "already delivered as #N", exit 0 (C9)

### drain on pass (contract item 2)
- [x] oldest first, across every `.radio/` under `.behavior/` (F4) — the op is named
      `setRadioTaskRecordsDrainedByPush`, so the worktree-wide drain shows at the call site;
      the dir walk lives in the record dao (`get.dirs`)
- [x] gate per record by its own target (X1, C20)
- [x] context per record from its own via + auth + target; auth fault holds as `upstream:auth` (C22)
- [x] upstream fault stops the drain, order kept, reason recorded (case=5) — the records behind
      the halt are persisted with the halter's reason, so the store matches what the drain printed
      (`setRadioTaskRecordHeldBehindHalt`, clamp proven to bite)
- [x] the drain walks its line with a promise fold and the heldSeq scan folds its max, so neither
      grows the call stack with the backlog
- [x] a refused replay closes as REFUSED, loud, never retried (case=7, U3) — refusal =
      a `BadRequestError` that is not a `ConstraintError` (a 401 is a `ConstraintError`, held)
- [x] the send-fault allowlist is closed: a `BadRequestError` (or its `ConstraintError` subclass),
      an exec error (string `cmd`), or an fs error (string `code` + `syscall` + `path`), the io
      ones recast as a `MalfunctionError` that names the io kind. an `UnexpectedCodePathError`,
      `MalfunctionError`, or any other value is a defect and fails loud
- [x] delivery via extant upstream findsert (X2)
- [x] a DELIVERED record is never re-sent, open gate or shut: the drain reads only the held
      queue, and a re-push reads `already delivered` beside any backlog it carried (C3, C6)
- [x] drain output: drained / pushed / refused / still held / backlog; each drained line names
      `held since <utc stamp>` (case=3, F11) and a lost mark reads `already upstream — marked delivered` (case=4);
      the header reads `the backlog is delivered` only when naught stays held, else `part of the backlog`
- [x] a failed transcribe write is a `MalfunctionError` (X3), any fault, cross-realm included

### remind at stop (contract item 3)
- [x] skill `radio.task.held` — lists held records; `--when hook.onStop` prints one line as a claude
      `systemMessage`, naught when none held, local files only (case=8); never exit 2 —
      `withStopHookNeverBlocks` prints a stop-hook constraint under its own `✋ ConstraintError:`
      header, once, and exits 1 (the glyph and the exit disagree on purpose, as in a PreToolUse hook)
- [x] a record held on an upstream fault behind an open gate is named as a fix (`fix: upstream:auth`),
      never "the radio is open" — `asRadioHeldUpstreamFaults`
- [x] the reminder loads the gate states once per call, then reads each record's gate from them
      (`asRadioTaskRecordLift`), so a larger backlog adds no permission file reads
- [x] dispatcher `onStop` hook entry — calls the cli export via `node -e`, not `rhachet run`:
      `rhachet run` prints its header to stdout, which would break the json claude parses
