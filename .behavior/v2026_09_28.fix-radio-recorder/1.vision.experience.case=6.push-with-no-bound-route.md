# case=6 — a push with no single bound route is still held

cells: **R2** (critipath), **R3** (alterpath) · feel: sharp

## .narrative

a human works on `main` in a repo with no route bound. they spot a bug in another repo and push a
task. the radio is blocked. the wish places the record in "the route's `.radio/`" — but there is
no route. to refuse would drop the task: the exact loss the wish exists to end.

so the push holds it in `.behavior/.radio/`, beside the routes. it says where, and that the next
push that gets through — from any route in this worktree — delivers it (F2, F4).

the same holds on a branch bound to two routes at once. `getBranchBehaviorBind` returns
`behaviorDir: null` when it finds more than one bind, so the push cannot pick one; it holds the
task in `.behavior/.radio/` and names the two binds, rather than a guess.

## .timeline (sketch)

```
given('[case6] no route bound to the branch; radio.uses blocked')

  when('[t0] the human pushes a task')
    then('the task is transcribed into .behavior/.radio/ as QUEUED')
    then('no upstream call is made')
    then('stdout reads held, and names the place')
        🦫 held for the radio
           ├─ status = QUEUED (radio.uses:blocked — local)
           ├─ held at .behavior/.radio/ (no route bound to this branch)
           └─ lift it (human): rhx radio.uses allow
    then('exit code is 2')

given('[case6] the branch is bound to two routes; radio.uses blocked')

  when('[t1] a clone pushes a task')
    then('the task is transcribed into .behavior/.radio/, not into either route')
    then('stdout names both binds, so the human can see why no route was chosen')

given('[case6] a record held in .behavior/.radio/; a route is bound later; radio allowed')

  when('[t2] a push from that route gets through')
    then('the drain delivers the .behavior/.radio/ record too')
```

## .why it is sharp and still safe

the actor pushed from a place the wish did not plan for. it fails safe: the task is held (never
dropped), the place is named (never hidden), and the drain reaches it (never orphaned).
