# case=5 — bot token absent, ambient absent (sharp · critipath)

## narrative

a fresh box: no keyrack token, no `GH_TOKEN`, no `GITHUB_TOKEN`, no gh login. there is no
credential to fall back to. the push holds the record (never lost) and the fault names both
credentials it tried and the fix for each, so the human knows the one command that unblocks.

## [tn] sketch

```
given keyrack reports the bot token absent
  and no GH_TOKEN or GITHUB_TOKEN in the env, and gh has no login
  when [t0] `rhx radio.task.push --via gh.issues --into sandpine/svc-lessons --title "..." --description "..."`
    then the record is held QUEUED with reason upstream:auth (exit 2)
    then the fault names both:
      ✋ ConstraintError: no github credential could deliver this task
         ├─ the ehmpath bot token: absent from keyrack
         │  └─ fix: rhx keyrack set --owner ehmpath --env prep --key EHMPATH_BEAVER_GITHUB_TOKEN
         └─ the ambient credential: no GH_TOKEN, no GITHUB_TOKEN, no gh login
            └─ fix: gh auth login
    then a later push or drain, once either is fixed, delivers it
```
