# case=8 — a director audits the mailbox (chosen alterpath)

cells: A1 · A2 · S25 · happy · alterpath

## .narrative

at day's end the director wants to check a crew's claim: "i told the foreman about the slot race
before i merged." it opens the crew tree's mailbox. every text is a plain json file, numbered in
order: who sent it, to whom, what it said, whether it was delivered, and which text it answers.
the claim holds or it does not, from the files alone.

for a rendered view, `phone.text get` shows the same files as a thread.

## .timeline

```
given('[case8] a crew tree whose mechanic mailbox holds four texts, and whose foreman mailbox holds two')

  when('[t0] a reader lists the mailbox dirs')
    $ tree .agent/.cache/repo=bhuild/role=dispatcher/skill=phone.text/

    then('one dir per clone, named by its serial; one file per text within it')
    then('the file name carries an internal ordinal, so ls order is send order')
    then('the ordinal is storage order only: no view prints it, no flag accepts it')

  when('[t1] the mechanic reads its thread')
    $ rhx phone.text get

    then('it shows its own four texts, in order: uuid alias, from, to, status, reason, and --re link')
    then('it shows none of the foreman texts: each clone reads only its own mailbox')

  when('[t2] a clone reads one text, by uuid alias or full uuid')
    $ rhx phone.text get --text a1b2c3d4
    $ rhx phone.text get --text a1b2c3d4-6e0f-4b9a-8c27-5d31f90e7a46

    then('both show the same text')

  when('[t3] a clone names a text by an ordinal')
    $ rhx phone.text get --text 3

    then('it exits 2: a text is named by its uuid, never by a number; the refusal shows the alias form')
```
