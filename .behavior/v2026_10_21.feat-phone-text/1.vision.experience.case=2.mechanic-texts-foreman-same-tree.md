# case=2 — a crew mechanic texts its foreman in the same tree

cells: S3 · S22 · S24 · S30 · S31 · P1 · P3 · plus S32 (chosen alterpath) · happy · critipath — #491's first done-test

## .narrative

the mechanic of the tree `svc-lessons.beav.feat-book-a-lesson` hits a judgment call: should a lesson slot that two surfers
book at once go to the first write, or be refused for both? it is the foreman's call, not its own.

the foreman runs in the same tree. it needs no contact: a clone in one's own tree is always
reachable, and its short address is just `@:foreman`.

the mechanic texts, and carries on with the parts that do not hang on the answer. the foreman is
mid-turn on a review; the text waits in its submit queue and it reads it when its turn ends. it
answers. the answer lands in the mechanic's session as a new message, which is how the mechanic
learns the call was made.

## .timeline

```
given('[case2] a crew tree with a live @:mechanic and a live @:foreman')

  when('[t0] the mechanic texts the foreman by short address')
    $ rhx phone.text set --to @:foreman \
        --what 'two surfers book one lesson slot at once: first write wins, or refuse both?'

    then('the text is accepted with no contact — the foreman is in the same tree')
    then('the call returns at once; the mechanic carries on')

  when('[t1] the daemon ticks while the foreman is mid-turn')
    then('clone say enqueues the text into the foreman queue; the record settles DELIVERED')
    then('the foreman reads it once its turn ends')

  when('[t2] the foreman replies')
    $ rhx phone.text set --to @:mechanic --re 3a8f5c12 --what 'first write wins; tell the second surfer at once.'

    then('the mechanic session shows the reply — the mechanic is notified')
    then('the mechanic mailbox holds 3a8f5c12 out and 91d7e4b3 in; the foreman mailbox holds the mirror, each DELIVERED once')
    then('one tree, two mailboxes: neither seat reads the other's texts beyond the ones it sent or got')
    then('--re names the uuid alias, the same as across trees; no reference ever names an ordinal')

  when('[t3] the foreman follows up with a multiline note, over stdin')
    $ printf 'slot race, the call:\n- first write wins\n- the second surfer hears at once\n' \
        | rhx phone.text set --to @:mechanic --re 3a8f5c12 --what @stdin

    then('the mechanic session shows the note whole, every line, as one message')
    then('no newline submits it early; the record holds the text byte for byte')

  when('[t4] the foreman sends an empty text')
    $ rhx phone.text set --to @:mechanic --what ''

    then('it exits 2: a text must hold words; no record is written')
```
