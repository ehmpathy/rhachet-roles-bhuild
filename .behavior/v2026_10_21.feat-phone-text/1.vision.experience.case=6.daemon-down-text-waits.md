# case=6 — the daemon is down; the text waits on disk and goes through once

cells: P8 · P10 · sharp · critipath — plus A4 (chosen alterpath)

## .narrative

the grove rebooted overnight. the director's tree came back, its clone came back, but its phone
daemon did not. the next day the director texts a crew.

the text is written to disk like any other — the file is the queue, the daemon is only a
courier. `phone.text` sees no daemon holds the tree's lock and starts one before it returns. the
new daemon finds every QUEUED file, oldest first, and delivers each once.

if the daemon dies mid-delivery, the record stays QUEUED until the say returns a verdict; a
restart picks up where it was. one tree, one daemon: a second start sees the lock and steps aside.

## .timeline

```
given('[case6] a tree with one QUEUED text from yesterday and no daemon')

  when('[t0] the director sends a new text')
    $ rhx phone.text set --to <crew address> --what '...'

    then('the new text is queued after the old one, in write order')
    then('phone.text starts the daemon, since none held the lock')
      💧 phone.text set
         ├─ ...
         └─ daemon: started (was down)

  when('[t1] the daemon ticks')
    then('both texts are delivered, oldest first, each once')

  when('[t2] a second daemon start is attempted in the same tree')
    $ rhx phone.daemon set

    then('it finds the live one and exits 0, no second courier')
```
