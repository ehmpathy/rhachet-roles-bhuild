# case=4 — a text to an unknown address is refused, loud, and names the fix

cells: S5 · S6 · S18 · sharp · critipath — the reach boundary and the address grammar invariants

## .narrative

a crew mechanic reads in a log that the `svc-forecast.beav.feat-tide-widget` tree has a mechanic who knows the tide
api well, and tries to text it. that mechanic is not in its contacts and not in its tree.

the phone refuses at once. no file is queued, no daemon wakes, the stranger never hears a word.
the refusal says why, lists who the mechanic *can* reach, and names the one command that grants a
contact — and who may run it: the booter, not the clone itself.

later the director tries a group text to three crews, and one address has a typo. the phone
refuses the whole group, names the one bad address, and queues none of the three. a half-sent
group would leave the director unsure who heard what.

## .timeline

```
given('[case4] a crew mechanic whose contacts hold only its director')

  when('[t0] the mechanic texts an address not in its contacts and not in its tree')
    $ rhx phone.text set --to phone://grove=bert-laptop/tree=svc-forecast.beav.feat-tide-widget/clone=mechanic --what 'how do you read the tide api?'

    then('it exits 2, a ConstraintError')
      ✋ ConstraintError: phone://grove=bert-laptop/tree=svc-forecast.beav.feat-tide-widget/clone=mechanic is not a known peer
         ├─ a clone may text only its contacts, or a clone in its own tree
         ├─ your contacts
         │  └─ phone://grove=bert-laptop/tree=notebook/clone=director
         ├─ your tree
         │  └─ @:foreman
         └─ to add a contact, the human or director that booted this tree runs
            └─ rhx phone.contacts set --address phone://grove=bert-laptop/tree=svc-forecast.beav.feat-tide-widget/clone=mechanic

    then('no text file is written; the mailbox is unchanged')

given('[case4b] a director with two of three group peers in contacts')

  when('[t1] the director texts a group where one address is unknown')
    $ rhx phone.text set --to <known-a> --to <known-b> --to phone://grove=bert-laptop/tree=svc-lesons.beav.feat-book-a-lesson/clone=mechanic --what '...'

    then('it exits 2 and names the one unknown address')
    then('none of the three is queued — a group is all or none')

  when('[t2] the address is malformed (an org/repo shape, no keys)')
    $ rhx phone.text set --to sandpine/svc-lessons --what '...'

    then('it exits 2 and shows the address grammar with an example')
      🦫 bummer, that's no address

      ✋ ConstraintError: sandpine/svc-lessons is not a phone address
         ├─ full:  phone://grove=<grove>/tree=<tree>/clone=<clone>
         ├─ e.g.   phone://grove=local/tree=svc-lessons.beav.feat-book-a-lesson/clone=mechanic
         └─ short: @:<clone>, for a clone in your own tree

    then('no text file is written')

  when('[t3] the keys come out of order')
    $ rhx phone.text set --to phone://tree=notebook/grove=bert-laptop/clone=director --what '...'

    then('it exits 2 and prints the one canonical form, so a peer never has two spellings')
      🦫 bummer, that address reads backwards

      ✋ ConstraintError: phone://tree=notebook/grove=bert-laptop/clone=director is not in canonical order
         ├─ the keys come in one order: grove, tree, clone
         └─ use: phone://grove=bert-laptop/tree=notebook/clone=director
```
