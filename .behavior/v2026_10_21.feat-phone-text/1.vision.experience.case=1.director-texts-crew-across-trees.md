# case=1 — director texts a crew mechanic in another tree, and the mechanic texts back

cells: S1 · S2 · S7 · S14 · S21 · S23 · S24 · P1 · happy · critipath — the wish's named critical path

## .narrative

the director runs in its own tree, `notebook`, on the grove `bert-laptop`. at boot it was handed
its crew as contacts, among them the mechanic of the tree `svc-lessons.beav.feat-book-a-lesson`,
on the same grove.

the director wants a status read before it plans the next wave. it texts the mechanic:

> "where is book-a-lesson? blocked on aught?"

it types `grove=local`; the phone casts that to `bert-laptop` before it writes the record. the call
returns at once: the text is queued, named `7f3e9a02`, and the director goes back to
its plan. no pane was touched; no human relayed.

a moment later the director's phone daemon hands the text to the mechanic over `clone say`. the
mechanic was idle, so the text lands as the next message in its session, signed with who sent it
and how to answer:

```
🦫🔔 text 7f3e9a02 from phone://grove=bert-laptop/tree=notebook/clone=director

where is book-a-lesson? blocked on aught?

   └─ reply: rhx phone.text set --to phone://grove=bert-laptop/tree=notebook/clone=director --re 7f3e9a02 --what '...'
```

the text has one name in every tree, its uuid; the reply hint, the mailbox, and every view use it.

the mechanic finishes its thought and replies through the same verb. the mechanic's daemon hands
the reply to the director the same way. the director reads it as a new message in its own
session — that is the notification.

both texts sit as files in both trees: an `out` copy where each was sent, an `in` copy where each
landed, one uuid per text across both. a reader of either dir sees the whole exchange.

## .timeline

```
given('[case1] a director tree and a crew tree, on one grove, each with the other in contacts')
  .note = director: phone://grove=bert-laptop/tree=notebook/clone=director
  .note = crew:     phone://grove=bert-laptop/tree=svc-lessons.beav.feat-book-a-lesson/clone=mechanic
  .note = each tree's daemon is up; each clone is live + idle

  when('[t0] the director texts the mechanic')
    $ rhx phone.text set --to phone://grove=local/tree=svc-lessons.beav.feat-book-a-lesson/clone=mechanic \
        --what 'where is book-a-lesson? blocked on aught?'

    then('the call returns at once, with the text queued and grove=local cast to bert-laptop')
      🦫 tail slapped!

      💧 phone.text set
         ├─ from: phone://grove=bert-laptop/tree=notebook/clone=director
         ├─ to: phone://grove=bert-laptop/tree=svc-lessons.beav.feat-book-a-lesson/clone=mechanic
         ├─ text: 7f3e9a02
         └─ status: QUEUED → the daemon delivers it

    then('a file holds the text in the director clone mailbox, QUEUED')
      .agent/.cache/repo=bhuild/role=dispatcher/skill=phone.text/clone=<director serial>/
        └─ text.0001.out.json   { uuid: 7f3e9a02-…, way: out, from, to, what, status: QUEUED, reason: null }

  when('[t1] the director daemon ticks')
    then('the text is said into the mechanic over clone say, once')
    then('the out record settles DELIVERED')
    then('an in copy lands in the mechanic clone mailbox, with the same uuid')
    then('the mechanic session shows the text, its sender, and a reply hint that names 7f3e9a02')

  when('[t2] the mechanic replies, by the uuid in the hint')
    $ rhx phone.text set --to phone://grove=bert-laptop/tree=notebook/clone=director --re 7f3e9a02 \
        --what 'green; one blocker: lesson-slot dedupe. pr up within the hour.'

    then('the reply is queued in the mechanic tree as c41d8e5b, linked to 7f3e9a02')
    then('it is admitted by contact here; case1b walks the same reply with no contact')

  when('[t3] the mechanic daemon ticks')
    then('the director session shows the reply — the sender is notified')
    then('the reply lands in the director mailbox as c41d8e5b, re 7f3e9a02 — the same pair of uuids')
    then('the reply record settles DELIVERED, once')

  when('[t4] a reader opens either mailbox dir')
    then('both texts are there, in order, each DELIVERED once, each with one uuid across both trees')

given('[case1b] contacts are one-way: the director may reach the mechanic, but the mechanic holds no contact for the director')

  when('[t0] the director texts the mechanic, and the director daemon delivers it')
    then('the mechanic tree holds the in copy, 4f0a6c21, from the director')

  when('[t1] the mechanic replies by the hint')
    $ rhx phone.text set --to phone://grove=bert-laptop/tree=notebook/clone=director --re 4f0a6c21 --what 'ack'

    then('it is admitted: the in copy of 4f0a6c21 proves the mechanic was made aware of the director')
    then('the reply is QUEUED, and is delivered like any other')

  when('[t2] the mechanic texts the director again, later, with no --re')
    then('it is still admitted — the in record, not the --re link, is the proof')

  when('[t3] the mechanic texts a clone that never texted it, with no contact')
    then('it is refused, exit 2, as in case=4 — an inbound record admits only its sender')
```
