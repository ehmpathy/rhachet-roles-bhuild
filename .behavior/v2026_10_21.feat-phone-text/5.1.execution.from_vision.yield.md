## .owed by a human — the live two-clone playtest

a clone may not enroll another (`clone enroll depth budget spent`), so no clone can stand up the
second live peer the real `clone say` path needs. the steps, for a human at a terminal:

```sh
# in a crew tree
rhx enroll claude --async --as @:foreman
# from this clone, or any clone in that tree
rhx phone.text set --to @:foreman --what 'live check: reply with phone.text'
rhx phone.daemon get        # LIVE
rhx phone.text get          # DELIVERED once the foreman takes it
```
