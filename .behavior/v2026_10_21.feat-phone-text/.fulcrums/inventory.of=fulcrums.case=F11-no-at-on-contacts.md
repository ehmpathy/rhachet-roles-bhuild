# F11 — no `--at` on `phone.contacts`

## .the fork

- **A**: `phone.contacts set|del --address <address> [--at <tree>]` — a booter grants another tree
  from its own shell
- **B (taken)**: no `--at`. a grant changes the contacts of the clone it runs as; a booter grants
  each seat in that seat's own boot

## .taken, and why

- `--at` is a reach hole: a clone with an allowed meter could widen another tree's contacts, which
  that tree's meter never gated
- it is a fourth way to name a place, beside the address's grove, tree, and clone
- a booter already holds each seat's shell: the boot hook runs beneath each clone, so no reach is
  lost
- with contacts per clone (F12), `--at <tree>` would not even name enough: it names a tree, not a seat
