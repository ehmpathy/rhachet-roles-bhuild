the vision's demos (`1.vision.experience.case=1..8`) map to journeys J1–J9 below. the one promise
literal is `task-to-public-repo-is-anonymized`; below it reads `<promise>`.

## journey test sketches

### J1 — a public push, nudged, then sent

```
given('[case1] a gh.issues repo whose visibility is PUBLIC (stub)')
  when('[t0] before any push')
    then('the record dir holds no record')
  when('[t1] push new text with no --promise')
    then('exit code is 2')
    then('calls.log holds a repo view call and no issue create')
    then('the push leaves no record held (queue get lists none)')
    then('input/output matches snapshot')  ← snapshot
  when('[t2] re-run the printed command, with --promise <promise>')
    then('exit code is 0')
    then('calls.log holds exactly one issue create')
    then('input/output matches snapshot')  ← snapshot
```

| step | action | user sees |
|---|---|---|
| t0 | none | — |
| t1 | `rhx radio.task.push --via gh.issues --into sandpine/surf-forecast --title 'retry lesson reminders' --description '…'` | the 🦫 nudge, exit 2 |
| t2 | the same + `--promise task-to-public-repo-is-anonymized` | `🦫 onto the pile!` / `🎙️ created:`, exit 0 |

#### t1 nudge (snapshot target)
```
$ rhx radio.task.push --via gh.issues --into sandpine/surf-forecast --title 'retry lesson reminders' --description 'retry a failed reminder once'
🦫 hold up — this task goes to a public repo
   ├─ repo: sandpine/surf-forecast (public)
   ├─ check the title and body hold none of:
   │  ├─ the source org, repo, route path, or pr / issue numbers
   │  ├─ internal endpoint, service, table or product names
   │  └─ customer, revenue or other business detail
   └─ once checked, re-run the command below

rhx radio.task.push --via gh.issues --into sandpine/surf-forecast --title 'retry lesson reminders' --description 'retry a failed reminder once' --promise task-to-public-repo-is-anonymized
```

#### t2 (snapshot target): the push output of today, `🦫 onto the pile!` then `🎙️ created: <title>`, the issue created.

### J3 — unreadable

```
given('[case3] a gh.issues repo whose visibility read fails (stub: repo view exits 1)')
  when('[t1] push new text with no --promise')
    then('exit code is 2'); then('no issue create in calls.log')
    then('the nudge marks the repo (visibility unreadable — treated as public)')
    then('input/output matches snapshot')  ← snapshot
  when('[t2] re-run with --promise <promise>')
    then('exit code is 0'); then('no repo view in calls.log for this push'); then('one issue create')
  when('[t3] push --exid 41 --description with no --promise')
    then('exit code is 2'); then('the nudge prints the --exid 41 command + --promise'); then('no issue edit')
    then('input/output matches snapshot')  ← snapshot
```

marker line: `   ├─ repo: sandpine/surf-forecast (visibility unreadable — treated as public)`

### J6 — the drain of held records

```
given('[case6] four records held behind a shut gate: A public + promise, B public, C private, D unreadable')
  when('[t0] queue get')
    then('lists four held records'); then('input/output matches snapshot')  ← snapshot
  when('[t1] open the gate; queue drain')
    then('A and C reach their repos (two issue create calls)')
    then('B and D stay QUEUED, reasons public-repo:unpromised / public-repo:unreadable')
    then('the output names B and D, each with its fix lines')
    then('D carries (visibility unreadable — treated as public)')
    then('exit code is 2')
    then('input/output matches snapshot')  ← snapshot
  when('[t2] queue drain --promise <promise>')
    then('B and D reach their repos'); then('exit code is 0')
    then('input/output matches snapshot')  ← snapshot
  when('[t3] queue drain --promise wrong-value')
    then('exit code is 2'); then('the error names the one valid value'); then('no send')
```

held row (snapshot target):
```
   └─ <uuid> retry lesson reminders → sandpine/surf-forecast (public-repo:unpromised)
      ├─ awaits: public repo, no anonymized promise on this record
      ├─ check its title and body at .behavior/.radio/record.<uuid>.json: no source org, repo, route path, pr / issue numbers, internal names, or business detail
      ├─ scrub the body if need be: rhx radio.task.queue set --uuid <uuid> --description @stdin
      ├─ once checked, vouch: rhx radio.task.queue drain --promise task-to-public-repo-is-anonymized (it promises every held public record)
      └─ or drop it: rhx radio.task.queue del --uuid <uuid> --why "<why>"
```

`queue get` lists a held record by its title only, so the fix line points at the record file, which
holds the body, and at the extant `set --description` amend for a scrub. a title cannot be amended
(it is the create's identity); a private title is fixed by `del`, then a push with the new title.

the nudge's exact command shell-quotes each value (`'…'`, an inner `'` as `'\''`), so a title or body
with spaces, quotes, `$`, or newlines copies and re-runs as typed.

## critical paths

| critical path | description | why critical |
|---|---|---|
| private push | push into a private repo, as today | nearly every push; any friction here trains the reflex and slows every clone |
| public push, two passes | nudge, check, re-run with the printed command | the one path the gate exists for; it must leak naught and cost one re-run |
| status-only update | claim / deliver an issue on any repo | the dispatch lifecycle; a nudge here would be pure ceremony |
| drain with a mix | private records land; public unvouched ones wait, named | one public record must never block the rest, nor be lost |

### if each path failed, and its pit of success

| critical path | if it failed | narrower inputs | convenient | failsafe | failfast | idempotent |
|---|---|---|---|---|---|---|
| private push | every clone push gains friction, or a private push is held as unreadable | no new input | no flag owed | a failed read holds the record QUEUED, named, never lost | — | the extant findsert by (repo, title) |
| public push, two passes | a leak (pass 1 sends) or a stuck task (pass 2 refuses) | `--promise` accepts one literal | the nudge prints the full command to re-run | the nudged record is dropped, so a scrubbed re-run with a new title leaves no stale twin | a wrong value exits 2 before any record or send | the re-run re-queues the same key and findserts upstream; a second re-run finds the issue |
| status-only update | a nudge on every claim; ceremony that trains the reflex | no new input | no flag, no read | — | — | unchanged |
| drain with a mix | a public record blocks the line, or is sent unvouched | `drain --promise` accepts one literal | fix lines print the exact drain command | the hold carries `halt: false`; the rest still send | a wrong value exits 2 before any send | a re-drain re-sends only what still waits |
