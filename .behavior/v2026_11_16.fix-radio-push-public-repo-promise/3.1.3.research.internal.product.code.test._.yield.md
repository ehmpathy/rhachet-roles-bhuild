## T3 — the transport clamp reads the stub's call log · [EXTEND]

the stubs log each argv (a `calls.log` beside the stub, in [1]–[6]). the clamp the wish names is an
assertion on that log:
- no promise, public → the log holds a `repo view` call and no `issue create` / `issue edit`
- with the promise → the log holds exactly one `issue create` (or one `issue edit`), and no `repo view`

- extend: a small reader of `calls.log` per test file
