# experience inventory: the public-repo promise gate

verdicts: **demoed** (a `case=N`) · **itemized** (on record, no demo) · **forbidden** (the caller
may attempt it; the gate rejects it) · **impossible** (no attempt can reach it).
feel: happy · sharp. care: critipath · alterpath — by the one test, *is there a workable fallback?*

## .actors × feel

| actor | happy | sharp |
|---|---|---|
| **pusher, present** | a clone pushes to a private repo and it lands with no new step (`case=3`) · a clone re-runs with the promise and its task lands clean (`case=2`) · a clone claims a public issue by status alone, unasked (`case=6`) | a clone pushes private detail at a public repo and is stopped before the send, told what to check and how to re-run (`case=1`) · a clone edits a public issue's text and meets the same stop (`case=5`) · a clone whose visibility read fails is stopped as if public (`case=4`) |
| **drainer** | a human drains a backlog whose public records were vouched at push time, and all land (`case=7` A) | a human drains and one unvouched public record is set aside, named with its fix, while the rest land (`case=7` B) |
| **absent pusher** | — skip: its happy path is the drainer's (`case=7` A) | its unvouched public record rides out in another clone's push and is set aside, not sent (`case=8`, the densest walk) |

care test (severity = freq × cost): two rules decide every row.

- **critipath** — a row where a broken gate either sends unvouched text to a public repo (cost:
  public forever) or stops an unvouched private send (freq: nearly every push, all of them blocked).
  that covers every public, unreadable, and unvouched-private row, and status-only updates
- **alterpath** — a row where only the vouched path breaks: a promise on a send that needs none, or a
  re-run after a nudge. its break costs one re-run, rarely
