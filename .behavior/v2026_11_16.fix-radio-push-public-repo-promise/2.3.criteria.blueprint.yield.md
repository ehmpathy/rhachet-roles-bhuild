# criteria.blueprint: mechanism bounds for the public-repo promise gate

## blackbox criteria satisfied

- usecase.1 = a push of new text to a public repo ✓
- usecase.2 = a push to a private or internal repo ✓
- usecase.3 = a push when the visibility cannot be read ✓
- usecase.4 = an update of an issue's text on a public repo ✓
- usecase.5 = a status-only update ✓
- usecase.6 = a drain of held records ✓
- usecase.7 = a push carries out a backlog that holds an unvouched public record ✓
- usecase.8 = what waits, and help ✓
- usecase.9 = os.fileops ✓

## subcomponent contracts

given('a visibility read of one gh repo (communicator)')
  then('exposes: read the visibility of one repo, under the record\'s own auth')
  then('returns public | private | internal on success')
  then('returns unreadable — never throws — on any failure, with the cause kept for display')
    sothat('row 5: a fault reads as public, and one fault never halts a drain')

given('the promise gate (decision, pure)')
  then('exposes: given channel, record content, visibility, promise → send | hold')
  then('decides hold only for gh.issues text bound for a public or unreadable repo, with no promise')
  then('never asks for the visibility when the record carries no text, uses os.fileops, or holds a promise')

given('the record')
  then('carries the promise the push came with, or none')
  then('takes the promise only from the push at hand — never inherited from a prior push of the same task')

given('the promise value check')
  then('accepts exactly the literal task-to-public-repo-is-anonymized')
  then('refuses any other value, or a bare flag, before any record or send, exit 2, the valid value named')

## composition boundaries

given('the per-record send, which every path already shares (push, backlog flush, queue drain)')
  then('composes the promise gate after the radio.uses gate and the auth derive, before the send')
  then('a hold settles the record QUEUED with a public-repo reason, and the line goes on')
    sothat('one held record never blocks the rest')

given('the push cli')
  then('passes --promise into the record')
  then('when its own record was held by the promise gate: drops that record and prints the nudge with the exact command it ran plus --promise')

given('the queue cli, drain verb')
  then('passes --promise into the drain, which vouches for every held record it sends')

given('the drain and queue get outputs')
  then('name a promise-held record with its fix lines: check the text, then drain --promise, or drop it')
