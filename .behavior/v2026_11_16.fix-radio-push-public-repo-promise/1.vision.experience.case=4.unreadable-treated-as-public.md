# case=4: visibility unreadable → treated as public

sharp × critipath · cells #6, #11 · happy × alterpath · cells #7, #12 (and #18, #19 by the same rule; #18 is demoed in `case=7` D)

## .narrative

a clone's robot token lapsed an hour ago. it runs
`rhx radio.task.push --via gh.issues --into sandpine/coachbook --title 'add swell alerts' --description '…'`.
the visibility read fails, so the gate cannot prove `sandpine/coachbook` is private. it assumes the
worst: the beaver nudge, its repo line `sandpine/coachbook (visibility unreadable — treated as
public)`, and as its last line the exact command plus `--promise task-to-public-repo-is-anonymized`.
naught is sent. the clone reads the marker, sees a token fault rather than a public repo, and — its
text clean — re-runs the printed command. the push proceeds to the send.

later the same clone edits issue 41 there with `--exid 41 --description '…'`, the token still
lapsed: the same nudge, the same marker, the exact `--exid 41` command with the promise appended.
no edit is made until it re-runs with the promise.

an unchecked send is the one outcome the gate never permits.

## .bdd sketch

```
given gh repo view fails for the target (non-zero exit)
  when radio.task.push ... --title .. --description .. (no --promise)                    (#6)
    [t0] then exit code is 2
    [t1] then stdout holds the nudge, the repo line `(visibility unreadable — treated as public)`
    [t2] then the nudge's last branch is the exact command + `--promise task-to-public-repo-is-anonymized`
    [t3] then no create request reached the transport, and the push's record is DROPPED
  when radio.task.push ... --promise task-to-public-repo-is-anonymized                   (#7)
    [t4] then no visibility read is made, one create request reached the transport, exit code is 0
  when radio.task.push --exid 41 --description '..' (no --promise)                       (#11)
    [t5] then exit code is 2, the same nudge and marker
    [t6] then the nudge's last branch is the exact `--exid 41` command + `--promise task-to-public-repo-is-anonymized`
    [t7] then no edit request reached the transport
  when the same edit carries --promise task-to-public-repo-is-anonymized                 (#12)
    [t8] then one edit request reached the transport; exit code is 0
```
