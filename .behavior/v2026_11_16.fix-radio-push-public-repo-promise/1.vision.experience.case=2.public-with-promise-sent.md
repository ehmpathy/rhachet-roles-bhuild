# case=2: a push to a public repo, with the promise → sent

happy × critipath · cell #2 · forbidden · cell #23 (a mistyped promise)

## .narrative

the clone from `case=1` has scrubbed its text. it re-runs the exact command the nudge printed. the
push sends as it did before this behavior existed: one issue, the usual output.

had it typed the promise by hand and slipped — `anonymised` for `anonymized` — the push would have
stopped at once, before any record or send, and named the one value it accepts. a typo never reads
as a silent "no promise", which would only re-nudge with no clue why.
