# criteria.blackbox.matrix: the public-repo promise gate

the gate decides one record's fate. `promise` = the vouch in force for that record: the push's own
`--promise`, or (for a held record) the one recorded at its push or passed to `drain`.

## matrix 1 — the gate, per record (gh.issues)

| ind: content | ind: visibility | ind: promise | ind: pusher presence | dep: request sent? | dep: visibility read? | dep: record fate | dep: output | dep: exit (of this push / drain) |
|---|---|---|---|---|---|---|---|---|
| new / exid.text | public | absent | present | no | yes | dropped | nudge `(public)` + exact command + `--promise` | 2 |
| new / exid.text | public | absent | absent | no | yes | held, reason = public-repo hold | named as held + `drain --promise` fix | push: per its own record · drain: 2 |
| new / exid.text | public | present | any | yes | no | delivered | as today | 0 |
| new / exid.text | private / internal | absent | any | yes | yes | delivered | as today | 0 |
| new / exid.text | private / internal | present | any | yes | no | delivered | as today | 0 |
| new / exid.text | unreadable | absent | present | no | yes (fails) | dropped | nudge `(visibility unreadable — treated as public)` + exact command + `--promise` | 2 |

## gaps

- none in matrix 1: all 4 independent dimensions walked; `exid.status` folds every other value
  because the gate never reads its visibility (no text leaves)
- matrix 1 row 2's exit: on a push, the exit follows the push's own record, not the held backlog
  record (extant semantics, usecase 7); on a drain, any held record exits 2 (extant semantics)

- usecases 10–12 (2.1) add no dimension to matrix 1: each is a sequence across two pushes or a
  fault class of the `unreadable` value, so each is a journey row in the blueprint, not a matrix
  cell. the catalog holds them as #27–#38

## decomposition signal

matrix 1 has 4 independent dimensions — the threshold. it does not split: `content` collapses to two
classes (text vs status-only) and `presence` changes only the fate column. the narrower boundaries
are already drawn: the promise value (matrix 2) and the channel (matrix 3) sit apart.
