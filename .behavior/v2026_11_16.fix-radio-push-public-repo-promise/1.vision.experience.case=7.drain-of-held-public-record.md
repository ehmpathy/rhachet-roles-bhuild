# case=7: a drain meets held records bound for public, private, and unreadable repos

cells #15 (happy × critipath) · #16 (sharp × critipath) · #17 (happy × alterpath) · #18 (sharp × critipath)

## .narrative

radio was blocked when four pushes ran, so all four were held. a human lifts the gate and runs
`rhx radio.task.queue drain`.

- A, bound for a public repo, was pushed with the promise → the promise was recorded on the held
  record → the drain sends it
- B, bound for a public repo, was pushed with no promise → the drain sets B aside, QUEUED, with the
  public-repo hold as its reason
- C, bound for a private repo → sent as today
- D, bound for a repo whose visibility the drain cannot read (the token lapsed for that org) → set
  aside as B is, its line marked `(visibility unreadable — treated as public)`

the drain delivers A and C, names B and D with their fix — check the text, then
`drain --promise task-to-public-repo-is-anonymized` — and exits 2. the human reads B's and D's
text with `queue get`, finds them clean, and drains again with the promise. both go. the drain
never sends a public or unreadable record that no one vouched for, and those records never block
the rest.

## .bdd sketch

```
given held records A (public, promise on record), B (public, no promise), C (private),
      D (visibility unreadable, no promise)
  when radio.task.queue drain
    [t0] then A and C reached the transport; B and D did not
    [t1] then B and D are set aside, QUEUED, each with the public-repo hold as its reason
    [t2] then exit code is 2
    [t3] then the output names B with its fix: check its text, then `drain --promise task-to-public-repo-is-anonymized`
    [t4] then the output names D the same way, its line marked `(visibility unreadable — treated as public)`
  when radio.task.queue drain --promise task-to-public-repo-is-anonymized
    [t5] then B and D reached the transport; exit code is 0
```
