# case=1: a push to a public repo, no promise → nudged, naught sent

sharp × critipath · cells #1

## .narrative

a clone wraps up a fix in a private repo and wants to hand a follow-up to `ehmpathy/rhachet`, a
public repo. it pastes its notes as the description — they name the private repo, a route path, and
pr #412. it runs the push it always runs. the push stops before the send: a beaver nudge says the
target is public, lists what to look for, and prints the exact command to re-run with the promise.
no issue appears on github. the clone strips the private names, re-runs with the promise, and the
issue lands clean.

## .bdd sketch

```
given a gh repo whose visibility is PUBLIC
  when radio.task.push --via gh.issues --into <it> --title .. --description .. (no --promise)
    [t0] then exit code is 2
    [t1] then stdout holds the 🦫 nudge, with the repo and `(public)`
    [t2] then the nudge's last branch is the exact command + `--promise task-to-public-repo-is-anonymized`
    [t3] then no create or edit request reached the transport
    [t4] then the nudge matches its snapshot
    [t5] then the push's record is DROPPED, so naught lingers in `queue get`
  when the push is re-run with a scrubbed title and the promise
    [t6] then one create request reached the transport, and only one record is QUEUED-or-DELIVERED
```
