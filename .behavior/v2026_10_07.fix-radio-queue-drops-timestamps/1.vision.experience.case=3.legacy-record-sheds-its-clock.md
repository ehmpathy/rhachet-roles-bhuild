# case=3 — a legacy record sheds its clock on its next write

feel: sharp · care: critipath

## .narrative

a route held a push last week, before this fix. its record still says
`"heldAt": "2026-10-07THH:MM:SSZ"`. today the clone upgrades bhuild and pushes again; the drain
reads that legacy record, delivers it, and writes it back.

the sharp edge: the record is read via `new RadioTaskRecord(JSON.parse(…))`, and `domain-objects`
copies every key it is handed (`DomainObject.js:33`, `Object.assign`). if the read does not drop
`heldAt` and `settledAt`, the write carries them forward — and the very file the wish names keeps
its clock forever.

so the read sheds them. the delivered record that lands has no `heldAt`, no `settledAt`. the diff
shows those lines removed, once, alongside the fate change. after that the file is clean.

## .the fail-safe

three ways this edge can go wrong, and how each fails safe:

| the edge | how it fails safe |
|----------|-------------------|
| the shed drops two keys without a word | **safe by construction, and why silence is right.** neither key has a reader (`settledAt`'s one read carried itself; `heldAt`'s two reads — order, label — move to `heldSeq`). git holds the prior bytes. a loud warn on every upgraded record would block no harm and teach no fix |
| a refactor later removes the shed | **loud.** the clamp (case=6) runs over a legacy fixture's rewrite; a `heldAt` that survives the write is an iso datetime in the bytes, so the scan goes red and names the field |
| a legacy file is malformed — bad json, or a `heldSeq` that is not a number | **fast + loud + names the fix.** the read already fails as a `MalfunctionError` that names the path and the cure (`daoRadioTaskRecord/index.ts:70-80`: `where: <path>`, `fix: repair the json of the record file, or remove it`). a non-numeric `heldSeq` joins that same path: without `heldAt` it is the sole order key, so a record that lacks one must halt the drain, never sort as `NaN` |

a legacy record that is never touched again keeps its stale lines — no code path reaches it. that
is a scope bound, not a guard (case=_).

## .bdd sketch

```
given('[case1] a legacy record on disk with heldAt + settledAt + heldSeq=4')
  when('[t0] the drain reads it')
    then('the record in memory carries no heldAt and no settledAt')
    then('it keeps heldSeq=4 — its place in line survives the upgrade')
  when('[t1] the drain delivers it and writes it back')
    then('the file on disk holds no heldAt and no settledAt')
    then('the file on disk holds recordStatus=DELIVERED')
given('[case2] two legacy records in one dir, heldSeq 4 and 5, heldAt reversed (a clock skew)')
  when('[t0] the held list is read')
    then('they drain 4 then 5 — the seq leads, the stale clock is ignored')
given('[case3] a legacy record whose heldSeq is absent or not a number')
  when('[t0] the drain reads it')
    then('it fails as a MalfunctionError')
    then('the error names the record path and the fix: repair the json, or remove the file')
    then('no record behind it is sent — the drain halts before it sorts')
given('[case4] the shed is removed from the read (a regression)')
  when('[t0] the clamp scans the bytes of a rewritten legacy record')
    then('it fails, and names heldAt and its value')
```
