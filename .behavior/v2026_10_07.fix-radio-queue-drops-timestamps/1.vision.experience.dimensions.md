# 1.vision.experience.dimensions

## .the space

an experience here = an actor meets a surface the dispatcher touches, at some moment in a record's
or task's life, and either reads only real change — or reads a clock.

## .the root axis — what the actor meets

the lead axis is latent in the wish: not every actor meets a file. surfaced so each subspace below
takes only the axes that apply to it.

| M | meets | values |
|---|-------|--------|
| M1 | a **written artifact** | the record subspace (R) · the drain lock (L) · the task subspace (T) · stdout (S) |
| M2 | the **rule + clamp** | the maintainer subspace (K) |
| M3 | a **guard** that reads a written artifact | the hook subspace (H) |
| M4 | a **sanctioned home** for a clock | `.log/` · a git commit's own date · github's own `createdAt` — read, never written by the radio |

## .R — the queue record (`$route/.radio/record.<key>.json`, `.behavior/.radio/…`)

| axis | values |
|------|--------|
| R.moment | `hold` · `repush` · `settle.delivered` · `settle.refused` · `settle.reheld` (a drain attempt that fails and keeps the record QUEUED with a new `reason`) |
| R.vintage | `fresh` · `legacy` (carries `heldAt` / `settledAt`) |
| R.dirs | `one.dir` · `many.dirs` |
| R.time | `rerun.later.day` · `concurrent` (two writes at the same instant) |

actors: `clone` (writes) · `reviewer` (reads the diff).

**why `same.run` is not a value.** the wish's harm is drift between runs. within one run there is
no second write to compare, so a `same.run` cell can neither pass nor fail the byte-identity claim.
it is dropped from the axis rather than walked as a column of non-cells.

## .L — the drain lock (`.behavior/.radio/.locks/`)

the drain lock lives inside the radio dir (`withRadioDrainLock.ts:10-11`). its cache envelope
holds `expiresAtMse` — an epoch-ms clock (`simple-on-disk-cache` `asSerializedEnvelope.js`).

| axis | values |
|------|--------|
| L.exit | `clean` (release deletes the lock — `with-simple-mutex` `delMutexLock.js`) · `crashed` (the holder dies; the file stays until the lease lapses and a later drain overwrites it) |

actor: `reviewer` (reads `git status` in a consumer that tracks `.radio/`).

## .T — the dispatched task

| axis | values |
|------|--------|
| T.channel | `osfileops` (task file + backup) · `ghissue` (title + body) |
| T.moment | `create` · `transition.claim` · `transition.deliver` · `read` (`radio.task.pull`) |
| T.vintage | `fresh` · `legacy` (a task file written before this fix) — the wisher ruled datestamps fine, so the os.fileops format does not change and `legacy` = `fresh` in bytes |

actors: `clone` (writes) · `human.reader` (reads via pull).

| T.time | `same.task.later.day` (a transition or re-read of one task) · `new.push.later.day` (a second push of the same title) |

a second push is a second task: os.fileops mints a fresh random exid (`daoRadioTaskViaOsFileops.ts:18-19`)
and gh mints a fresh issue number, so its bytes differ by identity, never by clock. the
byte-identity claim binds one task across days, not two tasks.

## .S — stdout

| axis | values |
|------|--------|
| S.command | `radio.task.push` (held / drained lines) · `radio.task.held` (stop reminder) · `radio.task.pull` (detail) |

actor: `human.reader`. untracked; walked only because its source fields change.

## .K — the maintainer

| axis | values |
|------|--------|
| K.change | `adds a clock field to a written shape` · `adds a non-clock field` · `reads the brief` |

## .H — the guard

| axis | values |
|------|--------|
| H.guard | `consumer hook` (`check.timestamps.sh`, F1) · `this repo's husky` (the same check, adopted, F11) · `this repo's clamp` (byte scan, F8) |

input: every artifact R and T write.

## .the correlations, named

the subspaces are not fully orthogonal within themselves. each correlation is named here so the walk
in `case=_` can be falsified against it:

| correlation | why | how the walk treats it |
|-------------|-----|------------------------|
| `R.dirs = many.dirs` bites only the order of a drain and the mint under `concurrent` | a single write never compares across dirs | `hold`/`repush` × `many` walked once, for byte-identity; order walked under `settle.*` |
| `R.vintage = legacy` bites only a read-then-write | a hold writes a new key, never a legacy one | `hold × legacy` verdicted impossible |
| `T.channel = ghissue` makes `T.vintage` moot | github stores the body; we never rewrite a body's date because it never held one | `ghissue × legacy` verdicted impossible |
| `T.moment = transition.*` for osfileops also writes the backup | the backup is a step of the transition | the backup rides the transition cell |
| `R.moment = repush` has the shape of `hold` | the place in line is kept | walked beside hold |
