# case=1 — a held push, rerun a day later, writes the same bytes

feel: happy · care: critipath

## .narrative

a clone on route `v2026_10_07.book-a-lesson` pushes `fix lesson reminder copy` into
`sandpine/svc-lessons`. the radio gate is shut for `sandpine`, so the push is held: one record lands
in `$route/.radio/record.3f9a…json`.

```json
{
  "key": "3f9a0c1e7d2b4a58",
  "kind": "create",
  "repo": { "owner": "sandpine", "name": "svc-lessons" },
  "via": "gh.issues",
  "title": "fix lesson reminder copy",
  "recordStatus": "QUEUED",
  "reason": "gate:org",
  "heldSeq": 1,
  "deliveredExid": null
}
```

no `heldAt`. no `settledAt`. the place in line is `heldSeq: 1`.

the next day the clone reruns the same dispatch from a fresh worktree of the same route. the
record lands with the same key, the same seq, the same bytes. `git diff` on the route shows
naught. the reviewer who opens the pr sees one record file and never a line that changed only
because the sun moved.

## .bdd sketch

```
given('[case1] a route with no held records; the sandpine gate shut')
  when('[t0] radio.task.push --via gh.issues --into sandpine/svc-lessons --title "fix lesson reminder copy"')
    then('one record is written under $route/.radio/')
    then('the record holds heldSeq=1 and no field whose value is a clock')
    then('the push exits 2 (held), as today')
  when('[t1] the same dispatch reruns in a fresh worktree on a later day (clock pinned +1 day)')
    then('the record file is byte-identical to [t0]')
  when('[t2] the same push repeats in the same worktree')
    then('the record keeps heldSeq=1 — a repush keeps its place in line')
    then('the record file is byte-identical to [t0]')
```
