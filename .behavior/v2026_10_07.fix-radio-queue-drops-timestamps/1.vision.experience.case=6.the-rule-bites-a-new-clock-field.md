# case=6 — the rule bites when a maintainer adds a clock field

feel: sharp · care: critipath — the lead experience: a new clock field goes red ([case1])

also hosts: `[case2]` a non-clock field stays green — happy · alterpath · `[case3]` the maintainer reads the brief — happy · critipath. they ride here because each is the other side of the same clamp

## .narrative

six weeks on, a maintainer wants to show "how long has this task waited?" and adds
`lastTriedAt: now()` to the record. the unit suite goes red:

```
✋ ConstraintError: a radio record holds a timestamp
   ├─ field: lastTriedAt = 2026-11-19THH:MM:SSZ
   ├─ why:   a timestamp changes on every run with no change in sense; it churns diffs
   └─ fix:   order by heldSeq; read time from git or github; see rule.forbid.timestamps-in-tracked-files
```

the maintainer opens the brief, learns where a timestamp may live — `.log/`, an untracked file, a
git commit's own date, github's own `createdAt` — and that a bare datestamp (`2026-11-19`) is
allowed. the wait read is not worth a field; they drop it.

the clamp has two parts. a byte scan over every record and task the suite writes fails on an iso
datetime (a date with a time of day) and names the field. a two-run test writes the records twice
with the clock pinned a day apart and asserts the same bytes — which also catches a clock in a shape
the scan cannot read, such as an epoch number.

## .bdd sketch

```
given('[case1] a record shape with a clock field added')
  when('[t0] the clamp test runs over the record a push writes')
    then('it fails, and names the field and its value')
given('[case2] the record shape as this fix leaves it, plus a non-clock field a maintainer adds')
  when('[t0] the clamp test runs over every record + task file the radio suite writes')
    then('it passes — no iso datetime in any byte')
    then('so no file the radio writes holds a value the consumer husky hook could refuse')
given('[case3] the brief')
  when('[t0] a reader opens rule.forbid.timestamps-in-tracked-files')
    then('it names the hazard, the sanctioned homes, allows a bare datestamp, and grades a tracked timestamp a blocker')
```
