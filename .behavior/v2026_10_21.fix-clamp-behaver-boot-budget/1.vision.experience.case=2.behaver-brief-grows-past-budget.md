## .narrative

six weeks on, a clone lands a lesson in `rule.require.experience-catalog-evolution.md` and, out of
habit, appends three paragraphs of *why* to the resident cue. locally, naught complains:
`npx rhachet roles cost --all` shows a 🟡 beside behaver and **exits 0**. nobody reads it.

ci runs `roleArtifacts.integration.test.ts`. its boot-budget case boots every `src` boot.yml via
`rhachet roles boot --what` and it goes red:

```
✋ ConstraintError: over budget
   ├─ budget   = <n> tokens   (declared in boot.yml)
   ├─ payload  = <m> tokens   (full emitted payload, o200k_base)
   └─ fix — four strategies, cheapest first
      ├─ catalogize · condense · reference · eliminate
```

the failure is fast (one test), loud (red ci, exit 2 from rhachet relayed), and teaches the fix
(rhachet's own four strategies). the clone moves the paragraphs into the `.reason.md` beside the
rule — the refout pattern the file itself cites — and ci goes green. had the growth been worth
it, the clone raises `budget.tokens` in the same pr, where the reviewer sees the number move (a11.b).
