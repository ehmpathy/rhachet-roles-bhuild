# case=4 — a budget too tight for the linked render goes red here, not in a consumer

feel = sharp · care = critipath · rows a6.b and a6.o — the sole densest walk (3 boundaries), and the trap a naive budget walks into

## .narrative

one boot.yml, two renders. in this repo the clamp boots `src/domain.roles/behaver/boot.yml`; a
consumer's seat boots the copy linked under `.agent/repo=bhuild/role=behaver/`. the brief paths are
the same, but the base path is longer, so the linked payload costs more — measured 2026-10-21:
**2,571 src vs 2,601 linked (+30)**.

an author trims behaver and, to keep it tight, sets `budget.tokens` to the exact `src` payload.
without a guard, the clamp stays green here while every consumer seat prints an overage notice
(rhachet warns, not halts, on a foreign spec — one linked in as a symlink). nobody in this repo
would see it; every seat would.

so the clamp boots the **linked render too**: it copies each role as real files to
`.agent/repo=bhuild/role=<role>/` in a temp repo and boots it there (F3). a real-file copy is not
a symlink, so rhachet takes its `halt` rung (`isBootSpecForeign` reads `lstat`). the author's tight budget
fits the src render and goes red on the linked one, in ci, with rhachet's own overage tree:

```
✋ ConstraintError: over budget
   ├─ budget   = 1,9xx tokens   (declared in boot.yml)
   ├─ payload  = 1,9xx tokens   (full emitted payload, o200k_base)   ← the linked render
   └─ fix — four strategies, cheapest first
```

the test names which render failed, so the author knows the path delta is the cause.

fast (one test), loud (red ci), and it names the fix. the failure lands in the repo that can fix
it, never in the seats that cannot.

## .bdd sketch

```
given('[case4] a role whose linked render costs more than its src render', () => {
  when('[t0] the budget is set to the src payload exactly', () => {
    then('the src render passes')
    then('the linked render fails, and the test names it as the linked render')
    then('the failure carries the budget, the payload, and the four fixes')
  })
  when('[t1] the budget is raised to the linked payload, rounded up to the next 100', () => {
    then('the clamp passes')
    then('a consumer seat boot reads under budget, no warn')
  })
  when('[t2] a frozen role (supervisor) is set to its src payload exactly', () => {
    then('the linked render fails the same way') // its delta is larger: ~25 said paths
    then('the fix is the same: raise to the linked payload, or trim')
  })
})
```
