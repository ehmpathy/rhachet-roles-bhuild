# case=7 — a new role ships with no budget

feel = sharp · care = critipath · rows a15.o (`[t0]`) and a21.o (`[t1]`) · the same assertion forbids a4.b / a4.o (a `budget:` line deleted from an extant role)

## .narrative

months on, a clone lifts a new role into `src/domain.roles/curator/` with a fresh `boot.yml` and no
`budget:` line. `roles cost --all` lists it as `(no budget)` and exits 0 — the same silence that
let five roles grow uncapped before this pr.

the clamp's first assertion walks every role **dir** under `src/domain.roles/` and requires a
`boot.yml` with a declared budget. it goes red:

```
✋ boot.yml declares no budget
   ├─ spec  = src/domain.roles/curator/boot.yml
   ├─ cost  = run `npx rhachet roles cost --what src/domain.roles/curator/boot.yml`
   └─ fix: declare `budget: tokens: <cost + margin, rounded up to the next 100>`
```

the clone measures, declares, and ci goes green. the freeze covers roles that do not exist yet.

a second clone lifts a role with **no `boot.yml` at all**. rhachet boots such a role whole ("a role
with no boot.yml says all"), so it is the most uncapped boot there is. a clamp that globbed
`*/boot.yml` would never see it; because the clamp walks role dirs, the same assertion fires and
names the absent file.

## .bdd sketch

```
given('[case7] a src role with no declared budget', () => {
  when('[t0] its boot.yml has no budget key', () => {

  })
})
```
