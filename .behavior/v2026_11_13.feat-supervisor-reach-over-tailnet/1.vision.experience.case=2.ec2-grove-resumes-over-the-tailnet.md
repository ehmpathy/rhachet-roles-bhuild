# case=2 — an asleep ec2 grove resumes and is reached over the tailnet

cell `c02` (+ its KEEP arm `c07`, its failure arms `c10` + `c14`) · happy · critipath · the wish's second "done means" line

## .narrative

`grove-sandpine-v20260901` hibernated overnight. the supervisor runs a wake. the aws half is unchanged: keyrack hands over the profile, the account guard matches the row, the nat resumes, then the box. what changed is the second half. the wake no longer waits on an ssm agent, opens no port-forward on a local port, and starts no detached `session-manager-plugin`. it awaits one signal, the same one it awaits on hetzner: `camper@<host>` answers ssh over the tailnet. the box's tailscaled rejoins on resume, and within the `--timeout` the probe passes. the alias names the tailnet host on port 22.

no 20-minute idle expiry, no orphan port, no keepalive workaround: the tailnet has none of those failure modes.

a second wake a minute later prints `[KEEP]` on every leg (`c07`).

if the box never answers (`c10`), the error names the two causes the ssm text named, now in tailnet words: it needs longer (wake again), or it is starved (load is the lever). it adds `tailscale status` / `tailscale ping <host>` to tell an absent peer from a mute sshd.

## .sketch

```
given('[case2] an ec2 grove row with an account, its box stopped')
  when('[t0] rhx git.grove.wake grove-sandpine-v20260901')
    then('keyrack, account guard, nat, box legs run as today')
    then('it never calls aws ssm, in any form')
    then('it awaits ssh camper@<host> true, up to --timeout')
    then('it writes HostName <tailnet host> / Port 22 / User camper')
    then('exit 0')
  when('[t1] the same wake again')
    then('every leg prints [KEEP]; no aws start call')
  when('[t2] rhx duct.read on a crew of that grove')
    then('the read rides ssh <alias> over the tailnet')
given('[case2.fail] the box answers ec2 but never ssh within --timeout')
  when('[t0] rhx git.grove.wake grove-sandpine-v20260901')
    then('exit 1; stderr names "needs longer" vs "starved", and tailscale status / tailscale ping')
    then('stderr never names ssm')
```
