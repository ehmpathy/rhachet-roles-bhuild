# case=7 — a supervisor on one grove reaches another grove

cells `c22` (+ its sharp arm `c23`) · happy · critipath · the case the wake was built for

## .narrative

the wake's header says a grove must be wakeable from anywhere, "FROM another grove above all" (`git.grove.wake.sh:11-21`). a supervisor clone runs on the ec2 grove `grove-sandpine-v20260901` and must boot a crew on the hetzner grove. under ssm that needed aws credentials on the ec2 grove; the hetzner grove could not be reached at all. now both groves are `tag:camp` peers, so the ec2 grove's supervisor runs the same wake, sees power `none`, probes `camper@<hetzner host>` over the tailnet, writes the alias into its own `~/.ssh/config`, and boots the crew. no aws credential is touched.

the sharp arm (`c23`): a supervisor whose own machine is not a tailnet peer runs the wake. the probe fails within ~10s. the error says what it can know — this caller saw no answer — and names `tailscale status` to run HERE, first, before any claim about the grove. a reader is never told the grove is down when the fault is the caller's link.

## .sketch

```
given('[case7] a supervisor on an ec2 grove; a tailnet row for the hetzner grove')
  when('[t0] rhx git.grove.wake grove-sandpine-hetzner-v20261022, run on the ec2 grove')
    then('power: none; no aws or keyrack call')
    then('the alias is written to the caller grove's ~/.ssh/config')
    then('exit 0')
  when('[t1] rhx git.crew.boot onto the hetzner grove, from the ec2 grove')
    then('the duct is created over ssh <alias>')
given('[case7.off-tailnet] a caller that is not a tailnet peer')
  when('[t0] rhx git.grove.wake <any grove>')
    then('exit 1 within ~10s for power none (after power-up for aws)')
    then('stderr names tailscale status, to run on THIS machine, as the first check')
    then('no alias is written')
```
