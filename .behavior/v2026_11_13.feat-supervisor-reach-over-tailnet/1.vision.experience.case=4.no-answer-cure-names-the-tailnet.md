# case=4 — a grove outside aws that does not answer gets a tailnet cure, never the wake alone

cells `c04`, `c16`, `c26` · sharp · critipath · the wish's third outcome line

## .narrative

the hetzner grove drops off the tailnet: its tailscaled crashed. the supervisor's poll tries `duct.read` and ssh times out. today every such hint reads "the grove is down, asleep, or its tunnel is dead — rhx git.grove.wake <grove>". the cause names a tunnel that no longer exists, and the cure names a power lever this grove does not have.

with this wish, one transformer reads the row behind the ssh host and names the cure per power:

- power `none` → cause "no tailnet answer from <host>", fix `tailscale status` then `tailscale ping <host>`
- power `aws` → the extant wake hint (case=2's wake now probes the tailnet and names it on failure)

the verdict word beside the cure stays as declared: the crew reads `😴 asleep`, a canonical term that means "we could not look" (`term=asleep`). `unreachable` is a forbidden synonym of it, so the render never says that. whether `asleep` over-claims for a box that never sleeps is an OPEN dispute (F06); this case is evidence for it, not a settlement.

the wake stays a correct second step for any grove: on a `none` grove it probes the tailnet and fails loud with the same words.
