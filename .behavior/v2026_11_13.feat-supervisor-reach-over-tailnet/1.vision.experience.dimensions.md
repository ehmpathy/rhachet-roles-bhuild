# 1.vision.experience.dimensions

the experience space of "the supervisor reaches a grove", factored into orthogonal axes.

## .axes

| # | axis | positions | why it varies the experience |
|---|---|---|---|
| D1 | **power** | `aws` (row holds `account`) · `none` (no `account`) | decides whether a wake touches aws at all |
| D2 | **grove state** | `up` · `asleep` (ec2 only) · `grove-off-tailnet` (up, but no tailnet answer) · `refused` (answers, rejects the key) · `no-sshd` (answers, refuses the connect on its port) · `starved` (accepts, no ssh banner) | decides which leg of a reach fails, and so which cure applies: only a silence or an unknown name is the tailnet's; a refusal or a mute proves the tailnet carried the connect |
| D3 | **row shape** | `tailnet` (host is a tailnet name/ip, or absent) · `relic` (`host: localhost` + a tunnel port, from the ssm era) · `no-row` (no registry entry by that name) · `unreadable` (not json, a field outside its grammar, or `type ec2` or `nat` with no account) | every extant ec2 row is a relic today (`~/.git.forest/groves/*.json`: `host: localhost, port: 36903`); a typo'd grove name has no row at all; a hand-edited row can contradict itself |
| D4 | **seat** | `camper` · `ground` | the wish names camper. the probe saw ground answer raw too (`appendix/5.1.execution.probe.tailnet-reach.md`), so the camper preference is a choice, not a refusal the tailnet forces (F03) |
| D5 | **verb** | `wake` · `crew verb` (boot · send · read) · `term verb` (a tab's `ssh -t <alias> tmux attach`) · `list probe` · `saturation` | each verb reads the row, or rides the alias, on its own today; they must agree. the no-answer cure is not a verb: it is the failure branch each verb takes when D2 is not `up`, so it rides inside those cells (c04, c12, c14, c16, c26) |
| D6 | **mode** | `apply` · `plan` | plan must touch no network beyond aws reads |
| D7 | **caller** | `laptop` (a human's machine) · `grove` (a supervisor that runs on another grove) · `caller-off-tailnet` (either, not a tailnet peer) | the wake header names grove→grove as the case that matters most (`git.grove.wake.sh:11-21`); ssm needed only aws creds, the tailnet needs the caller to be a peer |
| D8 | **concurrency** | `alone` · `concurrent` (two wakes of one grove, or a wake that races a crew verb) | the wake writes `~/.ssh/config` and powers a box; both are shared state |
| D9 | **alias on disk** | `absent` (never woken from this machine) · `stale` (an ssm-era block, or one short of the row's host, port, or user) · `converged` (ssh, asked for the alias, dials the row's host, port, and user) | crew and term verbs ride the alias; only the wake writes it. so at power `none` an absent alias still makes the wake the cure, and a name-only row (alias = host) is absent until woken, never exempt |

credentials (present / absent / wrong account) is a sub-axis of D1=`aws` only, live only on `wake`. this wish leaves its behavior unchanged, so it is walked as one cell per value: c02 (present), c05 (absent), c11 (wrong account).

## .the walked product

the full product is 2 × 6 × 4 × 2 × 5 × 2 × 3 × 2 × 3 = 34,560 cells. most collapse, because not every axis is live on every verb:

- D6 (`plan`) is live only for `wake`. plan reads ec2 state and stops, so its outcome varies by D1 alone → one plan cell per power: c08 (`none`), c09 (`aws`; an `aws·up` plan reads `[KEEP]` on the same path)
- D2=`asleep` is live only for D1=`aws` → the `none` × `asleep` slice is **impossible** (c18)
- D3=`relic` is live only for D1=`aws` (no non-aws row was written in the ssm era) → `none` × `relic` is **impossible** (c19)
- D3=`no-row` collapses every other axis: with no row, no power, host, or seat can be read. one cell per verb class that takes a grove name (c28 wake, c29 crew verb)
- D4=`ground` is a seat the supervisor never drives a crew on → `ground` × `crew verb` is **forbidden** (c20)
- D5 `term verb` rides the same alias as `crew verb`, so it shares every cell where crew verbs succeed; one cell shows it (c27)
- D7 is orthogonal to D1–D6 on the happy path: a caller that is a tailnet peer sees the same reach from a laptop or a grove. so D7 adds one demoed slice (`grove`, case=7) and one sharp slice (`caller-off-tailnet`), not × 3
- D8 `concurrent` is live only where the wake writes: two wakes (c30), a wake that races a crew verb (c31)
- D9 is live only on verbs that ride the alias (crew, term). list, saturation, and the wake probe the row, so D9 never varies their cure. one cell per alias state that changes a crew verb's cure: `absent` (c33, c35), `converged` (c04); `stale` is c17
- D3 `unreadable` collapses every axis but the verb: no host can be read. one cell (c32)
- D2 `no-sshd` and `starved` are live on probes that read the row (list, the wake's await): c34

after the collapse, each cell left is itemized in `1.vision.experience.case=_.md`.
