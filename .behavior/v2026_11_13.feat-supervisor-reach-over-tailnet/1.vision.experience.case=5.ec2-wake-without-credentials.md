# case=5 — an ec2 wake with no credentials stops where it stops today

cell `c05` · sharp · critipath · the pin that the power half did not regress

## .narrative

aws is still the power lever for an ec2 grove, so a wake with a locked rack must still halt at the keyrack, with the rack's own words on stderr. the reach half must not run first: a probe of a sleep box would wait out the full `--timeout` and then blame the tailnet, when the real cure is an unlock.

so the order holds: power, then reach. power fails fast with the extant refusal.

## .sketch

```
given('[case5] an ec2 row with an account, no AWS_ACCESS_KEY_ID, the rack locked')
  when('[t0] rhx git.grove.wake <grove>')
    then('exit 1 at the keyrack leg, with the extant "the rack did not hand over AWS_PROFILE" text')
    then('no ssh probe ran')
    then('no alias was written')
```
