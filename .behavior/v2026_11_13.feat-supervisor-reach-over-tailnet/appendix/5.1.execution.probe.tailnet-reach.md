## .what execution takes from this

1. **a stale wake alias shadows the tailnet name.** ssh takes `HostName` from `~/.ssh/config` even
   when `-p` is on the command line, so `ssh -p 22 camper@<exid>` lands on `localhost:22`. every
   probe the code runs (list, saturation, wake's await) must pin `-o HostName=<host>` — a
   command-line `-o` wins over the config, with no write. ⇒ fulcrum F08
2. **the tailnet name of a rebuilt box drifts.** the hetzner box rejoined as `…-1`; magicdns still
   answers the old name with an offline node. the reach rule already prefers a row's `.host`, so a
   row can pin the live name; `.exid` is only the fallback. ⇒ fulcrum F09
3. **`tailscale ping` exits 1 on a slow first pong** (seen on the first run, via DERP), and 0 on a
   direct path. the code never keys on it: the ssh `true` probe is the one signal
4. **camper trusts the supervisor key on every live node**, ec2 and hetzner alike. the `.ground`
   seat user is accepted too, so F03 (saturation probes as camper) is a choice, not a forced one
5. **no hetzner row exists in the forest yet.** the done-means run against hetzner needs one, with
   `host: grove-ahbode-hetzner-v20261022-1` — a row write the human (or `git.grove.set`, which this
   package does not ship) owns
