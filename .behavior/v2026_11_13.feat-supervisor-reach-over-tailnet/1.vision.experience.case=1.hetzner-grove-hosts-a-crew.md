# case=1 — a grove outside aws hosts a crew

cell `c01` · happy · critipath · the wish's first "done means" line

## .narrative

the foreman registered `grove-sandpine-hetzner-v20261022`: a hetzner box on the camp tailnet that never sleeps. its row holds a name, a user, and no `account`. before this wish, `git.grove.wake` died at the keyrack, which asked for an aws profile the grove has no use for. now the wake sees no `account`, skips every aws leg, and asks one question: does `camper@<host>` answer over the tailnet? it does in under a second. the wake writes the ssh alias. the supervisor boots a mechanic there, sends it a task, reads its pane, and opens a tab on it, with the same verbs it uses on every other grove. its fleet sweeps agree: `git.grove.list` greets the grove 🟢 live, and `git.grove.saturation` reads its load beside the ec2 groves.

the aha: the supervisor never learns that this grove is "different". one reach, every grove.

## .sketch

```
given('[case1] a grove row with a name, user camper, and no account')
  when('[t0] rhx git.grove.wake grove-sandpine-hetzner-v20261022')
    then('it prints power: none — this grove does not sleep')
    then('it probes ssh -o BatchMode=yes camper@<host> true, within 10s')
    then('it writes Host <alias> / HostName <host> / Port 22 / User camper')
    then('it calls neither aws nor rhx keyrack')
    then('exit 0')
  when('[t1] rhx git.crew.boot --tree <tree> --role mechanic, onto that grove')
    then('the duct is created over ssh <alias> + remote tmux')
  when('[t2] rhx duct.send, then rhx duct.read, on that duct')
    then('the send lands and the read returns the pane')
  when('[t3] a term skill opens a tab on that duct')
    then('the tab attaches via ssh -t <alias> tmux attach, as on any grove')
  when('[t4] rhx git.grove.list')
    then('the row probes <host>:22, reads the sshd banner, and shows 🟢 live')
  when('[t5] rhx git.grove.saturation')
    then('the grove folds under <host>:22 and reads its real load, as any grove does')
```
