# case=3 — a relic row from the ssm era converges to the tailnet

cell `c03` (+ `c17`) · sharp→happy · critipath · the densest cell

## .narrative

every extant ec2 row was written for the ssm tunnel: `host: localhost, port: 36903`. that is the address of a port-forward on the supervisor's own machine, not of the grove. if the new wake read `.host` literally, it would write `HostName localhost / Port 36903`, which reaches naught once no tunnel exists. if `git.grove.list` read it literally, it would probe `localhost:36903` and report 🔴 DOWN on a healthy grove. if saturation read it literally, it would fold every relic onto one `localhost:…` key.

so one reader decides a grove's reach, and all three verbs ask it. a loopback host (`localhost`, `127.0.0.1`, `::1`) is a tunnel relic and reads as absent, so the reach host falls back to the row's `.exid // .name` — exid first, since a `.ground` row's name is a seat while its exid names the box, so both seats of one grove still fold to one key. the wake's probe takes `accept-new`, since `known_hosts` holds no key for the new host yet (F07). the tunnel port that rides beside it is a relic too, so the reach port falls back to 22. the row itself is untouched. the wake rewrites the ssh alias, and list and saturation compute the same reach from the same row.

the human runs no new command. the first wake after upgrade converges the alias; `git.grove.list` reads 🟢 live against `<exid>:22`.

## .sketch

```
given('[case3] a row with host: localhost, port: 36903, an account')
  when('[t0] rhx git.grove.wake <grove>')
    then('the reach reads <exid>:22, never localhost:36903')
    then('ssh [REPLACE] the alias, from HostName localhost / Port 36903 to HostName <exid> / Port 22')
  when('[t1] rhx git.grove.list')
    then('it probes <exid>:22 and reads 🟢 live')
  when('[t2] rhx git.grove.saturation')
    then('the grove folds under the key <exid>:22')
given('[case3.before-wake] the same row, alias still names localhost:36903')
  when('[t0] rhx duct.read on a crew of that grove')
    then('ssh is refused; the hint names rhx git.grove.wake <grove>, which converges it')
```
