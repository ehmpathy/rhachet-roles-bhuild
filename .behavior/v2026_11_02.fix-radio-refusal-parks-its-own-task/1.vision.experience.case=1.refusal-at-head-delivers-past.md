## narrative

a clone holds four records across four repos. the oldest is an edit of #599 that the bot cannot
sign. the clone pushes a fifth task. the radio replays the backlog: github refuses the #599 edit,
`GraphQL: Resource not accessible by integration (updateIssue)`. the radio sets that one record
aside, reason `upstream:access`, and sends the rest, then the new task. the push names the record
it set aside and how to amend it.
