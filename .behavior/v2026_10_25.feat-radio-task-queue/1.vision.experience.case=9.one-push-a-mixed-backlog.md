# case=9 — one push carries a mixed backlog

feel: sharp · care: critipath · the densest walk: two set-aside classes, a gate, deliveries past each, and the carrier push, in one drain

## .narrative

a fleet clone has held work for a week. its worktree queue holds five records across four
repos. it pushes one more task. that push is the probe: the gate for its own target is open, so
it carries the whole backlog out, oldest first. in one tree the clone sees each record's fate —
which landed, which was set aside and why, which waits at a gate — and the one command that
frees each. its own push lands too, though older records faulted.

  then the push output leads with this push's fate, then the backlog's, one row each

given instead a rate limit on C

  then A and B are set aside, C halts the drain, D, E, and the new push wait behind C (case=6)
