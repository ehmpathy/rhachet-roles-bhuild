# case=3 — amend a held update to as-human, then drain (edit an extant issue)

feel: happy · care: critipath · #603 — [t0]–[t2]. [t3] is a sharp alterpath of its own (a retitle refused), verdicted in `case=_` grid 3; it rides here because it is the same verb on the same record

## .narrative

the clone wants the #599 edit to land, not to drop it. the robot app may not edit that issue;
the human's gh login may. the clone runs `radio.task.queue set --key 3f9a… --auth as-human`.
the record keeps its place in line, its body, its target — only its auth changes. the next
drain sends the edit under the gh cli login, and `gh issue edit 599` succeeds.

for a one-off, `radio.task.queue drain --auth as-human` sends this drain's records under the gh
login without a change on disk.
