# case=4 — drain while radio.uses blocks

feel: sharp · care: critipath · the wish's bound

## .narrative

a human has paused the radio globally. a clone, eager to clear its queue, runs
`radio.task.queue drain`. naught goes out. the output says so, and names the one command a human
runs to lift the gate. the queue is unchanged except each record's reason now reads the gate.

## .timeline

```
given the queue holds [A] create → X, [B] create → Y
  and radio.uses --global block

when [t0] radio.task.queue drain
  then no gh call is made
  then A and B stay QUEUED, reason gate:global
  then the output reads "naught delivered: the radio is blocked" and names the lift
       `radio.uses --global allow (human)`
  then exit 2

given instead radio.uses allows X and blocks Y
when [t1] radio.task.queue drain
  then A delivers; B is held at its gate, its lift named
  then exit 2
```
