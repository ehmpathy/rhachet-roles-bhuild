# F7 — which issues the pr closes

- **the fork**: close only what is fully met · close all three, each with a note for the part left
- **verdict**: set by the director, 2026-10-25 (`refs/director.verdict.v2026_10_25.[given].by_human.md`): "closes #N" for each the pr fully covers, and name any part it leaves, so the merge strikes them with that note
- **the pr body lines**:
  - `closes #604` — the tree itself
  - `closes #513` — fully: the default stays as-ehmpath; the robot-auth failure names `--auth as-human`; `drain --auth` and `set --auth` carry it to held records; clamps [caseA–C]
  - `closes #603` — leaves: an edit of an issue outside the radio frame (no `🎙️ task -` title); it stays refused, with the rule and the fix named (F9)
  - `closes #511` — leaves: caseC, a set-aside record retries on every drain rather than only on an explicit act (F2); caseE, a held record replays with its own auth or `drain --auth`, never the carrier push's (F3)
- **rework**: clean — pr body lines
- **confidence**: set by a human
