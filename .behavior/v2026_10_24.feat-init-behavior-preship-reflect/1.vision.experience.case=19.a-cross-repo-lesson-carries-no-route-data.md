# case=19 · a cross-repo lesson carries no route data

feel = sharp · care = critipath · cell = c34

## .narrative

a route in a pii repo reaches `7.reflect`. one of its three-whys chains ends in another repo: the
mechanic's test skill hid a flake. the cure belongs there, so the driver dispatches a task to that
repo's tracker.

the task names the lesson ("a red that passes on re-run is still a red") and the cure's shape (the
skill should print the flaky case by name). it quotes no peer review text, no fixture, no yield
text, no name from the route. the pii repo's data stays in the pii repo; only the lesson travels.

the stone has no pii read — that check is the F1 follow-up's. so the text rule binds in every repo,
and a public repo's route loses naught by it: a lesson and a shape are what the owner repo needs.

surfaced at the blueprint review (i006): the scope note held D5 for checkpoints only, and missed
reflect's outbound text.
