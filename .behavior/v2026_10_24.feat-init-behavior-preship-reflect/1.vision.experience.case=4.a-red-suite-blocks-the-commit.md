# case=4 · a red suite blocks the commit

feel = sharp · care = critipath

## .narrative

at `6.preship` the clone runs the full suite, not just the scope it touched. one integration
test in a far module goes red: a snapshot the change shifted. the clone does not commit. it
fixes the cause, re-runs the full suite, and only then commits.

"cicd green locally" means the whole suite, every time. a red commit would cost a remote round
and land a broken pull in front of the commander.

## .timeline

```
given('[case4] a route at 6.preship; the full suite has one red test')
  when('[t0] the driver runs the full suite')
    then('one suite fails; the driver makes no commit')
  when('[t1] the driver fixes the cause and re-runs the full suite')
    then('every suite passes')
  when('[t2] the driver commits and pushes')
    then('as case=3 [t1] onward')
```
