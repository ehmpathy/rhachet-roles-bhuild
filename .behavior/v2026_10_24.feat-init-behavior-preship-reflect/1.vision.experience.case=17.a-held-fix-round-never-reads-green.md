# case=17 · a held fix round never reads green

feel = sharp · care = critipath · cell = c28

## .narrative

preship's first push lands, and the remote suite goes red. the driver reads the errors, fixes the
cause, and asks for a commit. the quota is spent: `git.commit.set` refuses. the fix is held.

the pr is still red, and its head is the red one. the driver writes that down verbatim: the red
rollup, the refusal, the human who can grant it, the grant command, and how many commits the route
still needs. the same record goes to the repo's task queue, with the commit message and the land
steps, so it outlives the route.

the head-proof review asks for the `### pr` proof. there is no green head to paste, so the driver
takes the held arm: it pastes the `### held` record and the last rollup seen. it does not write
"green". the route goes on to reflect, held and honest about it.

surfaced at the blueprint review (i004): the walk had visited a grant refusal only at preship's
first commit.
