# case=5 · a refused commit is held

feel = sharp · care = critipath

## .narrative

the clone reaches `6.preship` with a green suite. bert granted a quota of one at dawn; another route
in the same worktree spent it. `git.commit.set` refuses.

the clone does not try another path — no raw `git commit`, no new branch, no wait loop — and it
does not halt the route either. it notes the hold in the preship yield: the refusal word for word,
the grant command, and what is held (the done work, uncommitted). then it moves on to `7.reflect`.

the director sees the held commit and lands it when the switch opens. the route never stalls on a
grant, and no commit lands without one.

the same hold, with `no commit quota set`, meets a route that never had a grant.

## .timeline

```
given('[case5] a route at 6.preship; the suite is green; the quota is spent')
  when('[t0] the driver runs git.commit.set --mode apply')
    then('it refuses: "no commit uses left", and names "git.commit.uses set --quant N --push allow|block"')
    then('the driver notes the hold in the preship yield: the refusal verbatim, the grant, what is held')
    then('it runs no raw git commit, and does not halt --as blocked')
  when('[t1] the driver passes 6.preship')
    then('it moves to 7.reflect; the work stays uncommitted on the tree, recorded as held')
  when('[t2] the director opens the switch')
    then('the held commit lands, and the pull is watched green, as case=3 [t1] onward')
```
