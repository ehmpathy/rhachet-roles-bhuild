## .narrative

the route runs in a repo that holds student records for the surf school. it is declared pii.

the sharp edge: every other route pushes at the vision checkpoint, and the clone has done so a
hundred times. the habit is the hazard. so the checkpoint text reads the pii declaration first, and
only then names the command — `git.commit.set` with no `--push`. the push is never the default the
driver must remember to drop; it is the branch the declaration closes.

at the vision and the blueprint, the clone commits locally. the wisher reviews those yields on the
box, as before. at `6.preship` the clone pushes every local commit at once, then opens the pull. no
draft of a pii design sat on a remote before the route was done.

the residual risk is a pii repo with no declaration: the stone would read it as public. how a repo
is known pii, and whether "undeclared" should default to local, is q1.
