# case=18 · a refused suite halts at once

feel = sharp · care = critipath · cell = c30

## .narrative

the driver reaches `6.preship` and runs the full suite. the skill refuses before any test runs:
the integration suite needs a credential, and the keyrack is locked. the skill prints the unlock
command as its hint.

no code change can unlock a key, so a fix round has no cause to fix. the driver does not spend its
three fix rounds on it. it halts with `--as blocked` at once, the refusal and its hint verbatim, so
the human reads one command to run.

the refusal and a red suite both exit 2. the driver tells them apart by what the skill printed: a
red suite names the tests that failed; a refusal names the input or the key it lacks.

surfaced at the blueprint review (i004): the walk held only green and red for the local suite.

## .timeline

```

    then('the driver halts --as blocked with the refusal and the hint verbatim')
    then('it spends no fix round, and makes no commit')
  when('[t1] the human unlocks the keyrack and the driver resumes')
```
