# case=16 · no ship tools halts at the first commit

feel = sharp · care = critipath

## .narrative

a stranger's repo enrolls the behaver role, but not the ehmpathy mechanic role. the clone drives a
route to `6.preship`. its suite step names `rhx git.repo.test`; its commit step names
`rhx git.commit.set`. the skills are not there.

the clone does not reach for raw `git commit` — that would be a commit no paved skill guards, as
the bot, with no quota check. it halts with `--as blocked`, quotes the absent-skill error verbatim,
and names the one fix: enroll the role that ships the tools. the stranger enrolls it once; every
later route in the repo ships.

this is a halt, not a hold: a hold waits on a grant the director can open, but an absent tool has no
switch to open. the first commit the route asks for is preship's (the vision checkpoint is deferred
to the follow-up behavior), so the gap shows at the end of the first route.

## .timeline

```
given('[case16] a repo with no ehmpathy mechanic role enrolled; a route at 6.preship')
  when('[t0] the driver runs rhx git.repo.test or rhx git.commit.set')
    then('rhx reports the skill is not found')
    then('the driver halts --as blocked with that error verbatim and names the role enroll')
    then('it runs no raw git commit, and no raw test command in place of the paved one')
  when('[t1] the human enrolls the mechanic role and the driver resumes')
    then('preship proceeds, as case=3 [t0]')
```
