# case=3 · preship lands a green pull

feel = happy · care = critipath · the densest cell

## .narrative

the clone finishes `5.5.playtest` on a book-a-lesson reminder. bert approves the playtest. the
route moves to `6.preship`.

the clone runs the full suite locally. it is green. the session holds a commit quota with push
allowed. the clone commits the work at the done gate, pushes, and the pull opens. it runs
`rhx git.release --watch` and waits. the watch says done — but a watch can read the rollup before
github registers the checks for this push, so the clone asks github which head it holds and what ran
on it. the head is its sha; every check on it is green.

the clone stops there. it does not `--apply`, it does not merge. it signals the stone passed and
moves to `7.reflect`. that night bert opens one link and sees a green pull, ready for his gate.

before: the work sat in a worktree, suite green, for hours, until a human chased it.
after: the route itself carries the work to a green pull.
